# Системное резервное копирование Android

Приложение разрешает Android создавать системную копию пользовательской базы и настроек. В неё входят история прослушиваний, избранное, заметки, тексты и тайминги, сохранённые переводы, правила источников, чёрный список и настройки оформления.

Данные доверия Connect, адреса связанных устройств, кэш обложек и временные файлы не входят. После восстановления может потребоваться повторно связать устройства и выдать системные разрешения.

В рабочей сборке со студией караоке также включён отдельный каталог её черновиков: исходная и текущая разметка и положение редактора. Это дополнение не меняет уже опубликованный APK 1.5.1. Исходные аудиофайлы не копируются; после переноса на другой телефон файл для волны может потребоваться выбрать снова, поскольку доступ к документу выдаёт Android.

## Когда создаётся копия

Резервирование должно быть включено в системных настройках телефона. Его выполняет Android, а не кнопка в Lirix. Расписание, выбранный провайдер и доступность копии определяются системой. Для облачной копии действует лимит 25 МБ на приложение; превышение может остановить резервирование всей базы.

На Android 9–11 включение данных требует клиентского шифрования у транспорта. На Android 12+ облачная копия запрещена без поддержки шифрования, а перенос между Android-устройствами настроен отдельно. На Android 8.0–8.1 такой флаг недоступен: поддерживается базовая защита системного транспорта без обещания сквозного шифрования.

Приложение не сообщает, что копия создана: наличие правил и успешная сборка не являются подтверждением выполненной системной операции. Полный цикл копирования/восстановления проверяется отдельно на тестовом устройстве, без удаления рабочей библиотеки пользователя.

## Переход со старой подписи

Эта настройка не создаёт копию задним числом для 1.4.0, где резервирование было отключено. Она также не разрешает восстановление между APK с несовместимыми подписями. Полного ручного экспорта/восстановления через Android-интерфейс пока нет. Не удаляйте старую установку с важными данными ради смены подписи.

См. [официальную документацию Android Auto Backup](https://developer.android.com/identity/data/autobackup). Эти изменения добавлены после существующего тега v1.5.0 и не входят в ранее собранный APK из build/release150.
