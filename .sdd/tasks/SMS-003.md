**Зависит от:** `SMS-002`

**Поведение:**
1. `SmsIngestController` / `SmsIngestControllerImpl`:
   - Монотонный `seqGenerator = AtomicLong(0L)`.
   - `val channel = Channel<SmsRawPayload>(Channel.UNLIMITED)`.
   - `override val queueDepth: Int` возвращает число элементов в буфере.
   - `enqueueSms(contract: SmsContract, subId: Int?): Long`:
     - Создаёт `SmsRawPayload(seq, contract.originAddress, contract.body, contract.timestampMillis, Instant.now(), subId)`.
     - Отправляет в `channel.send(payload)`.
     - Возвращает `seq`.
   - `processPayload(payload: SmsRawPayload): Long`:
     - **Шаг 1:** Вычисляет `payloadJson` и `dedupKey = EventNormalizer.computeDeduplicationKey(SourceId.SMS, "android.telephony.sms", payloadJson)`.
     - **Шаг 2:** Проверяет дубликат `storageGateway.findDuplicate(dedupKey)`. Если найден -> вернуть `existingId`.
     - **Шаг 3:** Немедленный `storageGateway.insertRawEvent(rawEvent)` (ADR-004).
     - **Шаг 4:** `val event = SmsMapper.toEvent(savedRawEvent, contract)`.
     - **Шаг 5:** `storageGateway.insertEvent(event)`.
     - **Шаг 6:** `storageGateway.upsertSourceHealth(health)`.
     - Возвращает `rawId`.
   - `start()` и `stop()`: управление жизненным циклом корутины фонового консьюмера.
2. `SmsBroadcastReceiver`:
   - `onReceive(context, intent)`:
     - Null-guard, проверка `Telephony.Sms.Intents.SMS_RECEIVED_ACTION`.
     - `goAsync()` для продления жизненного цикла.
     - `SmsMapper.fromSmsMessages(Telephony.Sms.Intents.getMessagesFromIntent(intent))`.
     - Извлечение `subId`.
     - `smsIngestController.enqueueSms(smsContract, subId)`.
     - `pendingResult.finish()`.
3. `SmsPoller`:
   - `pollNewMessages(sinceTimestamp: Long): Int`:
     - Запрос к `contentResolver.query(Telephony.Sms.Inbox.CONTENT_URI, ... DATE > sinceTimestamp)`.
     - Итерация по курсору с проверкой `findDuplicate` и вызовом `insertRawEvent` + `insertEvent`.
     - Возвращает количество сохранённых новых сообщений.

**Критерий приёмки:**
- Консьюмер немедленно персистит `RawEvent` до любой бизнес-логики.
- Дубликаты отсекаются через `findDuplicate`.
