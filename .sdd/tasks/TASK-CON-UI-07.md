# TASK-CON-UI-07: Android Connect BottomSheet («Воспроизвести на устройстве», CameraX QR-сканер, громкость, a11y)

## 1. Контекст и Описание задачи
В соответствии со спецификацией **`SPEC-CONNECT-01 (§5.1, §5.2, §5.3)`**, реализовать компонент нижней шторки (Compose `ModalBottomSheet`) для выбора целевого устройства Lirix Connect на Android.
Шторка интегрируется с `DeviceRegistry` и `HandoffStateMachine` из `:shared`, обеспечивает плавный переход воспроизведения на ПК или планшет, регулировку удалённой громкости и сопряжение новых устройств через сканирование QR-кода камерой (CameraX / ML Kit / ZXing).

---

## 2. Архитектурные требования и UI (§5.2, §5.3)
1. **Точка входа**:
   - Векторная иконка `Icons.Default.DevicesOther` в `NowPlayingScreen.kt` рядом с регулятором громкости/трекбаром с бейджем активного удалённого подключения.
2. **Блок «ТЕКУЩЕЕ УСТРОЙСТВО»**:
   - «● Этот телефон (Android)» с зелёным индикатором.
   - Слайдер системной громкости телефона.
3. **Блок «ДОСТУПНЫЕ УСТРОЙСТВА В СЕТИ»**:
   - Реактивный список из `DeviceRegistry.devices: StateFlow<List<ConnectedDeviceInfo>>`.
   - Карточки устройств с иконками (`Icons.Default.Computer`, `TabletAndroid`, `PhoneAndroid`).
   - Статус: «В сети» / «Не в сети», «Играет: <Трек>» / «Нажмите для передачи».
   - Клик по устройству запускает `HandoffStateMachine.requestHandoff(device)` с показом спиннера подключения на карточке (до 5 с).
   - При активном удалённом воспроизведении: регулятор громкости удалённого устройства прямо в карточке.
   - Меню «⋮» для каждого доверенного устройства: «Переименовать», «Забыть устройство» (с диалогом подтверждения).
4. **Блок «ПОДКЛЮЧИТЬ НОВОЕ УСТРОЙСТВО»**:
   - Кнопка «Сканировать QR-код».
   - Сканер на базе `CameraX` / `MLKit Barcode Scanning` (или `ZXing Android Embedded`) со скругленным видоискателем и подсветкой границ.
   - Распознавание URI `lirix://pair?d=<base64url>`.
   - При отказе в разрешении камеры: понятный экран с кнопкой «Открыть настройки» и альтернативным полем «Ввести код вручную».
5. **Доступность (a11y) и TalkBack**:
   - `contentDescription` для всех кнопок и слайдеров.
   - Озвучивание смены роли («Воспроизведение перенесено на Компьютер», «Устройство отключено»).
