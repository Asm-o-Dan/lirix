# TASK-UI-PROMPTER-FIX-01: Комплексное устранение дефектов рендера и композиции Teleprompter Deck

## Статус
`DONE`

## Контекст и Проблема
Первая сборка десктопного плеера Lirix Desktop 2.0 (`Lirix.exe`) выявила критические расхождения со спецификацией и дефекты рендера:
1. **Fallback-шрифт**: Literata и Golos Text не были физически подключены; использовались `FontFamily.Serif` / `FontFamily.SansSerif`, что на Windows дало системный Times New Roman.
2. **Эмодзи в UI**: Вместо векторных иконок отрисовались разнородные системные глифы (синие квадраты ⏮ ⏭, 🎤, 🎸, ℹ, ⚡, битый квадратик tofu в HUD).
3. **Слипшийся транспорт**: Из-за недостатка ширины в левой колонке (420 dp) ряд под трекбаром сжался в `00:00 / 00:00Сдвиг текста −0,3 с`, кнопки `[−] [+]` вытеснены. Сам трекбар отображается тонкой черточкой.
4. **Винил остался**: Занимает ~270 px с кнопкой «Скрыть винил», перегружая экран.
5. **Ложь в idle**: Отображаются выдуманные строки песни «Lirix Studio Desktop Hub» и пустой VU-метр с горящим «0 dB».
6. **SaaS-рамки («карточки в карточках»)**: Толстые двойные обводки, блок тем на 6 кнопок с капсом «ДИЗАЙН ТЕМА».
7. **Маркер оторван от текста**: 3 dp планка стоит на 60–80 px левее текста из-за промежуточного 44 dp слота перемотки.
8. **Белый заголовок окна**: Системная рамка Windows не переведена в тёмный режим (DwmSetWindowAttribute).

## Зона ответственности
`media-ui` / `desktop`

## Задачи исполнителя (DoR -> DoD)

### 1. Подключение реальных шрифтов Literata и Golos Text
- Скачать / положить TTF/OTF файлы Literata (Medium, Regular) и Golos Text (SemiBold, Medium, Regular) в `desktop/src/main/resources/fonts/`.
- В `LirixTypography.kt` (или платформенном фабричном методе) загружать реальные `androidx.compose.ui.text.platform.Font` из ресурсов jar/дистрибутива.
- Обеспечить OpenType `tnum` для моноширинных цифр в таймкодах.

### 2. Замена эмодзи на векторные иконки Compose Material Icons / Vector Graphics
- Убрать все Unicode-эмодзи (`⏮`, `⏭`, `▶`, `⏸`, `🎤`, `🎸`, `ℹ`, `⚡`, `🪟`, `🎛`, `🗗`).
- Использовать векторные `androidx.compose.material.icons.Icons` (`Icons.Filled.SkipPrevious`, `Icons.Filled.PlayArrow`, `Icons.Filled.Pause`, `Icons.Filled.SkipNext`, `Icons.Filled.QueueMusic`, `Icons.Filled.Lyrics`, `Icons.Filled.Info`, `Icons.Filled.PictureInPicture`, `Icons.Filled.Tune` и т.д.).

### 3. Исправление компоновки транспорта и трекбара
- Разделить блок транспорта по вертикали:
  - Строка кнопок транспорта (`Prev`, `Play/Pause`, `Next`) по центру.
  - Полноразмерный контрастный `Slider` (высота дорожки 4 dp, контрастный thumb и track).
  - Под трекбаром: слева таймкоды `00:00 / 00:00` (Golos Text tnum), справа — компактный блок сдвига `Сдвиг текста −0,3 с` с кнопками `[−]` и `[+]`.
  - Достаточный отступ между ними, никакого наползания текста.

### 4. Очистка левой колонки (удаление винила)
- Полностью удалить компонент `AnalogTurntable` и кнопку «Скрыть винил» из десктопного `DesktopDeckScreen.kt`.
- Левая колонка строится сверху вниз:
  - Компактная обложка альбома (88×88 dp со скруглением 12 dp) или монохромная заглушка ноты.
  - Название трека (Literata 18 sp или Golos SemiBold 16 sp) и исполнитель (Golos Regular 13 sp).
  - Блок транспорта и трекбара.
  - Блок WASAPI Loopback VU-метра (отображается **только** если есть активный сигнал `audioLevels?.isActive == true && audioLevels.isSilent == false`). В тишине и в idle — VU-метр полностью скрыт.

### 5. Честный пустой экран в IDLE
- Удалить `demoLrcLines` и выдуманный текст «Lirix Studio Desktop Hub».
- Если ничего не играет (`playback == null`):
  - По центру правой суфлёрской зоны показывать чистую заглушку: «Ничего не играет. Запустите музыку в любом плеере».
  - Без фейковых строк и без фейковых таймкодов.

### 6. Упрощение тем и человеческий статус
- Оставить строго 2 темы: `Graphite & Chalk` (тёмная) и `Paper & Ink` (светлая).
- Удалить блок из 6 кнопок «ДИЗАЙН ТЕМА» из левой панели. Переключатель темы (иконка Луна/Солнце) разместить в `DesktopTopBar`.
- Статус в TopBar: вместо `idle.session • GSMTC` показывать «Нет активного плеера» (в idle) или «Играет в Яндекс Музыке / Spotify» при активном источнике.
- Вкладку «Текст (LRC)» переименовать в «Текст».
- Убрать капс «LIRIX STUDIO» -> «Lirix Studio».

### 7. Композиция, отступы и маркер
- Убрать толстые вложенные рамки `surfaceCard` с границами. Сделать единый фон `appBackground` с тонкими делимиттерами `hairline` (1 dp) между левой панелью и суфлёром.
- Выровнять левый край метаданных и суфлёра.
- Планка-маркер 3 dp должна стоять вплотную к активной строке (на расстоянии 8–10 dp левее текста). Слот кнопки перемотки `[▶ 1:15]` разместить левее планки или сделать всплывающим без отрыва планки от текста.
- Якорь активной строки зафиксировать строго на 40% высоты вьюпорта.
- Контраст неактивных строк: проверить через `ContrastClampHelper`, чтобы коэффициент контраста был $\ge 4.5:1$ (цвет `Mist` #8C929D на `Graphite` #1B1E24).

### 8. Тёмный заголовок окна Windows (DwmSetWindowAttribute)
- В `Main.kt` при инициализации окна на Windows применить `DwmSetWindowAttribute` (атрибут 20 = `DWMWA_USE_IMMERSIVE_DARK_MODE`) через Win32 / JNA, чтобы системный title bar стал тёмным Graphite в тон темы.

## Критерии приёмки (DoD)
1. Шрифт лирики — настоящая `Literata` с засечками (не Times New Roman). Шрифт таймкодов — `Golos Text` с `tnum`.
2. В интерфейсе нет ни одного эмодзи: все контролы на векторных иконках Compose.
3. Левая панель без винила: обложка 88 dp, название, транспорт, трекбар с рабочими кнопками `[−] [+]`.
4. В idle нет выдуманного текста и нет пустого VU-метра.
5. Заголовок окна Windows тёмный (не белый).
6. Тесты `:desktop:test` и сборка `packageDmg` / `createDistributable` проходят без ошибок.
