# TASK-UI-MOB-FIX-05: Полировка интерфейса (Капс, эмодзи, отступы дока, контраст и вёрстка)

## 1. Контекст и Проблематика
1. **Остаточный капс**: в Чёрном списке заголовки «ПРАВИЛА АКТИВНЫЕ», «ВСЕГО», «ВСЕ (1) / ТРЕКИ / АРТИСТЫ / ПРИЛОЖЕНИЯ» набраны капсом, а крайняя вкладка обрезана справа.
2. **Эмодзи в интерфейсе**: эмодзи 📝 и 🎸 в сегментном переключателе Инспектора («Текст песни / Аккорды»).
3. **Наезд нижнего дока во Wrapped**: плавающая капсула навигации перекрывает нижний элемент списка («Клуб сотни»).
4. **Курсив Literata во Wrapped**: длинный абзац курсивом на кириллице тяжело читается. Курсив допустим только для первого вводного предложения.
5. **Статический режим лирики**: серая полоса над текстом песни выглядит чужеродно; кнопки занимают лишнюю высоту, лирика получает меньше 50% экрана.
6. **Медиатека**: бейдж «Текст» имеет слабый контраст по сравнению с «Синхронно»; чип-фильтры обрезаются без намёка на горизонтальный скролл.
7. **Экран «Текст не найден»**: внутренняя формулировка «в стандартных базах». Требуется человечный текст «Не нашли текст для этого трека» с пояснением под кнопкой.
8. **Инспектор TeachMode**: нижняя панель занимает треть экрана и закрывает веб-страницу; рамки выделения и вырезания не различимы визуально.

## 3. Критерии приёмки (DoD)
1. **Вычистка капса (Sentence Case)**:
   - В `BlacklistSettingsScreen.kt`: «Активные правила», «Всего правил: N», вкладки: «Все (N)», «Треки», «Артисты», «Приложения».
   - Чипы фильтров в Чёрном списке и Медиатеке оборачиваются в `LazyRow` с `contentPadding = PaddingValues(horizontal = 16.dp)`, исключая обрезку.
2. **Векторные иконки вместо эмодзи**:
   - В `TeachModeScreen.kt`: заменить 📝 на `Icons.Default.Description`, 🎸 на векторную иконку гитары/ноты.
3. **Отступ под док во Wrapped**:
   - Добавить `contentPadding = PaddingValues(bottom = 96.dp)` для списка Wrapped, чтобы все карточки ачивок и кнопка «Поделиться» свободно скроллились выше плавающего навбара.
4. **Типографика эссе Literata**:
   - Первое предложение эссе: Literata Medium Italic.
   - Остальной текст абзаца: Literata Roman (обычное прямое начертание).
5. **Статический режим**:
   - Удалить серую непонятную полосу над текстом.
   - Компактный бейдж «Текст песни без таймингов» в шапке, высвобождая не менее 55% высоты под саму лирику.
6. **Медиатека**:
   - Бейдж «Текст»: контрастный фон `surfaceElevated` с читаемым цветом `textSecondary` (контраст не менее 4.5:1).
7. **Экран «Текст не найден»**:
   - Заголовок: «Не нашли текст для этого трека».
   - Подпись: «Вы можете найти его в веб-поиске и привязать к песне в один клик».
8. **Инспектор TeachMode**:
   - Нижняя панель: компактная (высота ≤ 120 dp) со стрелкой сворачивания/разворачивания.
   - Стилизация в `teach_inspector.js`: выделенный контейнер — **сплошная фиолетовая рамка** (`border: 2px solid #8B5CF6`), вырезанные блоки (`strip`) — **пунктирная красная рамка** (`border: 2px dashed #EF4444; background: rgba(239, 68, 68, 0.1)`).
