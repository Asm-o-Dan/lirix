## Задача UI-003: TimelineViewModel

**Файлы:**
- `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/TimelineViewModel.kt`
(создать)

**Спека:**
- `.sdd/specs/ui-timeline/overview.md#компонент-бизнес-логики-timelineviewmodel` (v1)

**Зависит от:** `UI-002`

**Поведение:**
- ViewModel принимает `storageGateway: StorageGateway`.
- Реактивное состояние через `StateFlow<TimelineUiState>`.
- Эффекты через `SharedFlow<TimelineUiEffect>`.
- Подписка на `storageGateway.observeEvents(limit = 100)` и `storageGateway.observeAllSourceHealth()`.
- Реактивная фильтрация по `SourceFilter` и локальный поиск по `searchQuery` (заголовок, текст, packageName).
- Методы:
  - `onSearchQueryChanged(query: String)`
  - `onFilterSelected(filter: SourceFilter)`
  - `onEventClicked(event: EventUiModel)`
  - `onDismissEventDetails()`
  - `onDeleteAllClicked()`
  - `onConfirmDeleteAll()`
  - `onDismissDeleteDialog()`
  - `onExportJsonClicked()`: выгружает данные через `storageGateway.exportAllToJson()`, эмитит `TimelineUiEffect.ShareJsonExport(json)`.

**Критерий приёмки:**
- Потокобезопасная обработка событий, 100% покрытие бизнес-логики тестами без Android context.
