## 1. Цель задачи
Реализовать эталонный мобильный экран плеера-суфлёра:
1. **Принцип верстки (weight(1f)):**
   - TopBar ($48\,\text{dp}$), метаданные ($64\,\text{dp}$), трекбар ($48\,\text{dp}$), контекстная строка сдвига и кегля ($48\,\text{dp}$), табы режимов ($48\,\text{dp}$), транспорт ($56\,\text{dp}$) имеют фиксированные высоты.
   - **Колонка лирики занимает всё оставшееся пространство через `Modifier.weight(1f)`**.
   - На экранах $< 700\,\text{dp}$ (360×640) срабатывает автосжатие: метаданные переносятся в шапку в одну строку, сохраняя высоту суфлёра не менее $300\,\text{dp}$.
2. **Контролы суфлёра в портрете:**
   - Степпер кегля текста `Аа` (масштаб $80\% \dots 150\%$).
   - Регулятор задержки текста `Сдвиг текста −0,3 с [ − ] [ + ]` (шаг $0.1\,\text{с}$).
   - Селектор 4 табов: `Караоке │ Аккорды │ Текст │ Заметки` (высота клика $48\,\text{dp}$).
3. **Режим «Фокус» (Double-Tap) и Доступность:**
   - Двойной тап по тексту скрывает метаданные и вспомогательные строки, отдавая суфлёру до **$72\%$ экрана ($540\,\text{dp}$)**.
   - Одноразовый хинт при первом запуске: *«Двойной тап по тексту — режим максимального фокуса»*.
   - **TalkBack:** семантическое действие `customAction(label = "Скрыть метаданные / Переключить фокус")`.
4. **Интерактивный Seek по долгому нажатию:**
   - Перемотка трека по `onLongPress` на строку караоке.
   - При `canSeek == false` жест блокируется, кнопка не всплывает. Одноразовый хинт: *«Удерживайте строку для перемотки»*.
5. **Подсветка экрана (`FLAG_KEEP_SCREEN_ON`):**
   - Флаг активен на экране плеера **в обеих ориентациях** (портрет и ландшафт на пюпитре).
   - Автоматически снимается при выходе с экрана плеера или при паузе трека более 5 минут.
   - Наличие тумблера «Не гасить экран на пюпитре» в настройках.
6. **Поддержка Reduced Motion:**
   - При `Settings.Global.ANIMATOR_DURATION_SCALE == 0` (или `LocalReducedMotion`) отключаются пружинные анимации: активная строка и скролл переключаются мгновенно.
7. **Пустые и Ошибочные Состояния:**
   - **Нет доступа к уведомлениям (первый запуск):** экран блокировки с ясным объяснением, кнопкой «Открыть настройки доступа к сессиям» и автоматической проверкой разрешения в `onResume`.
   - **Нет активного плеера:** нейтральная заглушка «Ничего не играет. Запустите трек в любом плеере Windows/Android».
   - **Текст не найден:** метаданные трека + кнопка «Искать вручную».
   - **Текст без таймингов:** статичный показ стихов, планка «сейчас» скрыта, подпись «Тайминги недоступны. Прокручивайте текст вручную».
   - **Перемотка недоступна:** визуальные подсказки `seekTo` скрыты.

## 2. Критерии приемки (DoD)
- [ ] **Скриншот-тесты (4 сценария):**
  1. $360\times 800\,\text{dp}$ (базовый портрет).
  2. $360\times 640\,\text{dp}$ (автосжатие метаданных в шапку, суфлёр $\ge 300\,\text{dp}$).
  3. $412\times 915\,\text{dp}$ (суфлёр плавно масштабируется через `weight(1f)`).
  4. Трёхкнопочная навигация Android (навибар $48\,\text{dp}$, нет перекрытий).
- [ ] **Масштабирование текста ОС (1.3x и 2.0x):** суфлёр не сжимается меньше $300\,\text{dp}$.
- [ ] Степпер «Аа» масштабирует текст от 80% до 150%, регулятор сдвига корректирует тайминги караоке.
- [ ] Экран не гаснет на пюпитре при воспроизведении, и гаснет после 5 минут паузы.
- [ ] При `ANIMATOR_DURATION_SCALE = 0` пружинный скролл отключается.
- [ ] Реализованы и протестированы все 5 пустых/ошибочных состояний.
