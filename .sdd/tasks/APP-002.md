- `.sdd/specs/app-lifecycle/overview.md#контейнер-внедрения-зависимостей-appmodule` (v1)

**Зависит от:** `APP-001`

**Поведение:**
1. `App.kt`:
   - Наследник `Application`, аннотирован `@HiltAndroidApp`.
   - Реализует `Configuration.Provider` для Hilt WorkManager (`@Inject lateinit var workerFactory: HiltWorkerFactory`).
   - `onCreate`:
     - Вызывает `System.loadLibrary("sqlcipher")`.
     - Вызывает `AppNotificationChannels.createChannels(this)`.
     - Планирует `NotificationWatchdogScheduler.scheduleWatchdog(this)` и `AbsenceAlertScheduler.scheduleAbsenceCheck(this)`.
2. `AppNotificationChannels.kt`:
   - `CHANNEL_SERVICE = "npc_service"` (Низкая важность, тихий, для foreground watchdog при необходимости).
   - `CHANNEL_ALERTS = "npc_alerts"` (Высокая важность, звук, heads-up, для критических алертов отсутствия событий).
   - Метод `fun createChannels(context: Context)`.
3. `AppModule.kt`:
   - `@Module @InstallIn(SingletonComponent::class)`
   - Предоставляет:
     - `@Provides @Singleton fun provideAppDatabase(@ApplicationContext context: Context): AppDatabase` (через фабрику SQLCipher с ключом из Keystore).
     - `@Provides @Singleton fun provideStorageGateway(db: AppDatabase): StorageGateway`.
     - `@Provides @Singleton fun provideWorkManager(@ApplicationContext context: Context): WorkManager`.
     - `@Provides @Singleton fun provideNotificationManagerCompat(@ApplicationContext context: Context): NotificationManagerCompat`.

**Критерий приёмки:**
- `.\gradlew.bat :app:compileDebugKotlin` завершается BUILD SUCCESSFUL.
