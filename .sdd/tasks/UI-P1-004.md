## Задача UI-P1-004: Обновить TimelineViewModel для объединения событий, транзакций и обратной связи

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/TimelineViewModel.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#5-timelineviewmodel-v2`  
**Контракт:** `.sdd/contracts/core-storage__ui.md`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.ui

import androidx.lifecycle.ViewModel
import com.example.npc.core.model.classify.Category
import com.example.npc.core.storage.StorageGateway
import com.example.npc.ui.timeline.mapper.EventUiMapper
import com.example.npc.ui.timeline.model.CategoryFilter
import com.example.npc.ui.timeline.model.TimelineUiState
import kotlinx.coroutines.flow.StateFlow

class TimelineViewModel(
    private val storage: StorageGateway,
    private val mapper: EventUiMapper
) : ViewModel() {
    val state: StateFlow<TimelineUiState>

    fun onCategoryFilterSelected(filter: CategoryFilter)
    fun onSearchQueryChanged(query: String)
    fun onUserCorrectionSubmitted(eventId: Long, newCategory: Category)
    fun onExportRequested()
    fun onDeleteAllRequested()
}
```

### Инварианты и алгоритм:
1. Реактивное объединение: `combine(storage.observeEvents(100), storage.observeTransactions(100), filterState)` сопоставляет финансовые транзакции с событиями по `eventId`.
2. Фильтрация по категории (`ALL`, `FINANCE`, `COMMUNICATION`, `MUSIC`, `SERVICES`, `ADVERTISEMENT`, `UNCLASSIFIED`) и поисковому запросу.
3. Метод `onUserCorrectionSubmitted`: запускает `viewModelScope.launch { storage.recordUserCorrection(eventId, newCategory) }`.
4. Экспорт и удаление через методы `storage.exportEventsJson()` и `storage.clearAllData()`.

### Критерии приемки (DoD):
- [ ] При обновлении транзакций или событий StateFlow немедленно эмитит обновленный список.
- [ ] Тесты покрывают фильтрацию, поиск и вызов `recordUserCorrection`.
