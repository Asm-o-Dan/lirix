## Задача APP-001: Каркас модуля :app, сборка и AndroidManifest

**Файлы:**
- `app/build.gradle.kts`
- `app/src/main/AndroidManifest.xml`
(создать / обновить)

**Спека:**
- `.sdd/specs/app-lifecycle/overview.md#архитектурное-окружение-и-структура-пакетов` (v1)
- `.sdd/specs/app-lifecycle/overview.md#манифест-приложения-androidmanifestxml` (v1)

**Зависит от:** `UI-004` (все предыдущие модули :core:*, :ingest:*, :ui:* готовы)

**Поведение:**
- В `app/build.gradle.kts`:
  - Применить плагины: `convention.android.application`, `convention.compose`, `hilt`.
  - `namespace = "com.example.npc.app"`
  - `applicationId = "com.example.npc"`
  - Зависимости:
    - `:core:model`, `:core:storage`, `:ingest:notification`, `:ingest:sms`, `:ingest:media`, `:ui:timeline`
    - Hilt (`hilt.android`, `hilt.compiler`, `androidx.hilt.work`, `androidx.hilt.navigation.compose`)
    - WorkManager (`androidx.work.runtime.ktx`)
    - Security / SQLCipher
    - Compose UI, Material 3, Navigation Compose
- В `AndroidManifest.xml`:
  - Разрешения:
    - `POST_NOTIFICATIONS`
    - `READ_SMS`, `RECEIVE_SMS`
    - `READ_CALENDAR`
    - `RECEIVE_BOOT_COMPLETED`
    - `FOREGROUND_SERVICE`
    - `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`
  - Регистрация `<application android:name=".App">`
  - Регистрация `MainActivity` с `intent-filter` (MAIN/LAUNCHER)
  - Регистрация `BootCompletedReceiver` с `BOOT_COMPLETED` и `MY_PACKAGE_REPLACED`
  - Отключение дефолтного `androidx.work.WorkManagerInitializer` для кастомного Hilt `Configuration.Provider`.

**Критерий приёмки:**
- `.\gradlew.bat :app:assembleDebug` компилирует скелет без ошибок.
