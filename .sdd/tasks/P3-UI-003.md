## Задача P3-UI-003: Реализовать живую валидацию, дифф конфликтов и превью регулярки

**Модуль:** `:feature:editor`, `:domain`  
**Целевые файлы:**  
- `feature/editor/src/main/kotlin/com/example/npc/feature/editor/vm/EditorViewModel.kt`  
- `feature/editor/src/main/kotlin/com/example/npc/feature/editor/ui/ValidationReportCard.kt`  
- `feature/editor/src/main/kotlin/com/example/npc/feature/editor/ui/ConflictDiffDialog.kt`  
**Спецификация:** `.sdd/architecture_phase3.md#61-one-tap-template-editor-human-in-the-loop`  

---

### Описание:
Реализовать реактивную валидацию черновика шаблона:
1. При изменении разметки токенов отправка `Intent.AssignTokenRole`.
2. Запуск цепочки через `debounce(150ms)` и `mapLatest`:
   - Синтез `TemplateSpec` через `TemplateInducer`.
   - Проверка компилятором `PipelineCompiler.compileTemplate()`.
   - Replay-тест на 500 исторических событиях.
3. Отображение отчета о валидации:
   - Статус готовности (зеленый бейдж «Готов к сохранению»).
   - Количество подходящих сообщений («Подходит к 37 из 41 уведомлений MAIB»).
   - Предупреждения о конфликтах («Перекроет статический экстрактор для 3 событий») с возможностью раскрыть дифф.
4. Раскрывающаяся панель «Показать сгенерированное регулярное выражение» для продвинутых пользователей.

### Критерии приёмки (DoD):
- Живая валидация не блокирует UI-поток (все вычисления на `Dispatchers.Default`).
- Кнопка «Сохранить» блокируется при наличии ошибок компиляции или негативных совпадений.
