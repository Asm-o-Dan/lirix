# TASK-CHR-02: Интерактивное транспонирование аккордов в реальном времени и регулятор масштаба текста

## 1. Контекст и цель
На вкладке «Аккорды» в `NowPlayingScreen` пользователи-музыканты (гитаристы, укулелисты) часто сталкиваются с необходимостью:
1. Сменить тональность песни под свой диапазон голоса (например, с неудобной тональности с баррэ `F#m` / `C#m` на более простые открытые аккорды `Em` / `Am`).
2. Быстро рассчитать положение каподастра (например, если песня записана в оригинале, а гитарист ставит каподастр на 2 лад, аккорды нужно транспонировать на -2 полутона).
3. Изменить масштаб шрифта (`A-` / `A+`), чтобы текст аккордов читался комфортно, когда телефон стоит на пюпитре или столе в полутора метрах от музыканта.

## 2. Архитектура и контракты

### 2.1 Движок `ChordTransposer.kt`
Чистый детерминированный объект с методами:
* `transposeNote(note: String, semitones: Int): String`
  - Хроматическая гамма: `C, C#, D, D#, E, F, F#, G, G#, A, A#, B`.
  - Поддержка бемолей (`Db, Eb, Gb, Ab, Bb`) и традиционного обозначения `H` (си).
* `transposeChord(chord: String, semitones: Int): String`
  - Распознавание тоники, суффикса (надстройки) и дробного баса (`root`, `suffix`, `bass`).
  - Пример: `Am/G` (+2) -> `Bm/A`.
  - Пример: `F#m7` (+1) -> `Gm7`.
  - Пример: `Bb` (+2) -> `C`.
* `transposeText(text: String, semitones: Int): String`
  - Распознает аккордовые токены в строке моноширинного текста аккордов и заменяет их транспонированными версиями, сохраняя пробельную структуру и окружающий текст.

### 2.2 UI в `NowPlayingScreen.kt`
1. Состояние транспонирования: `transposeSemitones: Int` (диапазон `[-11, +11]`, по умолчанию 0).
2. Состояние масштабирования: `chordTextZoom: Float` (пресеты / шаги 0.85x, 1.0x, 1.15x, 1.3x, 1.5x).
3. Компактная панель управления в шапке вкладки «Аккорды»:
   - Строка 1: Виджет автоскролла `[ ▶ / ⏸ ] [-] 1.00x [+] [ ⤾ ]`.
   - Строка 2: Виджет музыканта:
     * Кнопки `[ ♭ -1 ]` `[ Тон: 0 ]` `[ ♯ +1 ]` (тап по "Тон" сбрасывает в 0).
     * Кнопки зума `[ A- ]` `[ A+ ]`.
     * Если транспонирование активно (`transposeSemitones != 0`), подсказка: `Каподастр: N лад` при отрицательном сдвиге.

## 3. Критерии приемки (Definition of Done)
1. Unit-тесты покрывают все сценарии транспонирования мажоров, миноров, диезов, бемолей, септаккордов и дробных басов (`ChordTransposerTest`).
2. Обычный текст песен и слова не ломаются при обработке.
3. Мгновенный отклик Compose без зависаний UI при переключении полутонов.
4. Прогон всех 150+ тестов: GREEN.
