## Задача P3-UI-006: Реализовать графики динамики расходов на Canvas и список транзакций Paging 3

**Модуль:** `:feature:analytics`  
**Целевые файлы:**  
- `feature/analytics/src/main/kotlin/com/example/npc/feature/analytics/ui/AnalyticsTrendChart.kt`  
- `feature/analytics/src/main/kotlin/com/example/npc/feature/analytics/ui/PagedTransactionsList.kt`  
**Спецификация:** `.sdd/architecture_phase3.md#62-financial-analytics-ui`  

---

### Описание:
1. Легковесный график динамики трат на `Canvas`:
   - Отрисовка столбиков или плавной кривой тренда через `DrawScope`.
   - Исключение сторонних библиотек чартов (MPAndroidChart) для экономии памяти и 60 FPS на бюджетном GPU Poco M7.
2. Постраничный список транзакций под графиком:
   - Интеграция с AndroidX Paging 3 (`LazyPagingItems`).
   - Отображение статусов транзакций (`CONFIRMED`, `SUGGESTED`, бейдж `REFUND`).
   - Клик по строке транзакции открывает `EventDetailsDialog` с возможностью быстрого перехода в редактор шаблона.

### Критерии приёмки (DoD):
- Время отрисовки кадра графика $\le 16$ мс (без дропов кадров при скролле).
- Плавный скролл списка транзакций при 1000+ элементах в базе.
