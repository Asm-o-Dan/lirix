## Задача UI-P1-009: Интегрировать компоненты Timeline 2.0 в TimelineScreen

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/TimelineScreen.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#7-timelinescreen-v2`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.ui

import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier

@Composable
fun TimelineScreen(
    viewModel: TimelineViewModel,
    modifier: Modifier = Modifier
)
```

### Инварианты и алгоритм:
1. Интеграция верхнего бара поиска и экспорта.
2. Горизонтальная прокрутка чипов фильтрации по категориям (`CategoryFilterChips`).
3. Список событий `LazyColumn` со строками `TimelineItemRow`:
   - Включает `CategoryBadge` с возможностью клика.
   - Если у события есть финансовая транзакция — рендерит `TransactionCard`.
4. Управление состоянием модальных диалогов:
   - `CategoryCorrectionDialog` при клике на бейдж.
   - `EventDetailsDialog` при клике на строку события.
   - `DeleteConfirmationDialog` при запросе очистки данных.

### Критерии приемки (DoD):
- [ ] Полная сборка экрана Timeline 2.0 в Jetpack Compose.
- [ ] Интерактивное переключение категорий, открытие диалогов, плавная прокрутка списка.
- [ ] Compose UI тесты ключевых сценариев взаимодействия.
