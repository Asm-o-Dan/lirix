## Задача SPI-P2-010: Реализовать встроенные исполнители условий

**Модуль:** `:pipeline:nodes-builtin`  
**Целевые файлы:** `pipeline/nodes-builtin/src/main/kotlin/com/example/npc/pipeline/nodes/builtin/condition/`  
- `PackageMatchExecutor.kt`
- `TextRegexMatchExecutor.kt`
- `SenderMatchExecutor.kt`
- `CategoryMatchExecutor.kt`
- `PrototypeSupportCountExecutor.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#31-условия-conditions`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#3-контракты-исполнения-stepresult-nodeexecutor-effectbuffer`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.builtin.condition

import com.example.npc.pipeline.nodes.api.effect.EffectBuffer
import com.example.npc.pipeline.nodes.api.executor.NodeExecutor
import com.example.npc.pipeline.nodes.api.executor.StepResult
import com.example.npc.pipeline.nodes.api.frame.Frame
import com.google.re2j.Matcher

class PackageMatchExecutor(
    val inPackageSlot: Int,
    val allowedPackages: Array<String>,
    val matchMode: Int,
    val negate: Boolean,
    val thenPc: Int,
    val elsePc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class TextRegexMatchExecutor(
    val inTextSlot: Int,
    val scratchMatcherSlot: Int,
    val negate: Boolean,
    val thenPc: Int,
    val elsePc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class SenderMatchExecutor(
    val inSenderSlot: Int,
    val senders: Array<String>,
    val caseSensitive: Boolean,
    val negate: Boolean,
    val thenPc: Int,
    val elsePc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class CategoryMatchExecutor(
    val inCategoryOrdinalSlot: Int,
    val inConfidenceSlot: Int,
    val expectedCategoryOrdinal: Long,
    val minConfidence: Double,
    val thenPc: Int,
    val elsePc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class PrototypeSupportCountExecutor(
    val inFingerprintSlot: Int,
    val inPackageSlot: Int,
    val minSupportCount: Long,
    val outCategorySlot: Int,
    val outConfidenceSlot: Int,
    val thenPc: Int,
    val elsePc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}
```

### Поведение:
1. `PackageMatchExecutor`:
   - Считывает имя пакета из `frame.texts[inPackageSlot]`.
   - Посимвольно сопоставляет с `allowedPackages` без выделения строк в Heap.
   - Поддерживает режимы: `EXACT (0)`, `PREFIX (1)`, `CONTAINS (2)`.
   - Если условие выполнено (с учетом `negate`), возвращает `StepResult.jump(thenPc)`, иначе `StepResult.jump(elsePc)`.
2. `TextRegexMatchExecutor`:
   - Извлекает предвыделенный `com.google.re2j.Matcher` из `frame.refs[scratchMatcherSlot]`.
   - Вызывает `matcher.reset(frame.texts[inTextSlot])` (напрямую через `CharSequence` интерфейс `TextRegister`, 0 аллокаций).
   - Выполняет `matcher.find()`. Возвращает переход на `thenPc` или `elsePc`.
3. `SenderMatchExecutor`:
   - Сверяет отправителя из `frame.texts[inSenderSlot]` с доверенным списком банковских отправителей (`"APB"`, `"PRISBANK"`, `"MAIB"`, `"900"`).
   - При совпадении переходит на `thenPc`, иначе `elsePc`.
4. `CategoryMatchExecutor`:
   - Сравнивает ординал категории `frame.longs[inCategoryOrdinalSlot] == expectedCategoryOrdinal` и уверенность `frame.doubles[inConfidenceSlot] >= minConfidence`.
5. `PrototypeSupportCountExecutor`:
   - Считывает отпечаток из `frame.refs[inFingerprintSlot]` и проверяет по таблице прототипов хоста.
   - Если прототип найден и `supportCount >= minSupportCount`, записывает категорию в `frame.longs[outCategorySlot]`, уверенность `1.0` в `frame.doubles[outConfidenceSlot]` и переходит на `thenPc`.

### Ошибки:
- Если слот содержит пустой текст или `null`, предикат считается не сработавшим и безопасно возвращает переход на `elsePc` (Fail-safe, без исключений).

### Граничные случаи:
- Пустые списки `allowedPackages` или `senders`: немедленный переход на `elsePc`.
- `inTextSlot` с усеченным текстом (`isTruncated = true`): RE2/J ищет совпадение по фактически доступной длине `len`.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Использовать `java.util.regex.*` или `kotlin.text.Regex` (строго только RE2/J).
- Аллоцировать любые объекты в методе `execute()`.
