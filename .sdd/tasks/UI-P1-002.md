## Задача UI-P1-002: Обновить EventUiModel для Timeline 2.0

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/model/EventUiModel.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#33-eventuimodel-v2`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.model

import androidx.compose.runtime.Immutable
import com.example.npc.core.model.classify.Category
import com.example.npc.core.model.classify.Engine

@Immutable
data class EventUiModel(
    val id: Long,
    val rawId: Long,
    val formattedTime: String,
    val title: String,
    val text: String,
    val sourceName: String,
    val sourceIconRes: Int,
    val category: Category,
    val confidence: Double,
    val engine: Engine,
    val isUserCorrected: Boolean,
    val transaction: FinancialTransactionUiModel? = null
)
```

### Инварианты и алгоритм:
1. Сохраняет существующие поля Фазы 0 (`id`, `rawId`, `formattedTime`, `title`, `text`, `sourceName`, `sourceIconRes`).
2. Добавляет атрибуты семантики: `category`, `confidence`, `engine`, `isUserCorrected` и опциональную прикрепленную финансовую транзакцию `transaction`.
3. `@Immutable` обеспечивает стабильность Compose параметров.

### Критерии приемки (DoD):
- [ ] Существующий код экрана компилируется без поломок.
- [ ] Готово для отображения бейджей категорий и карточек транзакций.
