## 1. Цель задачи
Реализовать нижнюю панель транспорта суфлёра:
1. **Крупные контролы:**
   - Предыдущий трек ($36\times 36\,\text{dp}$), Play/Pause ($48\times 48\,\text{dp}$), Следующий трек ($36\times 36\,\text{dp}$).
   - Трекбар с индикатором прогресса и табличными цифрами текущего времени и длительности (`01:15 / 06:12`).
2. **Регулятор задержки караоке (Sync Offset):**
   - Блок управления: `Сдвиг текста −0,3 с [ − ] [ + ]` (с шагом $0.1\,\text{с}$).
   - Позволяет пользователю мгновенно скорректировать рассинхрон между аудиопотоком Windows GSMTC и отображаемым караоке.
   - Значение смещения сохраняется локально в настройках приложения.
3. **Честный VU-индикатор (WASAPI Loopback slot):**
   - Справа на панели резервируется компактный стерео-индикатор $L/R$ (шкала dBFS от -60 до 0).
   - Если служба WASAPI Loopback не передает данные, слот аккуратно схлопывается без артефактов.
