**Зависит от:** `UI-001`

**Поведение:**
- Создать неизменяемые DTO моделей UI:
  - `EventUiModel`: id, rawId, formattedTime, title, text, source, isUpdate, isUpdateOf, threadKey, packageName, payloadJson.
  - `SourceFilter`: enum (ALL, NOTIFICATION, SMS, MEDIA).
  - `SourceHealthStatus`: enum (HEALTHY, WARNING, CRITICAL, UNKNOWN).
  - `SourceHealthUiModel`: source, status, events24hText, lastEventText, queueDepth, lastErrorText.
  - `TimelineUiState`: events, sourceHealth, selectedFilter, searchQuery, isLoading, selectedEventForDetails, isDeleteConfirmationVisible, isExporting.
  - `TimelineUiEffect`: sealed interface (ShowSnackbar, ShareJsonExport).
- `EventUiMapper`:
  - `toUiModel(event: Event, rawEvent: RawEvent?): EventUiModel`
  - `toHealthUiModel(health: SourceHealth, now: Instant): SourceHealthUiModel`
  - Форматирование относительного и точного времени (`HH:mm:ss`, `dd.MM.yyyy`).

**Критерий приёмки:**
- Модели компилируются, чистые функции маппинга покрыты инвариантами.
