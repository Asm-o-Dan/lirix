## 2. Описание проблемы
В `GuitarChordDictionary.extractChordsFromText` использовалось регулярное выражение с хвостовой границей слова `\b`:
`\b([A-H][b#]?(?:m|maj7|...)?)\b`
1. Символ диеза `#` не является словесным символом (`\w`), поэтому граница слова `\b` срабатывала сразу после латинской буквы корня (`C`, `F`, `G`), отсекая диез. В результате `C#` превращался в `C` («просто До»), а `F#` — в `F`.
2. Поиск велся сплошным сканированием всего текста без проверки контекста строки, из-за чего английский артикль `a` / `A` из вокального текста добавлялся в ленту аппликатур как аккорд `A`.

## 3. Критерии приемки (DoD)
- [x] Аккорды с диезами (`C#`, `F#`, `A#m`, `G#`, `D#m`) сохраняют знак альтерации `#` в `extractChordsFromText`.
- [x] Текстовые строки вокала не добавляют изолированные английские буквы (`a`, `A`) в список аккордов.
- [x] Инлайн-аккорды в скобках (`[C#]`, `[F#m]`) корректно извлекаются.
- [x] Все unit-тесты в `GuitarChordDictionaryTest.kt` проходят успешно.
- [x] Визуальная верификация на устройстве в приложении.
