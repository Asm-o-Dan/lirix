## Задача P3-UI-004: Реализовать сохранение, Undo и интеграцию с EventDetailsDialog

**Модуль:** `:feature:editor`, `:ui:timeline`  
**Целевые файлы:**  
- `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/components/EventDetailsDialog.kt`

**Спецификация:** `.sdd/architecture_phase3.md#61-one-tap-template-editor-human-in-the-loop`  

---

### Описание:
Замкнуть цикл Human-in-the-Loop для быстрого создания шаблона:
1. Встроить кнопку «Создать шаблон» / «Изменить шаблон» в карточку события `EventDetailsDialog`.
2. Автоматическое предзаполнение токенов на базе результатов `UniversalExtractor` (при открытии диалога слоты уже предразмечены).
3. По нажатию **«Сохранить и активировать»**:
   - Активация шаблона в `TemplateBankManager`.
   - Закрытие шторки редактора.
   - Показ Snackbar с кнопкой **«Отменить (Undo)»** (активна в течение 8 секунд) и предложением: «Применить к 37 прошлым событиям?».
4. Интеграционный сквозной сценарий: «Инцидент TEMU -> 1 тап на создание шаблона -> 1 тап на сохранение -> возврат отображается в финансах».

### Критерии приёмки (DoD):
- Сквозной UI-тест полного сценария (EventDetails -> Editor -> Save -> Verification).
- Функция Undo мгновенно отключает сохраненный шаблон.
