## 1. Цель задачи
Реализовать компонент суфлёрского монитора текста:
1. **Геометрия и выравнивание:**
   - Выравнивание лирики по левому краю (книжный рваный правый край).
   - Максимальная ширина текстовой колонки: $640\,\text{dp}$.
   - Активная строка фиксируется на $40\%$ высоты вьюпорта с пружинным плавным автоскроллом.
2. **Маркер «Звучит сейчас»:**
   - Вертикальная планка шириной $3\,\text{dp}$ цвета `Accent` слева от активной строки (скругление 1.5 dp).
   - Это единственный контрастный маркер состояния строки.
3. **Стабильный интерактивный слот (Zero Layout Shift):**
   - Слева от каждой строки зарезервирован фиксированный невидимый слот шириной $44\,\text{dp}$.
   - При наведении курсора мыши на строку в слоте плавно проявляется кнопка перемотки `▶ 1:15`.
   - Текст строки при этом не сдвигается ни на один пиксель.
   - Клик по кнопке или строке вызывает `onSeekRequested(timestampMs)`.

---

## 2. Критерии приемки (DoD)
- [ ] При воспроизведении активная строка удерживается на отметке 40% высоты окна.
- [ ] Появление кнопки `[▶]` при ховере не вызывает скачков верстки текста.
- [ ] Клик по строке перематывает трек в активном плеере.
