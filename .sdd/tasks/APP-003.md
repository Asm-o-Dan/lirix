## Задача APP-003: BootCompletedReceiver и AbsenceAlertWorker (DoD критерий 9)

**Файлы:**
- `app/src/main/kotlin/com/example/npc/app/receiver/BootCompletedReceiver.kt`
- `app/src/main/kotlin/com/example/npc/app/worker/AbsenceAlertWorker.kt`
- `app/src/main/kotlin/com/example/npc/app/worker/AbsenceAlertScheduler.kt`
- `app/src/main/kotlin/com/example/npc/app/worker/AbsenceAlertConfig.kt`
(создать)

**Спека:**
- `.sdd/specs/app-lifecycle/overview.md#обработчик-системной-загрузки-bootcompletedreceiver` (v1)
- `.sdd/specs/app-lifecycle/overview.md#детектор-длительного-отсутствия-событий-absencealertworker-dod-критерий-9` (v1)

**Зависит от:** `APP-002`

**Поведение:**
1. `BootCompletedReceiver.kt`:
   - Наследник `BroadcastReceiver`, `@AndroidEntryPoint`.
   - При получении `ACTION_BOOT_COMPLETED` или `ACTION_MY_PACKAGE_REPLACED`:
     - Ре-шедулинг WorkManager задач (`NotificationWatchdogScheduler`, `AbsenceAlertScheduler`).
2. `AbsenceAlertConfig.kt`:
   - `thresholdHours: Long = 6L` (порог отсутствия событий в часах).
   - `checkIntervalMinutes: Long = 30L`.
   - `suppressAlertWindowHours: Long = 4L`.
3. `AbsenceAlertWorker.kt`:
   - `@HiltWorker class AbsenceAlertWorker @AssistedInject constructor(...) : CoroutineWorker(context, params)`
   - Запрашивает через `StorageGateway.observeSourceHealth()` / базу данных время последнего события (`lastEventAt`) по всем источникам.
   - Если с момента последнего события прошло больше `thresholdHours` (или ни одного события не зафиксировано за `thresholdHours`):
     - Посылает системное уведомление в канал `"npc_alerts"`: "Внимание: нет новых событий более N часов! Проверьте разрешения автозапуска и листенера."
   - Если события есть (прошло < thresholdHours):
     - Отменяет активное уведомление (cancel).
4. `AbsenceAlertScheduler.kt`:
   - Метод `scheduleAbsenceCheck(context: Context)`:
     - `PeriodicWorkRequestBuilder<AbsenceAlertWorker>(30, TimeUnit.MINUTES)`
     - `ExistingPeriodicWorkPolicy.KEEP`
     - Имя воркера: `"npc_absence_alert_worker"`.

**Критерий приёмки:**
- Воркер и ресивер компилируются, покрыты юнит-тестами логики расчета интервала.
