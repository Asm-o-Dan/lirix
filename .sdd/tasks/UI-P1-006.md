## Задача UI-P1-006: Создать Compose-компонент TransactionCard

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/components/TransactionCard.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#62-transactioncard`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.ui.components

import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import com.example.npc.ui.timeline.model.FinancialTransactionUiModel

@Composable
fun TransactionCard(
    transaction: FinancialTransactionUiModel,
    modifier: Modifier = Modifier
)
```

### Инварианты и алгоритм:
1. Выделенный карточный блок внутри финансового элемента списка.
2. Отображение крупной форматированной суммы:
   - Если `transaction.isDeclined` $\to$ красный бейдж «ОТКАЗ / DECLINED», зачеркнутая сумма.
   - Списание (`DEBIT`) $\to$ красный/оранжевый цвет (`-150.00 RUP`).
   - Пополнение (`CREDIT`) $\to$ ярко-зеленый цвет (`+500.00 MDL`).
   - Перевод (`TRANSFER`) $\to$ нейтральный синий.
3. Дополнительные атрибуты: имя мерчанта/контрагента, банк ("APB", "MAIB"), маска карты (`*1234`), остаток баланса (если есть).

### Критерии приемки (DoD):
- [ ] Отрисовка успешных и отклоненных транзакций в Compose Preview.
- [ ] Четкая индикация валюты (RUP, MDL, RUB, EUR, USD).
