# TASK-UI-MOB-FIX-01: Данные и честность (Unknown Artist, время суток Wrapped, имена приложений Blacklist)

## 1. Контекст и Проблематика
По результатам визуального аудита мобильных экранов выявлены расхождения в достоверности данных:
1. **«Unknown Artist» в Топ-артистах Wrapped**: техническая заглушка учитывается как реальный исполнитель и попадает в рейтинг.
2. **Шаблонный текст во Wrapped**: фраза «Музыка становилась вашим вечерним ритуалом для отдыха и перезагрузки» звучит как шаблонная выдумка. Текст должен строго зависеть от реальных данных (например, «Чаще всего вы слушали музыку вечером (65% времени)»).
3. **Отображение правил в Чёрном списке**: `packageName` («opera») отображается как сырой id вместо человеческого имени («Opera») через `packageManager.getApplicationLabel`. Тип правила «Подстрока» является программистским жаргоном (требуется «Приложение: Opera», «Название содержит...», «Исполнитель содержит...»). Описание процесса («сканирование аудиопотока») некорректно — фильтруются медиасессии.

## 3. Критерии приёмки (DoD)
1. **Исключение заглушек из Wrapped**:
   - Фильтровать `artist` при расчёте топ-артистов: исключать строки, совпадающие (case-insensitive) с `Unknown Artist`, `Unknown`, `<unknown>`, `Неизвестный исполнитель`, пустые строки или пробелы.
2. **Честное описание времени суток**:
   - Во `WrappedStatsEngine` вычислять реальную процентную долю времени суток (утро, день, вечер, ночь).
   - Выводить текст строго по факту:
     - При выраженном пике (>50%): *«Чаще всего вы слушали музыку вечером (65% времени)»*.
     - При равномерном распределении: *«Вы слушали музыку равномерно в течение дня»*.
3. **Человеческие имена в Чёрном списке**:
   - Для правил типа `PACKAGE_NAME`: запрашивать `context.packageManager.getApplicationLabel(...)` в блоке `try-catch`. Отображать: `Приложение: Opera` (с иконкой приложения, если доступна).
   - Для правил типа `TITLE`: отображать `Название содержит: ...`
   - Для правил типа `ARTIST`: отображать `Исполнитель содержит: ...`
   - Исправить описание экрана/подсказки: «Блокировка сохранения треков из выбранных приложений и по ключевым словам в медиасессиях».
4. **Тесты**:
