## Задача P3-UNI-008: Реализовать учет провенанса и сбор метрики financeWithoutPayload

**Модуль:** `:extract:universal`, `:core:storage`  
**Целевые файлы:**  
- `core/model/src/main/kotlin/com/example/npc/core/model/finance/ExtractorKind.kt`  
- `core/storage/src/main/kotlin/com/example/npc/core/storage/entity/ExtractionFeedbackEntity.kt`  
- `core/storage/src/main/kotlin/com/example/npc/core/storage/dao/ExtractionFeedbackDao.kt`  
**Спецификация:** `.sdd/architecture_phase3.md#31-схема-room-v3--v4-миграция-аддитивная`  

---

### Описание:
1. Ввести перечисление провенанса транзакций:
   ```kotlin
   enum class ExtractorKind { STATIC, TEMPLATE, UNIVERSAL, MANUAL }
   enum class TxStatus { CONFIRMED_AUTO, SUGGESTED, USER_CONFIRMED, USER_EDITED }
   ```
2. Реализовать регистрацию обратной связи `ExtractionFeedbackEntity`:
   - Сохранение вектора признаков `features` и результата для последующей калибровки весов.
3. Отслеживание аномалий: инкремент счетчика `financeWithoutPayload` в случаях, когда классификатор определил категорию `FINANCE` с высокой вероятностью ($\ge 0.85$), но ни один экстрактор (статический, динамический, универсальный) не смог извлечь финансовую информацию.

### Критерии приёмки (DoD):
- Полнота провенанса в `FinancialTransaction`: источник происхождения фиксируется для 100% создаваемых записей.
- Счетчик `financeWithoutPayload` доступен через `OrchestratorProbe` для экрана диагностики.
