# TASK-CON-UI-08: Popover и диалог Lirix Connect (Desktop Compose)

## 1. Контекст и Цель
Реализовать пользовательский интерфейс подключения устройств (Lirix Connect) в десктопном приложении (`:desktop`) по стандарту **SPEC-CONNECT-01 (§5.2, §5.3)**:
1. Кнопка `Icons.Default.DevicesOther` в панели `DesktopTopBar.kt` со статусом активного соединения (бейдж или подсветка акцентом).
2. Диалоговое окно / Popover `DesktopConnectDialog`:
   - Блок «ТЕКУЩЕЕ УСТРОЙСТВО»: «● Этот компьютер (Windows)» со слайдером громкости.
   - Блок «ДОСТУПНЫЕ УСТРОЙСТВА В СЕТИ»: карточки сопряжённых устройств (`TrustedDeviceStore`) со статусом («В сети» / «Офлайн / Был 10 мин назад»), кнопкой передачи трека (Handoff) и выпадающим меню «⋮» («Переименовать», «Забыть устройство»).
   - Блок «ПОДКЛЮЧИТЬ УСТРОЙСТВО (QR-код)»:
     - Генерация QR-кода на базе `PairingSecurityManager.generatePairingPayload` и формата `lirix://pair?d=<base64url>`.
     - Таймер обратного отсчёта TTL (120 с). По истечении таймера — полупрозрачный оверлей с кнопкой «Обновить код».
     - Кнопка «Скопировать код текстом» с предупреждением о безопасности.
   - Диалог подтверждения входящего запроса: «Добавить устройство <Name>?» с 6-значным кодом сверки и кнопками «Подтвердить» / «Отклонить».

## 3. Критерии приёмки (DoD)
1. **Интеграция в TopBar**: кнопка `DevicesOther` аккуратно вписана в верхнюю панель Desktop Studio Deck с сохранением 48dp кликабельности и подсказки Tooltip («Воспроизвести на устройстве»).
2. **Отображение устройств**: список доверенных устройств отображается корректно, при нажатии на устройство инициируется callback передачи управления.
3. **QR-генератор и TTL**: QR-код отображается размером не менее 200x200 dp, таймер 120 с тикает каждую секунду и корректно инвалидирует код по истечении.
4. **Типографика и стиль**: полное соответствие дизайну Studio Deck (тёмная палитра, шрифт Golos UI для интерфейса, отсутствие эмодзи, векторные иконки Material Icons).
5. **Компиляция**: успешная сборка без ошибок через `./gradlew.bat :desktop:compileKotlin`.
