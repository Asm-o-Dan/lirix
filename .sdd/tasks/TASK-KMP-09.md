## 1. Цель задачи
Декомпозировать монолитный `NowPlayingScreen` на независимые атомарные Compose Multiplatform компоненты:
1. Выделить изолированную панель караоке `LyricsScrollPanel` с плавной прокруткой активной строки.
2. Выделить компонент аккордов с контролами тональности и скорости автоскролла.
3. Выделить панель управления воспроизведением с изоляцией рекомпозиций таймера (чтобы секундный тик не перерисовывал весь экран).
4. Все компоненты должны работать как на Android, так и на Desktop.

---

## 2. Критерии приемки (DoD)
- [ ] Компоненты скомпилированы в `:shared/commonMain`.
- [ ] Тикающий таймер воспроизведения вызывает рекомпозицию только таймлайна, а не списка текста.
- [ ] Android `NowPlayingScreen` переиспользует эти компоненты без потери плавности.
