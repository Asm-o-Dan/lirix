## Задача SPI-P2-006: Реализовать рабочий контекст Frame

**Модуль:** `:pipeline:nodes-api`  
**Целевой файл:** `pipeline/nodes-api/src/main/kotlin/com/example/npc/pipeline/nodes/api/frame/Frame.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#212-описание-емкости-framelayout-и-рабочий-контекст-frame`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#2-регистровая-модель-памяти-bank-textregister-framelayout-frame`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.api.frame

import com.example.npc.pipeline.nodes.api.effect.EffectBuffer

/**
 * Рабочий контекст потока исполнения.
 * Поля представляют собой открытые (@JvmField) массивы для мономорфного доступа JIT.
 */
class Frame(val layout: FrameLayout) {
    @JvmField val longs: LongArray = LongArray(layout.longSlots)
    @JvmField val doubles: DoubleArray = DoubleArray(layout.doubleSlots)
    @JvmField val refs: Array<Any?> = arrayOfNulls(layout.refSlots)
    @JvmField val texts: Array<TextRegister> = Array(layout.textSlots) { TextRegister(layout.textCapacity) }

    @JvmField val effects: EffectBuffer = EffectBuffer(maxEffects = 32, maxArgs = 64, maxChars = 2048)
    @JvmField var stepBudget: Int = 1000

    fun resetRefs() {
        java.util.Arrays.fill(refs, null)
        for (i in texts.indices) {
            texts[i].clear()
        }
        effects.reset()
        stepBudget = 1000
    }
}
```

### Поведение:
1. Выделяет предвыделенные массивы строго по размерам, заданным в `layout`:
   - `longs`: массив 64-битных целых примитивов.
   - `doubles`: массив 64-битных вещественных примитивов.
   - `refs`: массив ссылок на внешние DTO хоста и scratch-объекты.
   - `texts`: массив предвыделенных безаллокационных текстовых регистров `TextRegister`.
2. Содержит встроенный `effects: EffectBuffer` емкостью 32 эффекта и аппаратный счетчик шагов `stepBudget = 1000` для защиты от бесконечных петель (Anti-loop protection).
3. `resetRefs()`:
   - Обнуляет все ссылки в массиве `refs` значением `null` (гарантия отсутствия утечек памяти между событиями).
   - Очищает все `texts[i].clear()`.
   - Вызывает `effects.reset()`.
   - Восстанавливает `stepBudget = 1000`.
   - Массивы `longs` и `doubles` очищать не требуется: статический компилятор доказывает Definite Assignment перед каждым чтением слота.

### Ошибки:
- При попытке передачи `null` в конструктор `Frame(layout)` выбрасывать `NullPointerException`.

### Граничные случаи:
- `FrameLayout` с нулевым числом слотов: массивы инициализируются нулевой длины, `resetRefs()` выполняется без ошибок.
- Повторные вызовы `resetRefs()` идемпотентны.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Добавлять геттеры/сеттеры взамен открытых `@JvmField` полей (мономорфный JIT-доступ критичен для Hot Path).
- Аллоцировать новые массивы внутри `resetRefs()`.
