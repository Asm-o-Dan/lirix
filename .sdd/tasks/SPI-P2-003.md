## Задача SPI-P2-003: Реализовать FrameLayout

**Модуль:** `:pipeline:nodes-api`  
**Целевой файл:** `pipeline/nodes-api/src/main/kotlin/com/example/npc/pipeline/nodes/api/frame/FrameLayout.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#212-описание-емкости-framelayout-и-рабочий-контекст-frame`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#2-регистровая-модель-памяти-bank-textregister-framelayout-frame`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.api.frame

/**
 * Топология регистровой памяти, вычисленная компилятором для скомпилированного конвейера.
 */
class FrameLayout(
    val longSlots: Int,
    val doubleSlots: Int,
    val refSlots: Int,
    val textSlots: Int,
    val textCapacity: Int = 1024,
    val requiredInputMask: Long = 0L
) {
    init {
        require(longSlots >= 0) { "longSlots must be non-negative: $longSlots" }
        require(doubleSlots >= 0) { "doubleSlots must be non-negative: $doubleSlots" }
        require(refSlots >= 0) { "refSlots must be non-negative: $refSlots" }
        require(textSlots >= 0) { "textSlots must be non-negative: $textSlots" }
        require(textCapacity > 0) { "textCapacity must be positive: $textCapacity" }
    }

    companion object {
        const val MASK_INPUT_TITLE: Long = 1L shl 0
        const val MASK_INPUT_TEXT: Long = 1L shl 1
        const val MASK_INPUT_SENDER: Long = 1L shl 2
        const val MASK_INPUT_POST_TIME: Long = 1L shl 3
        const val MASK_INPUT_PACKAGE: Long = 1L shl 4
        const val MASK_INPUT_CHANNEL_ID: Long = 1L shl 5
    }
}
```

### Поведение:
1. Хранит точные статические размеры банков памяти, необходимые конвейеру: количество слотов `longSlots`, `doubleSlots`, `refSlots`, `textSlots` и емкость текстовых регистров `textCapacity`.
2. Содержит битовую маску `requiredInputMask`, указывающую сборщику событий (`NotificationListenerService` / Ingest), какие конкретно поля Android Notification Bundle необходимо считывать и парсить (Title, Text, Sender, PostTime, Package, ChannelId).
3. Используется фабрикой `Frame(layout)` для инициализации плоских массивов фиксированной длины.

### Ошибки:
- При отрицательных значениях количества слотов (`< 0`) выбрасывать `IllegalArgumentException`.
- При неположительной емкости текстового регистра (`textCapacity <= 0`) выбрасывать `IllegalArgumentException`.

### Граничные случаи:
- Конвейер без слотов (`longSlots = 0, doubleSlots = 0, refSlots = 0, textSlots = 0`): валидно.
- `requiredInputMask = 0L`: конвейер не читает ни одного входного поля уведомления.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Добавлять изменяемые (`var`) свойства.
- Использовать динамические коллекции (`List`, `Map`) для хранения топологии слотов.
