## 1. Цель задачи
Редизайн медиатеки с безопасными и доступными жестами:
1. **Разделение системной зоны «Назад» и `scaledTouchSlop`:**
   - **Запрет `systemGestureExclusion` на списке:** приложение не должно захватывать системную кромку экрана (24–30 dp).
   - Любое касание, начинающееся внутри зоны системного жеста «Назад» (0..28 dp от края), беспрепятственно отдается системе Android.
   - Свайп вправо по карточке регистрируется только при старте за пределами системной зоны (> 28 dp), а порогом распознавания сдвига служит системный `ViewConfiguration.get(context).scaledTouchSlop` (~8 dp).
2. **Доступные альтернативы свайпам (TalkBack и контекстное меню):**
   - Для пользователей с моторными ограничениями, TalkBack и тех, кто не пользуется свайпами, реализуется второй путь:
     * **Долгое нажатие на строку трека** открывает меню действий (Bottom Sheet): `[ ★ В избранное ]`, `[ 🚫 Скрыть из медиатеки ]`.
     * **Семантические действия TalkBack:** добавляются `customActions` («Добавить в избранное», «Скрыть трек»).
3. **Единый адаптивный таймаут Snackbar:**
   - Таймаут рассчитывается через `AccessibilityManager.getRecommendedTimeoutMillis(6000, AccessibilityManager.FLAG_CONTENT_CONTROLS)` с базовым значением **6–8 секунд** (вместо произвольных 4 с).
4. **Стабильный цвет акцента:**
   - Использование фиксированного `AccentFallback` (`#7FA6F0` в тёмной / `#29549E` в светлой теме).

---

## 2. Критерии приемки (DoD)
- [ ] Касание у самой кромки экрана выполняет системный Back, свайп по телу карточки помечает трек как избранный.
- [ ] По долгому нажатию на трек открывается Bottom Sheet с действиями.
- [ ] В TalkBack доступны действия добавления в избранное и скрытия без свайпа.
- [ ] Кнопка «Отменить» в Snackbar доступна не менее 6–8 секунд (с учетом настроек доступности системы).
