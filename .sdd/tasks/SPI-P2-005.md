## Задача SPI-P2-005: Реализовать EffectBuffer

**Модуль:** `:pipeline:nodes-api`  
**Целевой файл:** `pipeline/nodes-api/src/main/kotlin/com/example/npc/pipeline/nodes/api/effect/EffectBuffer.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#24-буфер-отложенных-эффектов-effectbuffer`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#31-буфер-эффектов-effectbuffer-soa`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.api.effect

import com.example.npc.pipeline.nodes.api.frame.TextRegister

/**
 * Высокопроизводительный Struct-of-Arrays (SoA) буфер отложенных эффектов на плоских массивах.
 * Поддерживает транзакционность через [mark] и [rollback] для изоляции сбоев узлов.
 */
class EffectBuffer(
    val maxEffects: Int = 32,
    val maxArgs: Int = 64,
    val maxChars: Int = 2048
) {
    @JvmField internal val kindCodes: IntArray = IntArray(maxEffects)
    @JvmField internal val originPcs: IntArray = IntArray(maxEffects)
    @JvmField internal val argStarts: IntArray = IntArray(maxEffects + 1)
    @JvmField internal val longArgs: LongArray = LongArray(maxArgs)
    @JvmField internal val refArgs: Array<Any?> = arrayOfNulls(maxArgs)
    @JvmField internal val charBuffer: CharArray = CharArray(maxChars)

    @JvmField var effectCount: Int = 0
    @JvmField var argCount: Int = 0
    @JvmField var charCount: Int = 0

    @JvmField var currentPc: Int = 0
    @JvmField var allowMask: Long = -1L

    fun begin(kindCode: Int): Boolean
    fun putLong(value: Long): Boolean
    fun putRef(value: Any?): Boolean
    fun putText(text: TextRegister): Boolean
    fun end()

    fun mark(): Int = effectCount
    fun rollback(mark: Int)
    fun reset()
    fun view(): EffectView = EffectView(this)
}

class EffectView internal constructor(private val buf: EffectBuffer) {
    val size: Int get() = buf.effectCount
    fun getKind(index: Int): Int = buf.kindCodes[index]
    fun getOriginPc(index: Int): Int = buf.originPcs[index]
    fun getLongArg(effectIndex: Int, argOffset: Int): Long
    fun getRefArg(effectIndex: Int, argOffset: Int): Any?
    fun getTextArg(effectIndex: Int, argOffset: Int): String
}
```

### Поведение:
1. `begin(kindCode)`:
   - Проверяет маску разрешений: `(allowMask and (1L shl kindCode)) != 0L`. Если эффект не разрешен у узла $\to$ возвращает `false`.
   - Проверяет переполнение `effectCount < maxEffects`. Если нет места $\to$ возвращает `false`.
   - Записывает `kindCodes[effectCount] = kindCode`, `originPcs[effectCount] = currentPc`, `argStarts[effectCount] = argCount`.
   - Возвращает `true`.
2. `putLong(value)`: если `argCount < maxArgs`, записывает `longArgs[argCount++] = value` и возвращает `true`, иначе `false`.
3. `putRef(value)`: если `argCount < maxArgs`, записывает `refArgs[argCount++] = value` и возвращает `true`, иначе `false`.
4. `putText(text)`:
   - Копирует символы `text.chars` (до `text.len`) в `charBuffer` начиная с `charCount`.
   - Упаковывает смещение и длину в `longArgs[argCount++]`: `(offset.toLong() shl 32) or (len.toLong() and 0xFFFF_FFFFL)`.
   - Инкрементирует `charCount += len`. Возвращает `true` или `false` при нехватке места.
5. `end()`: фиксирует завершение записи эффекта: инкрементирует `effectCount++` и обновляет `argStarts[effectCount] = argCount`.
6. `mark()`: возвращает текущий `effectCount` как контрольную точку отката (Savepoint).
7. `rollback(mark)`: если `mark` валиден (`0 <= mark <= effectCount`):
   - Очищает `refArgs` от `argStarts[mark]` до `argCount` значением `null` (предотвращение утечек памяти).
   - Сбрасывает `argCount = argStarts[mark]`.
   - Сбрасывает `effectCount = mark`.
8. `reset()`: сбрасывает все счетчики в `0`, заполняет `refArgs` `null`-ами до `argCount`, сбрасывает `argStarts[0] = 0`.
9. `view()`: предоставляет безопасный итератор `EffectView` для чтения параметров эффектов на фазе коммита.

### Ошибки:
- При передаче некорректного `mark < 0` или `mark > effectCount` в `rollback()` метод безопасно игнорирует операцию (no-op).
- При выходе индекса за границы `[0, size - 1]` в `EffectView` выбрасывать `IndexOutOfBoundsException`.

### Граничные случаи:
- Добавление эффектов с 0 аргументов: валидно (`argStarts[i+1] == argStarts[i]`).
- Откат к `mark = 0`: полный сброс добавленных эффектов до начального состояния.
- Переполнение `maxEffects` или `maxArgs`: `begin()` и `put*()` возвращают `false`, предотвращая крах JVM.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Аллоцировать память внутри `begin`, `putLong`, `putRef`, `putText`, `end`, `mark`, `rollback`, `reset`.
- Использовать `ArrayList` или динамические коллекции вместо предвыделенных массивов.
