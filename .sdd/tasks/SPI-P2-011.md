## Задача SPI-P2-011: Реализовать встроенные исполнители трансформаций

**Модуль:** `:pipeline:nodes-builtin`  
**Целевые файлы:** `pipeline/nodes-builtin/src/main/kotlin/com/example/npc/pipeline/nodes/builtin/transform/`  
- `RegionalTextSanitizerExecutor.kt`
- `AmountParserExecutor.kt`
- `BankCurrencyResolverExecutor.kt`
- `FinanceExtractorExecutor.kt`
- `FingerprinterExecutor.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#32-трансформации-transforms`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#3-контракты-исполнения-stepresult-nodeexecutor-effectbuffer`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.builtin.transform

import com.example.npc.pipeline.nodes.api.effect.EffectBuffer
import com.example.npc.pipeline.nodes.api.executor.NodeExecutor
import com.example.npc.pipeline.nodes.api.executor.StepResult
import com.example.npc.pipeline.nodes.api.frame.Frame

class RegionalTextSanitizerExecutor(
    val inTextSlot: Int,
    val outTextSlot: Int,
    val maxChars: Int = 1024,
    val normalizeNbsp: Boolean = true,
    val nextPc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class AmountParserExecutor(
    val inTextSlot: Int,
    val outAmountMinorSlot: Int,
    val outFoundSlot: Int,
    val nextPc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class BankCurrencyResolverExecutor(
    val inTextSlot: Int,
    val inPackageSlot: Int,
    val defaultCurrencyOrdinal: Long,
    val outCurrencyOrdinalSlot: Int,
    val nextPc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class FinanceExtractorExecutor(
    val inTextSlot: Int,
    val inPackageSlot: Int,
    val inSenderSlot: Int,
    val outTxRefSlot: Int,
    val outSuccessSlot: Int,
    val timeoutMs: Long = 50L,
    val nextPc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}

class FingerprinterExecutor(
    val inTextSlot: Int,
    val scratchDigestSlot: Int,
    val outFingerprintSlot: Int,
    val nextPc: Int
) : NodeExecutor {
    override fun execute(frame: Frame, buffer: EffectBuffer): StepResult
}
```

### Поведение:
1. `RegionalTextSanitizerExecutor`:
   - Считывает текст из `frame.texts[inTextSlot]`.
   - Заменяет NBSP (`\u00A0`), Narrow NBSP (`\u202F`), Zero-width space (`\u200B`) на стандартный пробел `0x20`.
   - Удаляет нулевые байты `\u0000`.
   - Записывает результат в `frame.texts[outTextSlot]` с усечением до `maxChars`. Возвращает `StepResult.NEXT` (или `jump(nextPc)`).
2. `AmountParserExecutor`:
   - Выполняет посимвольный $O(n)$ парсинг числовой суммы без использования regex и вещественных типов.
   - Записывает целочисленные копейки/центы в `frame.longs[outAmountMinorSlot]`.
   - Если сумма найдена, выставляет `frame.longs[outFoundSlot] = 1L`, иначе `0L`.
3. `BankCurrencyResolverExecutor`:
   - Контекстный резолвинг валюты: если пакет `com.apb.mobile` или `com.prisbank.app`, токены `"руб."`, `"р."`, `"R"` однозначно преобразуются в ординал `CurrencyCode.RUP` (изоляция от `RUB`!).
   - Для `md.maib.maibank` токены резолвятся в `MDL`, `EUR`, `USD`.
   - Записывает ординал валюты в `frame.longs[outCurrencyOrdinalSlot]`.
4. `FinanceExtractorExecutor`:
   - В защищенной песочнице с замером наносекунд запускает специализированный банковский экстрактор (APB, MAIB, Prisbank, BankSMS).
   - При успешном извлечении записывает ссылку на DTO транзакции в `frame.refs[outTxRefSlot]`, выставляет `outSuccessSlot = 1L`.
   - При превышении таймаута `timeoutMs` (50 мс) или ошибке парсинга фиксирует сбой в метриках, выставляет `outSuccessSlot = 0L` и `outTxRefSlot = null`.
5. `FingerprinterExecutor`:
   - Алгоритм $O(n)$ заменяет цифры на `#`, даты на `<DATE>` и вычисляет SHA-256 хеш шаблона через переиспользуемый в scratch `MessageDigest.reset()`.
   - Записывает строку хеша в `frame.refs[outFingerprintSlot]`.

### Ошибки:
- При сбоях парсинга экстракторы не выбрасывают исключений наружу, а выставляют флаги неуспеха (`outSuccess = 0L`, `outFound = 0L`).
- При фатальном сбое JVM (OOM) исключение пробрасывается рантайму.

### Граничные случаи:
- Текст без сумм (`"Погода +10°C"`): `AmountParser` выставляет `outFound = 0L`, `outAmountMinor = 0L`.
- Текст длиной более 1024 символов: обрезается санитайзером с установкой `isTruncated = true`.
- Неизвестный банк/пакет: `BankCurrencyResolver` возвращает `defaultCurrencyOrdinal`.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Использовать числа с плавающей точкой (`Float`, `Double`) для денежных сумм.
- Аллоцировать строковые объекты внутри циклов парсинга.
