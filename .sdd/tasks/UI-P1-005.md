## Задача UI-P1-005: Создать Compose-компонент CategoryBadge

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/components/CategoryBadge.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#61-categorybadge`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.ui.components

import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import com.example.npc.core.model.classify.Category
import com.example.npc.core.model.classify.Engine

@Composable
fun CategoryBadge(
    category: Category,
    engine: Engine,
    confidence: Double,
    isUserCorrected: Boolean,
    onClick: () -> Unit,
    modifier: Modifier = Modifier
)
```

### Инварианты и алгоритм:
1. Цветовая дифференциация категорий:
   - `FINANCE` — изумрудно-зеленый (Emerald).
   - `COMMUNICATION` — лазурно-синий (Azure).
   - `MUSIC` — фиолетовый (Purple).
   - `SERVICES` — янтарно-оранжевый (Amber).
   - `ADVERTISEMENT` — приглушенный серый/красный (Slate/Crimson).
   - `UNCLASSIFIED` — нейтральный серый.
2. Иконка движка классификации:
   - `Engine.PROTOTYPE` $\to$ маркер "Шаблон" / бейдж доверия.
   - `Engine.USER` $\to$ маркер "Ручная правка" (иконка пользователя).
   - `Engine.RULES` $\to$ маркер "Правило".
3. Кликабельность: по клику вызывает `onClick()`, открывая `CategoryCorrectionDialog`.

### Критерии приемки (DoD):
- [ ] Компонент рендерится в Compose Preview.
- [ ] Доступен клик для вызова диалога коррекции.
