## Задача UI-P1-001: Реализовать UI-модели финансовых транзакций

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/model/FinancialTransactionUiModel.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#31-transactionstatusui-и-32-financialtransactionuimodel`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.model

import androidx.compose.runtime.Immutable
import com.example.npc.core.model.finance.Direction

enum class TransactionStatusUi {
    COMPLETED,
    DECLINED
}

@Immutable
data class FinancialTransactionUiModel(
    val id: Long,
    val bank: String,
    val direction: Direction,
    val formattedAmount: String,
    val formattedBalance: String?,
    val merchant: String?,
    val accountMask: String?,
    val status: TransactionStatusUi,
    val isDeclined: Boolean = status == TransactionStatusUi.DECLINED
)
```

### Инварианты и алгоритм:
1. `@Immutable` для оптимизации рекомпозиции в Jetpack Compose.
2. `isDeclined` вычисляется из `status == TransactionStatusUi.DECLINED` и используется для подсветки ошибок / зачеркивания суммы в UI.
