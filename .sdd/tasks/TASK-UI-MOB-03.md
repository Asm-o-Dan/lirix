## 1. Цель задачи
Реализовать ландшафтный суфлёрский пульт для пюпитра:
1. **Двухколоночная раскладка $800\times 360\,\text{dp}$:**
   - Левая колонка ($280\,\text{dp}$): обложка $48\times 48$, трекбар, транспорт, селектор режимов и компактный сдвиг `⏱`.
   - Правая колонка ($520\,\text{dp}$): чистая зона лирики (полезная ширина $460\,\text{dp}$).
2. **Устойчивость левой колонки при масштабе шрифта 1.3x:**
   - При стандартной высоте 360 dp и системном масштабе шрифта 1.3x суммарная высота элементов левой колонки превышает экран.
   - **Левая колонка оборачивается в `Modifier.verticalScroll(rememberScrollState())`** либо автоматически схлопывает текстовые подписи в иконки при обнаружении переполнения.
3. **Боковой трёхкнопочный навибар и вырез экрана:**
   - В горизонтальном положении навигационная панель Android располагается сбоку (ширина 48 dp).
   - Раскладка учитывает `WindowInsets.navigationBars` и `WindowInsets.displayCutout` (safe drawing), динамически вычитая ширину навибара из ширины правой колонки суфлёра.
4. **Типографика для дистанции:**
   - Базовый кегль: $28\,\text{sp}$, масштабирование через «Аа» до **$42\,\text{sp}$** для чтения вокалистом с дистанции $1.5$ метра.

---

## 2. Критерии приемки (DoD)
- [ ] Скриншот-тест в ландшафтном режиме с трёхкнопочной навигацией сбоку и вырезом камеры (Cutout Safe Insets).
- [ ] При системном масштабе шрифта 1.3x контролы левой колонки не обрезаются и доступны через плавный скролл.
- [ ] При масштабе текста 42 sp текст комфортно читается и центрируется.
