## Задача DSL-P2-008: Реализовать встроенный пресет LegacyPipelinePreset

**Файл:** `pipeline/dsl/src/main/kotlin/com/example/npc/pipeline/dsl/preset/LegacyPipelinePreset.kt` (создать)  
**Модуль:** `:pipeline:dsl` (чистый Kotlin JVM)  
**Спека:** `.sdd/specs/pipeline-dsl/overview.md#6-эталонный-пресет-legacy-11-the-golden-baseline-preset`  
**Контракт:** `.sdd/contracts/pipeline-dsl__compiler.md`  

**Сигнатура (НЕ МЕНЯТЬ):**
```kotlin
package com.example.npc.pipeline.dsl.preset

import com.example.npc.pipeline.dsl.PipelineDefinition

object LegacyPipelinePreset {
    const val PRESET_ID = "legacy-1.1-preset"

    /**
     * Создает канонический экземпляр PipelineDefinition, полностью воспроизводящий
     * монолитный конвейер Фазы 1.1 для дифференциального теста 100% паритета:
     * - Stage 1 (stage-fingerprint): вычисление отпечатка контента (FingerprintCompute)
     * - Stage 2 (stage-prototype-feedback): Feedback Loop по User Prototype (supportCount >= 2)
     * - Stage 3 (stage-bank-finance): шлюз доверенных банков (APB, Prisbank, MAIB, SMS 900) и FinanceExtract
     * - Stage 4 (stage-music): распознавание плееров и аудиосервисов (Category.MUSIC)
     * - Stage 5 (stage-communication): мессенджеры, звонки, личные SMS (Category.COMMUNICATION)
     * - Stage 6 (stage-services): погода, такси, доставка (Category.SERVICES)
     * - Stage 7 (stage-fallback-other): fallback для прочих уведомлений (Category.OTHER)
     */
    fun create(): PipelineDefinition
}
```

**Поведение:**
1. Создает программный иммутабельный экземпляр `PipelineDefinition`, соответствующий спецификации эталонного пресета Фазы 1.1.
2. Поля корневого объекта:
   - `id = PRESET_ID` (`"legacy-1.1-preset"`)
   - `name = "Legacy 1.1 Baseline Pipeline"`
   - `description = "Эталонная конфигурация Фазы 1.1 для дифференциального теста паритета 100% совпадения"`
   - `schemaVersion = 1`
   - `revision = 1L`
   - `enabled = true`
   - `priority = 1000`
   - `packageWhitelist = emptyList()`
   - `metadata = mapOf("systemPreset" to "true", "parityBaseline" to "1.1")`
3. Триггеры:
   - `TriggerDefinition.Notification(ignoreSelf = true)`
   - `TriggerDefinition.Sms(allowDirectReceiver = true, allowMessagingApps = true)`
   - `TriggerDefinition.Media(captureArtwork = false)`
4. Этапы (Stages):
   - `stage-fingerprint`: безусловный этап с `FingerprintCompute(algorithm = "SHA-256-TEMPLATED", targetVar = "contentFingerprint")`.
   - `stage-prototype-feedback`: условие `PrototypeSupportCount(minSupportCount = 2)`, действие `SetCategory(category = Category.UNCLASSIFIED, confidence = 1.0, engine = Engine.PROTOTYPE)`.
   - `stage-bank-finance`: условие `LogicalAnd` (белый список банков APB, Prisbank, MAIB, доверенные отправители SMS и исключение мессенджеров), трансформации `RegionalTextSanitize` + `FinanceExtract`, действия `SetCategory(FINANCE, 0.98, RULES)` + `SaveToStorage(true)`, `terminateOnMatch = true`.
   - `stage-music`: условие `PackageMatch` (пакеты плееров), действие `SetCategory(MUSIC, 0.95, RULES)` + `SaveToStorage(true)`, `terminateOnMatch = true`.
   - `stage-communication`: условие `LogicalOr` (пакеты мессенджеров, dialer, системные SMS), действие `SetCategory(COMMUNICATION, 0.90, RULES)` + `SaveToStorage(true)`, `terminateOnMatch = true`.
   - `stage-services`: условие `LogicalOr` (пакеты погоды/такси/доставки И `TextRegexMatch` по ключевым словам сервисов), действие `SetCategory(SERVICES, 0.90, RULES)` + `SaveToStorage(true)`, `terminateOnMatch = true`.
   - `stage-fallback-other`: безусловный этап (`condition = null`), действие `SetCategory(OTHER, 0.50, RULES)` + `SaveToStorage(true)`, `terminateOnMatch = true`.

**Ошибки:**
- Не выбрасывает исключений при вызове `create()`. Результат полностью валиден и детерминирован.

**Граничные случаи:**
- Вызов `create()` создает новый независимый экземпляр `PipelineDefinition` при каждом вызове.
- Сериализация созданного объекта в JSON и повторная десериализация через `PipelineJsonCodec.decodeFromString` дает побитово идентичный объект (`create() == decode(encode(create()))`).
