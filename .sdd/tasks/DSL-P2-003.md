## Задача DSL-P2-003: Реализовать TransformDefinition

**Файл:** `pipeline/dsl/src/main/kotlin/com/example/npc/pipeline/dsl/TransformDefinition.kt` (создать)  
**Модуль:** `:pipeline:dsl` (чистый Kotlin JVM)  
**Спека:** `.sdd/specs/pipeline-dsl/overview.md#43-узлы-трансформации-данных-transformdefinition`  
**Контракт:** `.sdd/contracts/pipeline-dsl__compiler.md#33-трансформации-transformdefinition`  

**Сигнатура (НЕ МЕНЯТЬ):**
```kotlin
package com.example.npc.pipeline.dsl

import kotlinx.serialization.ExperimentalSerializationApi
import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.JsonClassDiscriminator

@OptIn(ExperimentalSerializationApi::class)
@Serializable
@JsonClassDiscriminator("type")
sealed interface TransformDefinition {
    val type: String

    @Serializable
    @SerialName("FingerprintCompute")
    data class FingerprintCompute(
        @SerialName("algorithm") val algorithm: String = "SHA-256-TEMPLATED",
        @SerialName("targetVar") val targetVar: String = "contentFingerprint"
    ) : TransformDefinition {
        override val type: String get() = "FingerprintCompute"
    }

    @Serializable
    @SerialName("RegionalTextSanitize")
    data class RegionalTextSanitize(
        @SerialName("maxChars") val maxChars: Int = 1024,
        @SerialName("normalizeNbsp") val normalizeNbsp: Boolean = true,
        @SerialName("stripDiacritics") val stripDiacritics: Boolean = false,
        @SerialName("targetVar") val targetVar: String = "sanitizedText"
    ) : TransformDefinition {
        override val type: String get() = "RegionalTextSanitize"
    }

    @Serializable
    @SerialName("AmountParse")
    data class AmountParse(
        @SerialName("currencyHint") val currencyHint: String? = null,
        @SerialName("sourceVar") val sourceVar: String = "sanitizedText",
        @SerialName("targetVar") val targetVar: String = "parsedAmount"
    ) : TransformDefinition {
        override val type: String get() = "AmountParse"
    }

    @Serializable
    @SerialName("CurrencyResolve")
    data class CurrencyResolve(
        @SerialName("defaultCurrency") val defaultCurrency: String = "RUP",
        @SerialName("sourceVar") val sourceVar: String = "sanitizedText",
        @SerialName("targetVar") val targetVar: String = "resolvedCurrency"
    ) : TransformDefinition {
        override val type: String get() = "CurrencyResolve"
    }

    @Serializable
    @SerialName("FinanceExtract")
    data class FinanceExtract(
        @SerialName("extractorId") val extractorId: String = "auto",
        @SerialName("allowedPackages") val allowedPackages: List<String> = emptyList(),
        @SerialName("timeoutMs") val timeoutMs: Long = 50L,
        @SerialName("useCircuitBreaker") val useCircuitBreaker: Boolean = true,
        @SerialName("targetVar") val targetVar: String = "financialTransaction"
    ) : TransformDefinition {
        override val type: String get() = "FinanceExtract"
        init {
            require(timeoutMs in 5L..500L) { "timeoutMs must be between 5 and 500 ms, but was $timeoutMs" }
        }
    }
}
```

**Поведение:**
1. Предоставляет полиморфную иерархию декларативных узлов преобразования и извлечения признаков.
2. Маркируется аннотацией `@JsonClassDiscriminator("type")`.
3. `FingerprintCompute`: декларативно задает расчет отпечатка шаблона для Feedback Loop.
4. `RegionalTextSanitize`: задает очистку регионального текста (NBSP, диакритики, обрезка длины до `maxChars`).
5. `AmountParse`: декларативный узел парсинга суммы из указанной переменной `sourceVar` в неделимых единицах (minor units) с сохранением в `targetVar`.
6. `CurrencyResolve`: узел разрешения валюты транзакции с указанием дефолтного кода (по умолчанию "RUP").
7. `FinanceExtract`: узел защищенного запуска специализированного экстрактора с ограничением по времени `timeoutMs` и интеграцией с Circuit Breaker.

**Ошибки:**
- `IllegalArgumentException`: выбрасывается в `init` блоке `FinanceExtract`, если `timeoutMs < 5L` или `timeoutMs > 500L`.
- `SerializationException`: при некорректном JSON или неизвестном типе дискриминатора.

**Граничные случаи:**
- `FinanceExtract.timeoutMs = 5L` -> минимально допустимый бюджет.
- `FinanceExtract.timeoutMs = 500L` -> максимально допустимый бюджет.
- `FinanceExtract.timeoutMs = 4L` или `501L` -> выбрасывает `IllegalArgumentException`.
- `allowedPackages` пуст -> экстрактор доступен для всех пакетов, допущенных на уровне конвейера.

**Запрещено:**
- Исполнять логику парсинга или вычисления хеша внутри классов AST (эти узлы — чистые DTO).
- Подключать Android SDK или внешние библиотеки парсинга.
- Использовать Reflection при маппинге переменных.

**Критерий приёмки:**
- Файл скомпилирован в модуле `:pipeline:dsl`.
- Юнит-тесты проверяют валидацию `timeoutMs` в `FinanceExtract`, а также сериализацию и десериализацию всех 5 классов трансформаций.
