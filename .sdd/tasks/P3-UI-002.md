## Задача P3-UI-002: Реализовать токенную сетку и селектор ролей для One-Tap Editor

**Модуль:** `:feature:editor`  
**Целевые файлы:**  
- `feature/editor/src/main/kotlin/com/example/npc/feature/editor/ui/TokenGridView.kt`  
- `feature/editor/src/main/kotlin/com/example/npc/feature/editor/ui/TokenChip.kt`  
- `feature/editor/src/main/kotlin/com/example/npc/feature/editor/ui/RoleSelectionMenu.kt`  
**Контракт:** `.sdd/contracts/ui-features__domain-contracts.md#21-one-tap-template-editor`  

---

### Описание:
Реализовать специализированный интерфейс разметки уведомления:
1. Разбиение текста сообщения на кликабельные чипы-токены (цветовая дифференциация по типу слота: сумма — зеленый, валюта — синий, карта — фиолетовый, баланс — серый).
2. Выпадающее всплывающее меню по тапу на токен:
   - Быстрый выбор роли: `[Сумма] [Валюта] [Карта] [Баланс] [Мерчант] [Литерал] [Игнорировать]`.
3. Поддержка мульти-выделения: жест долгого нажатия и протяжки для объединения нескольких токенов в слот мерчанта (`TEMU.COM`).
4. Поддержка переключения режима возврата (`isRefund`).

### Критерии приёмки (DoD):
- Compose UI тест на взаимодействие с токенами и смену ролей.
- Отсутствие фризов при перерисовке сетки токенов на Poco M7.
