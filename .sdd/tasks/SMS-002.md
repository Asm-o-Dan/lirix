**Зависит от:** `SMS-001`

**Поведение:**
1. `SmsContract(val originAddress: String, val body: String, val timestampMillis: Long)`.
2. `SmsRawPayload(val seq: Long, val originAddress: String, val body: String, val timestampMillis: Long, val receivedAt: Instant, val subId: Int? = null)`.
3. `SmsSenderInfo(val address: String, val displayName: String?, val isAlphanumeric: Boolean)`.
4. `SmsBackfillStatus` (sealed interface: `NotStarted`, `InProgress`, `Completed`, `Failed`).
5. `SmsBackfillResult(val importedCount: Int, val skippedDuplicatesCount: Int, val isSuccess: Boolean, val failureReason: String? = null)`.
6. `SmsMapper`:
   - `fromSmsMessages(messages: Array<SmsMessage>?): SmsContract?`
     - Собирает multipart SMS в конкатенированный текст.
     - Безопасная обработка `null` адреса (fallback на `"UNKNOWN"`).
   - `toPayloadJson(originAddress: String, body: String, timestampMillis: Long, subId: Int? = null): String`
     - RFC 8259 канонический JSON с экранированием.
   - `toRawEvent(payload: SmsRawPayload, deduplicationKey: DeduplicationKey): RawEvent`
     - `source = SourceId.SMS`, `packageName = "android.telephony.sms"`.
   - `toEvent(rawEvent: RawEvent, contract: SmsContract): Event`
     - Очистка текста через `EventNormalizer.cleanText`.
     - Детект языка через `EventNormalizer.detectLang`.
     - `ThreadKey(contract.originAddress.trim())`, `isUpdateOf = null`.
   - `fromCursor(cursor: Cursor): SmsContract`
     - Извлечение колонок `Telephony.Sms.ADDRESS`, `BODY`, `DATE`.

**Критерий приёмки:**
- Все преобразования детерминированы, защищены от null и спецсимволов.
