## Задача DSL-P2-007: Реализовать PipelineJsonCodec

**Файл:** `pipeline/dsl/src/main/kotlin/com/example/npc/pipeline/dsl/codec/PipelineJsonCodec.kt` (создать)  
**Модуль:** `:pipeline:dsl` (чистый Kotlin JVM)  
**Спека:** `.sdd/specs/pipeline-dsl/overview.md#5-сериализация-и-json-кодек-pipelinejsoncodec`  
**Контракт:** `.sdd/contracts/pipeline-dsl__compiler.md#4-json-кодек-pipelinejsoncodec`  

**Сигнатура (НЕ МЕНЯТЬ):**
```kotlin
package com.example.npc.pipeline.dsl.codec

import com.example.npc.pipeline.dsl.PipelineDefinition
import kotlinx.serialization.json.Json
import java.security.MessageDigest

object PipelineJsonCodec {
    val json: Json = Json {
        ignoreUnknownKeys = false
        isLenient = false
        prettyPrint = false
        encodeDefaults = true
        coerceInputValues = false
        classDiscriminator = "type"
    }

    val prettyJson: Json = Json {
        ignoreUnknownKeys = false
        isLenient = false
        prettyPrint = true
        prettyPrintIndent = "  "
        encodeDefaults = true
        coerceInputValues = false
        classDiscriminator = "type"
    }

    val tolerantJson: Json = Json {
        ignoreUnknownKeys = true
        isLenient = false
        prettyPrint = false
        encodeDefaults = true
        coerceInputValues = false
        classDiscriminator = "type"
    }

    fun encodeToString(definition: PipelineDefinition): String
    fun encodeToPrettyString(definition: PipelineDefinition): String
    fun decodeFromString(jsonString: String, tolerant: Boolean = false): PipelineDefinition
    fun calculateCanonicalHash(definition: PipelineDefinition): String
}
```

**Поведение:**
1. Предоставляет единую детерминированную точку входа для сериализации и десериализации AST-моделей конвейера.
2. `encodeToString`: сериализует `PipelineDefinition` в компактную строку JSON без переносов и лишних пробелов с `encodeDefaults = true` и `classDiscriminator = "type"`.
3. `encodeToPrettyString`: сериализует с отступами в 2 пробела для человекочитаемого отображения в UI редактора и экспорта.
4. `decodeFromString`: десериализует JSON-строку. Если `tolerant = false` (по умолчанию), используется строгий парсер `json` (`ignoreUnknownKeys = false`). Если `tolerant = true` (режим импорта внешних файлов), используется `tolerantJson` (`ignoreUnknownKeys = true`).
5. `calculateCanonicalHash`: сериализует `PipelineDefinition` в компактный JSON и вычисляет контрольную сумму SHA-256 в шестнадцатеричном виде (lower-case hex string 64 символа) для отслеживания изменений и ревизий в базе данных.

**Ошибки:**
- `kotlinx.serialization.SerializationException`: при синтаксических ошибках в JSON, неизвестных полиморфных типах или при наличии неизвестных ключей (в нетолерантном режиме).
- `IllegalArgumentException`: при нарушении инвариантов валидации в блоках `init` классов AST (`id`, `name`, `priority`, `stages`).

**Граничные случаи:**
- Пустая строка JSON -> выбрасывает `SerializationException`.
- Мусорный бинарный контент -> выбрасывает `SerializationException`.
- JSON с дополнительным полем `"unknownField": 123` при `tolerant = false` -> выбрасывает `SerializationException`.
- JSON с дополнительным полем `"unknownField": 123` при `tolerant = true` -> успешно десериализуется.
- Канонический SHA-256 хеш всегда ровно 64 символа (`^[0-9a-f]{64}$`).

**Запрещено:**
- Использовать сторонние тяжелые JSON библиотеки (Jackson, Gson). Использовать строго `kotlinx.serialization.json`.
- Включать `isLenient = true` (запрещены неэкранированные спецсимволы и комментарии).
- Использовать Android SDK.

**Критерий приёмки:**
- Файл скомпилирован в модуле `:pipeline:dsl`.
- Юнит-тесты проверяют:
  - Round-trip тест: `decodeFromString(encodeToString(x)) == x`.
  - Детерминизм SHA-256: `calculateCanonicalHash(x)` выдает идентичный результат при повторных вызовах.
  - Поведение с неизвестными полями в строгом и толерантном режимах.
  - Обработку невалидного JSON.
