## 1. Цель задачи
Редизайн экрана итогов без SaaS-плиток:
1. **Типографическое эссе (Отказ от сплошного курсива):**
   - **Только первое ведущее предложение** выделяется курсивом `Literata Italic` ($18\,\text{sp}$):  
     *«За последний месяц вы провели в музыке 38 часов.»*
   - **Весь остальной текст эссе набирается прямым начертанием `Literata Regular/Medium`**, гарантируя идеальную читаемость кириллицы в длинных абзацах.
2. **Честные факты (Zero Fake Data):**
   - «Время в музыке», «Уникальных треков», «Просмотрено с текстом» (честная метрика вместо «спето вслух»), «Любимый трек».
3. **Минималистичные достижения (14 из 26):**
   - Компактный список со строкой прогресса без псевдо-золотых градиентов.
4. **Адаптивная карточка для шеринга:**
   - Генерация карточки под активную тему (тёмная `Graphite` или светлая `Paper`), исключая искусственные ограничения монохрома и сохраняя книжный стиль суфлёра.

---

## 2. Критерии приемки (DoD)
- [ ] Сплошной текст эссе набран прямым шрифтом Literata, курсивом выделена только первая строка.
- [ ] Экспорт карточки шеринга работает в тёмной и светлой темах.
- [ ] Метрика «Просмотрено с текстом» отражает честное число песен.
- [ ] В тексте нет капса, соблюден строгий sentence case.
