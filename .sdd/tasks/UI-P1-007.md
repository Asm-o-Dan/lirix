## Задача UI-P1-007: Создать диалог обратной связи CategoryCorrectionDialog

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/ui/components/CategoryCorrectionDialog.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#63-categorycorrectiondialog`  
**Контракт:** `.sdd/contracts/core-storage__ui.md`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.ui.components

import androidx.compose.runtime.Composable
import com.example.npc.core.model.classify.Category

@Composable
fun CategoryCorrectionDialog(
    currentCategory: Category,
    onCategorySelected: (Category) -> Unit,
    onDismissRequest: () -> Unit
)
```

### Инварианты и алгоритм:
1. Модальный диалог (`AlertDialog` / bottom sheet Material 3) со списком всех категорий:
   - `FINANCE`
   - `COMMUNICATION`
   - `MUSIC`
   - `SERVICES`
   - `ADVERTISEMENT` (Спам/Реклама)
   - `OTHER`
2. Текущая категория отмечена радио-кнопкой / галочкой.
3. Выбор новой категории:
   - Вызывает `onCategorySelected(newCategory)`.
   - Инициирует сохранение пользовательского прототипа в БД через `StorageGateway.recordUserCorrection`.
   - Немедленно закрывает диалог.

### Критерии приемки (DoD):
- [ ] Отработка выбора категории в 1 клик.
- [ ] Compose UI тестирование клика по категории и вызова колбэка.
