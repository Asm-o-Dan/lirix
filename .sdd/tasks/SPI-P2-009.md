## Задача SPI-P2-009: Реализовать NodeRegistry

**Модуль:** `:pipeline:nodes-api`  
**Целевой файл:** `pipeline/nodes-api/src/main/kotlin/com/example/npc/pipeline/nodes/api/registry/NodeRegistry.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#26-каталог-и-реестр-узлов-noderegistry`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#4-контракт-спецификации-и-каталога-узлов-nodespec-noderegistry`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.api.registry

import com.example.npc.pipeline.nodes.api.spec.NodeSpec

/**
 * Потокобезопасный каталог зарегистрированных спецификаций узлов конвейера.
 */
interface NodeRegistry {
    fun register(spec: NodeSpec)
    fun find(id: String): NodeSpec?
    fun getAll(): Collection<NodeSpec>
}

/**
 * Стандартная потокобезопасная реализация каталога на ConcurrentHashMap.
 */
class NodeRegistryImpl : NodeRegistry {
    private val specs = java.util.concurrent.ConcurrentHashMap<String, NodeSpec>()

    override fun register(spec: NodeSpec) {
        val prev = specs.putIfAbsent(spec.id, spec)
        require(prev == null) { "Node with id '${spec.id}' is already registered" }
    }

    override fun find(id: String): NodeSpec? = specs[id]

    override fun getAll(): Collection<NodeSpec> = java.util.Collections.unmodifiableCollection(specs.values)
}
```

### Поведение:
1. `register(spec)`: регистрирует спецификацию узла в каталоге. Если спецификация с таким `id` уже существует, выбрасывает исключение `IllegalArgumentException`.
2. `find(id)`: возвращает спецификацию `NodeSpec` по её строковому `id` или `null`, если тип узла не зарегистрирован.
3. `getAll()`: возвращает иммутабельную коллекцию всех зарегистрированных спецификаций для палитры UI редактора и инспекции.
4. Потокобезопасность: все операции атомарны и безопасны для параллельного чтения и записи из разных потоков приложения.

### Ошибки:
- При попытке повторной регистрации узла с существующим `id` выбрасывать `IllegalArgumentException`.
- При передаче пустого или пробельного `spec.id` выбрасывать `IllegalArgumentException`.

### Граничные случаи:
- `find("non_existent_id")`: возвращает `null` без выброса исключений.
- Пустой реестр: `getAll()` возвращает пустую коллекцию.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Использовать динамический `java.util.ServiceLoader` (R8/ProGuard-опасно).
- Разрешать перезапись существующих спецификаций без предварительной очистки.
