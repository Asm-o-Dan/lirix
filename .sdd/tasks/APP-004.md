(создать)

**Спека:**
- `.sdd/specs/app-lifecycle/overview.md#пошаговый-онбординг-с-поддержкой-hyperos--poco-m7-onboardingflow` (v1)
- `.sdd/specs/app-lifecycle/overview.md#главная-activity-mainactivity` (v1)

**Зависит от:** `APP-003`

**Поведение:**
1. `HyperOsIntegration.kt`:
   - Определение устройства Xiaomi / Poco (`Build.MANUFACTURER.contains("xiaomi", ignoreCase = true)` или проверка системного свойства `ro.miui.ui.version.name`).
   - Интенты автозапуска HyperOS / MIUI:
     - ComponentName `com.miui.securitycenter/com.miui.permcenter.autostart.AutoStartManagementActivity` с безопасным fallback на настройки приложения.
2. `OnboardingManager.kt`:
   - Проверка текущего состояния разрешений (`OnboardingState`):
     - `NotificationListenerAccess`: `NotificationManagerCompat.getEnabledListenerPackages(context).contains(context.packageName)`
     - `BatteryOptimization`: `powerManager.isIgnoringBatteryOptimizations(context.packageName)`
     - `PostNotifications`: `ContextCompat.checkSelfPermission(POST_NOTIFICATIONS) == PERMISSION_GRANTED`
     - `SmsPermissions`: `READ_SMS` и `RECEIVE_SMS`
     - `CalendarPermission`: `READ_CALENDAR`
     - `HyperOsDevice`: флаг из `HyperOsIntegration`
3. `OnboardingScreen.kt`:
   - Jetpack Compose экран с пошаговым списком карточек (Чекбокс/Индикатор готовности, заголовок, описание, кнопка действия перехода в системные настройки).
   - Кнопка "Перейти к событиям" (активна, когда `state.isMandatorySetupComplete == true`).
4. `MainActivity.kt`:
   - `@AndroidEntryPoint class MainActivity : ComponentActivity()`
   - Compose `setContent`:
     - Реактивно наблюдает готовность разрешений.
     - Если `!state.isMandatorySetupComplete` -> отображает `OnboardingScreen`.
     - Если все обязательные настройки готовы -> отображает `TimelineScreen` (из модуля `:ui:timeline`).

**Критерий приёмки:**
- Полная сборка APK: `.\gradlew.bat :app:assembleDebug` завершается BUILD SUCCESSFUL.
