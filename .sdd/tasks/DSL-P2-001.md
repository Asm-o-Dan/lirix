## Задача DSL-P2-001: Реализовать TriggerDefinition

**Файл:** `pipeline/dsl/src/main/kotlin/com/example/npc/pipeline/dsl/TriggerDefinition.kt` (создать)  
**Модуль:** `:pipeline:dsl` (чистый Kotlin JVM)  
**Спека:** `.sdd/specs/pipeline-dsl/overview.md#41-триггеры-источников-triggerdefinition`  
**Контракт:** `.sdd/contracts/pipeline-dsl__compiler.md#31-триггеры-triggerdefinition`  

**Сигнатура (НЕ МЕНЯТЬ):**
```kotlin
package com.example.npc.pipeline.dsl

import kotlinx.serialization.ExperimentalSerializationApi
import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.JsonClassDiscriminator

@OptIn(ExperimentalSerializationApi::class)
@Serializable
@JsonClassDiscriminator("type")
sealed interface TriggerDefinition {
    val type: String

    @Serializable
    @SerialName("NOTIFICATION")
    data class Notification(
        @SerialName("ignoreSelf")
        val ignoreSelf: Boolean = true,
        @SerialName("subTypes")
        val subTypes: List<String> = emptyList()
    ) : TriggerDefinition {
        override val type: String get() = "NOTIFICATION"
    }

    @Serializable
    @SerialName("SMS")
    data class Sms(
        @SerialName("allowDirectReceiver")
        val allowDirectReceiver: Boolean = true,
        @SerialName("allowMessagingApps")
        val allowMessagingApps: Boolean = true
    ) : TriggerDefinition {
        override val type: String get() = "SMS"
    }

    @Serializable
    @SerialName("MEDIA")
    data class Media(
        @SerialName("captureArtwork")
        val captureArtwork: Boolean = false
    ) : TriggerDefinition {
        override val type: String get() = "MEDIA"
    }
}
```

**Поведение:**
1. Предоставляет полиморфную иерархию описания источников событий (`TriggerDefinition`), активирующих конвейер обработки.
2. Маркируется аннотацией `@JsonClassDiscriminator("type")` для детерминированной полиморфной сериализации и десериализации через `kotlinx.serialization`.
3. Подтип `Notification` описывает захват push-уведомлений Android (`NotificationListenerService`). По умолчанию `ignoreSelf = true` исключает циклическое самовозбуждение от уведомлений собственного приложения.
4. Подтип `Sms` описывает захват SMS сообщений (через прямой BroadcastReceiver и/или системные SMS-клиенты AOSP / Google Messages).
5. Подтип `Media` описывает захват метаданных активных медиасессий (`MediaSessionManager`). По умолчанию `captureArtwork = false` для исключения тяжелых аллокаций картинок в горячем контуре.
6. Каждый подтип переопределяет свойство `type` строковым литералом, совпадающим со значением аннотации `@SerialName`.

**Ошибки:**
- Не выбрасывает исключений в runtime при корректных значениях полей.
- При десериализации неизвестного значения дискриминатора `"type"` библиотека `kotlinx.serialization` выбрасывает `SerializationException`.

**Граничные случаи:**
- `subTypes` пуст (`emptyList()`) -> триггер срабатывает на любые подтипы уведомлений.
- `subTypes` содержит произвольные строки -> компилятор выполняет валидацию допустимых тегов.
- `ignoreSelf = false` -> допускается захват собственных уведомлений (для тестовых конвейеров).

**Запрещено:**
- Использовать любые Android SDK классы (`android.*`, `androidx.*`).
- Использовать Java reflection при сериализации.
- Менять имя дискриминатора `"type"` или значения `@SerialName`.

**Критерий приёмки:**
- Файл скомпилирован в модуле `:pipeline:dsl`.
- Проходят юнит-тесты: сериализация и десериализация всех 3 вариантов триггеров в компактный и форматированный JSON, проверка поля `type`.
