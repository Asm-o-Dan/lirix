# TASK-UI-CHORDS-SMART-WRAP-01: Умный перенос строк и синхронное разбиение слоговых пар аккордов

## 1. Контекст и проблема
Пользователь сообщил:
> `если в аккордах будет длинная строка изза отсутствия переносов ничего не будет видно`

В `ChordsTabContent.kt`:
1. Текстовое поле аккордов использовало `softWrap = false` вместе с `.horizontalScroll(horizontalScrollState)`.
2. Если строка куплета или припева превышает ширину экрана смартфона (~34-40 символов моноширинного шрифта), правая часть строки уходит за правый край экрана. Музыкант с гитарой в руках физически не может скроллить экран вбок во время игры и автоскролла.
3. Если текст песни получен из веб-источника без переносов (`\n`) или одной длинной строкой, весь трек вытягивается в одну бесконечную горизонтальную полосу, где видно только первые 4-5 слов.
4. Обычное включение `softWrap = true` на всем тексте Compose ломает выравнивание: строка аккордов и строка текста переносят слова в разных местах, в результате чего аккорды смещаются на 1-2 строки относительно слов песни.

## 2. Архитектурное решение (ADR-052)
1. **Предварительная нормализация переносов:**
   - Если текст содержит длинные неразбитые строки (`lines().size <= 2 && length > 80`), автоматически применять `LrcSyncEngine.sanitizePlainText(chordsText)`, восстанавливая переносы строк по заголовкам секций (`[Куплет]`, `[Припев]`), знакам препинания (`.`, `!`, `?`) и позициям аккордов.
2. **Синхронное разбиение слоговых пар (`wrapSyllabicPair`):**
   - Для строк с инлайн-аккордами (`formatInlineChordsToSyllabicPair`), превышающих расчетную ширину экрана `maxCharsPerLine` (36-40 символов в портрете):
     - Находить границу слова в строке текста перед `maxCharsPerLine`.
     - Разрезать одновременно и строку текста, и строку аккордов по этой позиции.
     - Сохранять точное позиционирование аккордов над слогами в каждой получившейся паре строк.
3. **Безопасный перенос обычных строк:**
   - Строки чистых аккордов или чистого текста, превышающие `maxCharsPerLine`, также детерминированно переносить по границам пробелов.
4. **Тулбар-переключатель переноса (`[ ↩ ]` / `[ ⇄ ]`):**
   - Добавить в компактную панель управления микро-кнопку переключения режима переноса (по умолчанию включен `isWrapEnabled = true`).
   - При включенном переносе строки гарантированно умещаются на экране смартфона без необходимости горизонтального скролла.

## 3. Критерии приемки (DoD)
- [x] Длинные строки аккордов и текста автоматически переносятся и не обрезаются экраном.
- [x] Аккорды в перенесенных строках строго сохраняют привязку к своим слогам.
- [x] Тексты без переносов строк автоматически форматируются в читаемые куплеты.
- [x] Присутствует переключатель `[ ↩ ]` (с переносом / без переноса).
- [x] Сборка `:shared:desktopTest` и `:app:assembleDebug` успешна, проверена на физическом устройстве.
