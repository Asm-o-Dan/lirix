## Задача SPI-P2-001: Реализовать enum Bank

**Модуль:** `:pipeline:nodes-api`  
**Целевой файл:** `pipeline/nodes-api/src/main/kotlin/com/example/npc/pipeline/nodes/api/frame/Bank.kt`  
**Спецификация:** `.sdd/specs/pipeline-spi/overview.md#21-регистровая-модель-данных-bank-textregister-framelayout-frame`  
**Контракт:** `.sdd/contracts/pipeline-compiler__spi.md#2-регистровая-модель-памяти-bank-textregister-framelayout-frame`  

### Сигнатура (НЕ МЕНЯТЬ):
```kotlin
package com.example.npc.pipeline.nodes.api.frame

/**
 * Регистровые банки памяти виртуальной машины конвейера.
 */
enum class Bank {
    /** 64-битные целые: Long, Int, Short, Byte, Boolean (0L/1L), Enum ordinals, EpochMillis. */
    LONG,

    /** 64-битные вещественные IEEE 754 (Double, Float bits). */
    DOUBLE,

    /** Иммутабельные ссылки на тяжелые DTO хоста (FinancialTransaction, Category, UserPrototype) и scratch-объекты. */
    REF,

    /** Предвыделенные безаллокационные текстовые регистры с фиксированной емкостью. */
    TEXT
}
```

### Поведение:
1. Служит дискриминатором типа физического хранилища слота в `FrameLayout` и `PortSchema`.
2. Компилятор на фазе аллокации регистров использует `Bank` для распределения портов по соответствующим типизированным плоским массивам `Frame` (`longs`, `doubles`, `refs`, `texts`).
3. Имеет строго 4 элемента в порядке: `LONG`, `DOUBLE`, `REF`, `TEXT`.

### Ошибки:
- При десериализации или парсинге неизвестного строкового имени банка выбрасывать `IllegalArgumentException`.

### Граничные случаи:
- Значения `Bank.entries` кэшируются на уровне JVM для предотвращения клонирования массивов при обходе.

### Запрещено:
- Использовать Android SDK (`android.*`).
- Добавлять изменяемые (`var`) поля в enum.
- Добавлять новые банки без согласования в FROZEN-контракте компилятора.
