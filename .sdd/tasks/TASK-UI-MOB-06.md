## 1. Цель задачи
Шлифовка вспомогательных экранов и сервисов:
1. **TeachModeScreen (Режим обучения):**
   - Разгрузка шапки: ровно 3 элемента (`✕ Закрыть`, `Обучение: Название`, `⋮ Меню`).
   - Кнопка подъема по DOM: надпись `[ Расширить выделение ]` (вместо «Выше» или «Родительский тег»).
   - Выбор элементов различим не только по цвету (доступность при дальтонизме): сплошная рамка 2dp цвета Accent для выделения текста, пунктирная зачеркнутая рамка с диагональной штриховкой для исключений.
   - Фильтрация ложных кликов при скролле калибруется через системный `ViewConfiguration.get(context).scaledTouchSlop`.
   - Состояние «Правило устарело»: при смене верстки сайта выводится подсказка: *«Вёрстка страницы изменилась. Выделите текст заново»*.
2. **BlacklistSettingsScreen (Чёрный список):**
   - Человеческие имена приложений (`Яндекс Навигатор`, `Telegram`, `VK Музыка`) через `PackageManager.getApplicationLabel`.
   - Терминология: строго «Правило игнорирования».
   - Каскадное удаление треков: подтверждение и обязательный Snackbar: *«Удалено N треков. [ Отменить ]»* (таймаут 6–8 секунд с AccessibilityManager).
3. **Ручная синхронизация (Tap-to-Sync):**
   - **Настройка компенсации моторного лага:** параметр в интерфейсе `Задержка реакции: 200 мс` (значение по умолчанию $200\,\text{мс}$, с возможностью регулировки пользователем от 0 до 500 мс, персистится в Preferences).
   - Кнопка отмены: `[ ↶ Отменить ]` стирает последнюю метку и возвращает строку назад.
   - Тонкая доводка: кнопки `−0,1 с` и `+0,1 с` возле строк.
4. **Диалоги системных разрешений и онбординг:**
   - Четкие и понятные пользователю формулировки:
     * «Доступ к уведомлениям для чтения медиасессий» (Notification Listener Service). При первом запуске: поясняющий экран, кнопка «Открыть системные настройки» и автоматическая проверка предоставления разрешения при возврате в `onResume()`.
     * «Поверх других приложений» (`SYSTEM_ALERT_WINDOW` для плавающего виджета).

## 2. Критерии приемки (DoD)
- [ ] Шапка TeachModeScreen содержит ровно 3 элемента, рамки выделения различимы по типу контура.
- [ ] Ошибочные клики отсекаются по системному `scaledTouchSlop`.
- [ ] Задержка реакции в Tap-to-Sync настраивается (дефолт 200 мс) и учитывается при записи таймкодов.
- [ ] Доступны кнопки отмены шага и доводки `±0.1 с`.
- [ ] Разрешения запрашиваются с корректными системными именами.
