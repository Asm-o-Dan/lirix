## Задача UI-P1-003: Обновить EventUiMapper для форматирования атрибутов Фазы 1

**Модуль:** `:ui:timeline`  
**Целевой файл:** `ui/timeline/src/main/kotlin/com/example/npc/ui/timeline/mapper/EventUiMapper.kt`  
**Спецификация:** `.sdd/specs/ui-timeline/overview.md#4-eventuimapper-v2`  

### Входные контракты / сигнатуры:
```kotlin
package com.example.npc.ui.timeline.mapper

import com.example.npc.core.model.Event
import com.example.npc.core.model.finance.FinancialTransaction
import com.example.npc.ui.timeline.model.EventUiModel
import com.example.npc.ui.timeline.model.FinancialTransactionUiModel

class EventUiMapper {
    fun toUiModel(
        event: Event,
        transaction: FinancialTransaction?
    ): EventUiModel

    fun toTransactionUiModel(
        transaction: FinancialTransaction
    ): FinancialTransactionUiModel
}
```

### Инварианты и алгоритм:
1. Форматирование суммы транзакции: `amount.formatDisplay()` с префиксом `"-"` для DEBIT и `"+"` для CREDIT.
2. Маппинг `TransactionStatus` $\to$ `TransactionStatusUi`: `COMPLETED` $\to$ `COMPLETED`, `DECLINED` $\to$ `DECLINED`.
3. Форматирование остатка баланса (если присутствует): `"Остаток: ${balance.formatDisplay()}"`.
4. Извлечение категории и движка классификатора из события.
