**Модуль:** `:feature:analytics`  
**Целевые файлы:**

- `feature/analytics/src/main/kotlin/com/example/npc/feature/analytics/vm/FinancialAnalyticsViewModel.kt`  
**Контракт:** `.sdd/contracts/ui-features__domain-contracts.md#22-financial-analytics-ui`  

---

### Описание:
Реализовать экран финансовой аналитики с поддержкой нескольких валют (**ADR-305**):
1. Раздельные карточки по валютам: `MDL`, `RUP`, `USD`, `EUR`, `RUB` (без ложного сложения разных валют).
2. Выбор временного диапазона:
   - Быстрые фильтры: «Сегодня», «Эта неделя», «Этот месяц».
   - Выбор произвольного интервала дат.
3. Фильтрация по направлению операций: «Все», «Расходы», «Доходы».
4. Переключатель режима возвратов (`RefundCalculationMode`):
   - «Уменьшать расходы» (дефолт): возврат компенсирует траты.
   - «Считать доходом»: возврат учитывается в общих поступлениях.
5. Бейдж-индикатор «Требуют проверки: N» для транзакций со статусом `SUGGESTED`.

### Критерии приёмки (DoD):
- Реактивное обновление карточек сумм при добавлении новых транзакций.
- UI тест экрана аналитики на корректность переключения периодов и фильтров.
