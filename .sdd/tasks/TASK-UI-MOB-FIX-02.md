# TASK-UI-MOB-FIX-02: Контекстная строка сдвига/шрифта и эргономика заметок с клавиатурой

## 1. Контекст и Проблематика
1. **Строка «Сдвиг, Аа» показана на всех вкладках**: отображается даже в «Заметках» и на экране «Текст не найден». Сдвиг задержки бессмыслен без синхронизированных таймингов караоке, а в заметках не нужны ни сдвиг, ни кегль. Это отнимает драгоценную высоту у основной контентной зоны.
2. **Заметки с клавиатурой**: при открытии экранной клавиатуры поле ввода сжимается до 1–2 строк, потому что трекбар, строка сдвига, табы режимов и транспортный блок остаются висеть над клавиатурой. Кроме того, шапка экрана наезжает на статус-бар (`statusBarsPadding`).

## 3. Критерии приёмки (DoD)
1. **Контекстное отображение строки «Сдвиг, Аа»**:
   - Строка регулятора задержки (сдвига текста) и размера шрифта отображается **только** в режиме `NowPlayingMode.KARAOKE` (и при наличии текста с таймкодами).
   - В режимах `NowPlayingMode.NOTES`, `NowPlayingMode.CHORDS` (если нет синхронизации) и при пустом состоянии `LYRICS_NOT_FOUND` эта строка скрыта (`AnimatedVisibility(visible = isKaraokeWithLyrics)`).
2. **Режим редактирования заметок (`NowPlayingMode.NOTES`)**:
   - При фокусе на поле ввода заметок (или при видимой клавиатуре `WindowInsets.isImeVisible`):
     - Плавно скрывать трекбар, транспортные кнопки плеера и вкладки режимов.
     - Поле ввода `OutlinedTextField` расширяется на всю доступную высоту с применением `Modifier.imePadding()`.
     - Добавить в правый верхний угол кнопку «Готово» / галочку для быстрого закрытия клавиатуры.
3. **Безопасные отступы (Insets)**:
   - Шапка экрана защищена `Modifier.statusBarsPadding()`, исключая наезд элементов на системные иконки часов и батареи.
