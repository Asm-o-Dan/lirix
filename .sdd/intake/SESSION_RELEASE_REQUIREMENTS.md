## Финальные гейты

- Commit existing work как отдельный checkpoint, новые исправления/документы логическими коммитами. .git write потребует разрешенного выполнения.
- Проверить staged diff на случайные локальные данные/дампы; исключить только локальные временные файлы осмысленными ignore rules, не терять данные.
- Тесты и сборки Android/Desktop; SHA256 артефактов; версии одинаковы.
- Реальный audio smoke не заменять компонентными тестами. При невозможности слышимости заявить ограничение и не называть это подтвержденной работоспособностью.
- Release notes с реальным scope и ограничениями; финальный git status --porcelain пуст.
- Remote публикация/тег только после сборок и review; без force push и без перемещения существующих тегов.
