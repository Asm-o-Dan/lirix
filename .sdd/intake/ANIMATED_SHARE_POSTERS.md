# Animated Share Posters — SDD Intake Brief

## Инициатива
Пользователь запросил генерацию анимированных GIF/видеопостеров вместо статичных PNG. Ключевое требование: **красивые анимации с качественным дизайном**, вдохновлённые уровнем Prompt Motion / кинетическая типографика.

## Текущее состояние (Baseline)
- `EditorialPosterRenderer.kt` — статический рендер через `android.graphics.Canvas` + `StaticLayout` → `Bitmap`
- `ShareCardGenerator.kt` — 10 стилей постеров (Obsidian, Solar, Terminal, Rose Noir...) с коллажами обложек, неоновыми градиентами, виниловыми мотивами → `Bitmap` (1080×1080 / 1080×1920)
- `ShareFormatDialog.kt` — превью + экспорт через SAF как `image/png`
- `ShareManager.kt` — отправка через `Intent.ACTION_SEND`
- Нет никакой анимации, нет фреймовой генерации, нет видеокодека

## Концепция анимированных постеров

### Варианты формата экспорта
| Формат | Плюсы | Минусы |
|--------|-------|--------|
| **Animated WebP** | Нативная поддержка Android, малый размер, хорошее качество | Не везде отображается (Telegram ОК, Instagram — нет) |
| **GIF** | Универсальная совместимость, все соцсети поддерживают | 256 цветов, большой размер, нет прозрачности с альфа |
| **MP4 (H.264)** | Лучшее качество, Instagram/Stories/TikTok ready | Сложнее генерировать, нужен `MediaCodec` |
| **APNG** | Полноцветный, поддержка альфа | Плохая поддержка в соцсетях |

**Рекомендация:** MP4 (H.264) как основной формат — он принимается всеми соцсетями, даёт лучшее качество и наименьший размер. GIF как fallback для мессенджеров.

### Идеи анимаций (по типу постера)

#### NowPlaying Poster
1. **Vinyl Spin** — обложка альбома вращается как виниловая пластинка с бликом тонарма
2. **Lyrics Typewriter** — строка текста печатается посимвольно с мерцающим курсором
3. **Waveform Pulse** — аудиоволна пульсирует под обложкой
4. **Parallax Drift** — фон и обложка двигаются с разной скоростью (параллакс)
5. **Glow Breathe** — неоновый акцент плавно пульсирует (вдох-выдох, 2-3 секунды цикл)

#### Wrapped Poster
1. **Counter Roll** — числа (минуты, треки, артисты) крутятся как счётчик одометра до финального значения
2. **Card Cascade** — карточки треков выезжают одна за другой снизу с пружинным эффектом
3. **Chart Growth** — столбики "Пульс суток" растут с упругой анимацией
4. **Spotlight Sweep** — луч прожектора проходит по постеру, подсвечивая элементы
5. **Particle Dust** — частицы плавают и мерцают на фоне (как Spotify Wrapped)

### Техническая архитектура

```
AnimatedPosterEngine
├── FrameRenderer          — рендерит кадр N из M на Canvas (как сейчас, но с параметром t ∈ [0..1])
├── AnimationTimeline      — описывает keyframes и easing-функции для каждого элемента
├── VideoEncoder           — MediaCodec (H.264) или GIF encoder (LZW)
│   ├── Mp4FrameEncoder    — android.media.MediaCodec + MediaMuxer
│   └── GifFrameEncoder    — покадровый LZW (NBitEncoder или AnimatedGifEncoder)
├── ExportPipeline         — собирает frames → encode → file → share intent
└── PreviewComposable      — Compose Canvas анимация для живого превью в диалоге
```

### Параметры генерации
- **Длительность:** 3–5 секунд (loop)
- **FPS:** 24 (MP4) / 12 (GIF)
- **Разрешение:** 1080×1080 (Square) / 1080×1920 (Stories)
- **Размер файла:** < 5 MB (GIF) / < 2 MB (MP4)
- **Цикличность:** бесшовный loop

## Оценка сложности
- **Blast radius:** Высокий — затрагивает `EditorialPosterRenderer`, `ShareCardGenerator`, `ShareFormatDialog`, `ShareManager`
- **Новые зависимости:** Возможно `android.media.MediaCodec` (встроен в Android), без внешних библиотек
- **Объём:** ~8–12 атомарных задач (Timeline DSL, FrameRenderer параметрический, MP4 Encoder, GIF Encoder, Preview Composable, 3–4 конкретных анимации, интеграция в ShareFormatDialog, тесты)
- **Риск:** Производительность покадрового рендера на бюджетных устройствах. Mitigation: фоновый поток + прогресс-бар.

## Решение
Зафиксировано как направление развития. Требует:
1. Выбор приоритетного формата (MP4 vs GIF vs оба)
2. Выбор первых 2–3 анимаций для MVP
3. Спецификация `AnimationTimeline` DSL
4. Декомпозиция на атомарные задачи
