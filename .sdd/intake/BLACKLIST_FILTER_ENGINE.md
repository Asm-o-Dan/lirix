# SDD Intake: Blacklist Filter Engine & Auto-Purge Settings

## 1. Запрос пользователя
«возможность блокировать сохранение записей в медиатеке по названию или по автору или по провайдеру(приложению) для этого нужен отдельный экран настроек с конструктором запретов при с создании запрета идёт проверка всей медиатеки и удаляется все что попадает под данное правило»

## 2. Бизнес-требования
1. **Критерии фильтрации**:
   - `TITLE`: Название трека (например, "Реклама", "Диктофон", "Voice Note").
   - `ARTIST`: Автор / Исполнитель (например, нежелательный артист).
   - `PACKAGE_NAME`: Провайдер / Исходное приложение (например, `org.telegram.messenger`, `com.google.android.apps.podcasts`, `ru.dublgis.dgismobile`).
2. **Режимы сопоставления (Match Mode)**:
   - `CONTAINS_IGNORE_CASE`: подстрока без учета регистра (по умолчанию).
   - `EXACT`: точное совпадение.
   - `REGEX`: регулярное выражение (опционально/расширенно).
3. **Авто-очистка существующей медиатеки (Immediate Purge)**:
   - В момент сохранения или включения правила система сканирует все треки в `music_tracks`.
   - Удаляет найденные треки и их сессии в `music_listening_sessions`.
   - Возвращает и отображает пользователю количество удаленных треков (`X треков удалено из медиатеки`).
4. **Рантайм-фильтрация (Ingress Guard)**:
   - Когда играет заблокированный трек, плеер Lirix может отображать его в NowPlaying (с пометкой/бейдж «Заблокировано фильтром»), но **никогда** не сохраняет его в базу `music_tracks`, не пишет в историю и не накручивает статистику Wrapped.
5. **UI Экран Настроек (BlacklistSettingsScreen)**:
   - Список существующих правил с бейджами типа критерия и кнопками быстрого включения/выключения и удаления.
   - Кнопка «+ Создать запрет».
   - Диалог конструктора с селектором типа, текстовым полем, подсказками известных приложений (Spotify, VK, Telegram, Я.Музыка, YouTube) и превью количества треков, которые будут удалены.
   - 100% поддержка 4 тем Lirix (`LirixThemeTokens.colors`).

## 3. Зоны ответственности
- `storage`: Таблица `blacklist_rules`, DAO, миграция Room v10 -> v11.
- `media-core`: `BlacklistEngine`, `purgeMatchingTracks()`, интеграция в `MusicFeatureEngine`.
- `media-ingress`: Проверка перед сохранением трека.
- `media-ui`: `BlacklistSettingsScreen.kt`, навигация из ⋮ меню и Библиотеки.
