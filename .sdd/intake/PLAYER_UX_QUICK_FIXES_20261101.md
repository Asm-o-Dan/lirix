# Плеер и медиатека: быстрые UX-правки (2026-11-01)

Уровень 1. Источник: `.sdd/reports/UI_UX_REVIEW_20261101.md` (разделы «Плеер», «Медиатека», P2 «Итоги»), D02/D04 из `LIRIX_PLAYER_DESIGN_HANDOFF_20261029.md`. Этап 2 утверждённого плана.

## Объём

1. «▾» убрать из `player_in_source` (RU/EN) и из заголовка компактного/фокус-режима портрета. Заголовок ничего не делает — без ложной подсказки выбора.
2. D02: в караоке, когда показан только обычный текст, единственный статус — бейдж «Текст песни без таймингов» в области текста; строка статуса в метаданных в этом состоянии не дублирует его.
3. D04: у области метаданных (портрет и альбом) доступное имя «Информация о треке: <название> — <исполнитель>», роль кнопки. Полоса прогресса в портрете получает ту же семантику слайдера, что уже есть в `LandscapePlayerSeekBar` (`setProgress`, диапазон, описание позиции).
4. Сдвиг синхронизации: пользователю показывается «задержка текста» (= −хранимый offset). «−» = текст раньше, «+» = текст позже, подпись и окно калибровки используют ту же шкалу. Хранимое значение (`SyncOffsetStore`) и формат не меняются.
5. Пункт меню «О треке и источниках» переименовать в название окна («Инфо о треке» / «About track»), окно (shared) не трогаем. Из меню «⋮» убрать «Редактировать текст песни» / «Синхронизация — студия» только когда те же кнопки видимы в тексте (караоке, показан обычный текст без LRC и не идёт загрузка).
6. «Unknown Artist» (и пустой исполнитель) при показе заменять на `R.string.unknown_artist`. Ключи треков/БД не меняются.
7. Медиатека: счётчики «Треки / Артисты» и список артистов строятся из одной выборки — `filteredTracks` (фильтр + поиск); артисты группируются по отображаемому имени.
8. Плавающая навигация: капсула фиксированной ширины (на всю доступную ширину, не шире 420 dp), слоты с весами — ширина и положение капсулы не зависят от вкладки. Роль вкладки и `selected` для TalkBack.
9. «Итоги»: минуты с разделителем разрядов по локали (`NumberFormat`), исполнитель-заглушка локализован.

## Вне объёма

Схема БД, миграции, автоизбранное, TeachMode, студия, `ShareCardGenerator`/`BlacklistIngressGuardTest`, desktop.

## Приёмка

- Нет «▾» в RU/EN; нажатие на заголовок ничего не делает.
- В караоке без таймингов один статус.
- Знак кнопок совпадает со смыслом и числом на экране и в калибровке; offset в хранилище не меняется по формату.
- Меню не дублирует видимые кнопки; в остальных состояниях пункты остаются.
- «Unknown Artist» в RU показывается как «Неизвестный исполнитель».
- Артистов не больше, чем треков в той же выборке.
- Ширина капсулы одинакова на «Медиатеке» и «Итогах».
- `9363` → `9 363` (RU).
- `./gradlew :app:testDebugUnitTest :app:compileDebugAndroidTestKotlin` — проходит (кроме известного падения `ShareCardGeneratorTest`, которое чинит основная сессия).
- Проверка на телефоне — только после согласия пользователя; иначе NOT RUN.
