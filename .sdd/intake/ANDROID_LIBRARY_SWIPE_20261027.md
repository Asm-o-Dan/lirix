# Медиатека: меню трека и навигационные свайпы

## Новый пользовательский контракт 2026-10-27
Убрать действия лайка и скрытия по свайпам строк. У каждой записи медиатеки меню ⋮ с переключением избранного и удалением записи из медиатеки. Горизонтальные свайпы использовать для навигации между разделами, не мешая вертикальной прокрутке и системному Back.

Удаление аудиофайлов не входит в запрос. Сохранность и границы данных записей, связанных заметок и истории исследовать до реализации удаления; результат и возможность Undo должны соответствовать подписи. Не выдавать временное скрытие за удаление.

Предыдущий эксперимент временного скрытия заменён прямым решением пользователя; убрать только собственные изменения эксперимента, не трогая чужую работу. APK не создавать. Выполнить относящиеся к изменению проверки без APK и честно обозначить непроверенный runtime.
