## Контекст

Выбранный фокус на 3–6 месяцев — **качество Android**. Desktop и Connect идут после, в 2.0.

Текущее состояние ветки `codex/release-1.5.1` (последний коммит `9df6625`, запушен):

- **Опубликовано:** v1.5.1 (`versionCode 19`).
- **Не закоммичено:** 79 изменённых файлов (+3512/−1118) и около 40 новых. В одном рабочем дереве смешаны семь потоков:
  1. UX-правки плеера и медиатеки — готово (`reports/PLAYER_UX_QUICK_FIXES_20261101.md`);
  2. ручное избранное, фильтр мессенджеров, запрет автопоиска для «Unknown Artist», Room 14→15 — готово, спека APPROVED;
  3. TeachMode 2.0 — почти готово; сессия дважды остановилась на лимите; правки по ревью не перепроверены; `TeachModeMultiSelectTest` падает;
  4. редизайн студии караоке (Codex) — в работе;
  5. поиск по медиатеке, компактная шапка, панель «Настроить текст» (Codex, 7–8 ноября) — код готов, на устройстве NOT RUN;
  6. машинный перевод и два варианта сборки: private (OPUS-MT) и compact (ML Kit) — уровень 2, в работе;
  7. обновления через GitHub для двух APK, правки `ci.yml`/`release.yml`.
- **Риски:**
  - 1 ноября `:app:connectedDebugAndroidTest` удалил Lirix с личного телефона. Система восстановила данные, полноту владелец не подтвердил; тесты на телефоне приостановлены.
  - Почти вся приёмка на устройстве — NOT RUN (крупный шрифт, альбом, TalkBack, жесты, батарея, живые источники).
  - Большой незакоммиченный объём в одной папке, где работают несколько агентов.
  - В корне лежат личные файлы (docx, png, `*.db-wal`, `upwork-*`); `reports/STRATEGIC-ROADMAP-TO-PERFECTION.md` описывает другой проект (Ledger).
