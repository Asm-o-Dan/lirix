## Результат

Подключить дополнительные работающие источники в существующий поиск Android и desktop. Каждый источник должен дать подтверждённое содержимое нужного типа, корректно сопоставленное с исполнителем и названием. Добавление названия/URL без рабочего поиска не считается результатом.

## Приёмка

- Инвентарь фактически используемых провайдеров и точек интеграции.
- Для добавляемых источников: live-проверка поиска и загрузки, проверка отрицательного результата; в логах только метаданные, без полных текстов песен.
- Парсерные и интеграционные тесты на синтетических материалах: неверный исполнитель/версия, пустой ответ, некорректная разметка, отказ доступа, отмена запроса, сохранность ручных правок.
- Новые источники соблюдают существующие отключение/отклонение источника, кеширование и приоритеты. Сетевые запросы ограничены; новый поиск не запускается от каждого изменения позиции проигрывания.
- LRC содержит реальные таймкоды источника. Переводы остаются отдельными данными с языком и происхождением; временная привязка не выдумывается.
- Соответствующие тесты shared/desktop/Android и сборка APK. Недоступные источники обозначаются отдельно, без ложного заявления об интеграции.

## Первые наблюдения

- lyrics.ovh: `/v1/Coldplay/Yellow` возвращает HTTP200 и непустой текст (1089 символов); необходимо проверить текущий инвентарь и дополнительные случаи.
- Megalobiz: известный search endpoint вернул HTTP410; не включать как рабочий источник по одному наличию адаптера в сторонней библиотеке.
- NetEase: поиск вернул HTTP200, но прикладной code -462 требует привязки телефона. В этой конфигурации недоступен; обход или чужие cookies не используются.
- Lyrsense и Akkords.pro доступны через веб-просмотр; нативный поиск и извлечение ещё проверяются.

Платные ключи, аккаунты и публикация релиза не требуются для этого этапа. Окончательный состав выбирается по фактическому результату проверок.

## Состав реализации

- lyrics.ovh: plain fallback,3known200 и1missing404. API возвращает только текст, без независимых artist/title; используется точная пара в endpoint. Не является независимым LRC upstream.
- KuGou: дополнительный LRC; публичный HTTPS поиск+download, служебный ключ только из ответа поиска. Coldplay/Yellow и Radiohead/Creep дают реальные метки, nonexistent —0candidates.
- Akkords.pro: аккорды и оригинальный текст; Radiohead/Creep и Кино/Группа крови подтверждены page metadata, nonexistent —0.
- Lyrsense: русские переводы; Radiohead/Creep и Adele/Hello подтверждены page metadata+translator, nonexistent —0.
