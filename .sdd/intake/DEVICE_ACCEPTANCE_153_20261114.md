# Приёмка Lirix 1.5.3 на устройстве

- Уровень: 1 (проверка, код не меняется).
- Исполнитель: Antigravity.
- Основание: `.sdd/releases/v1.5.3.md`, спеки `.sdd/specs/media-core/track_metadata_and_avatar_v1.md` и `.sdd/specs/wrapped-analytics/sound_summary_and_achievements_v1.md`.
- Итог: отчёт `.sdd/reports/DEVICE_ACCEPTANCE_153_<дата>.md`, у каждого пункта статус PASS / FAIL / NOT RUN / BLOCKED.

## 0. Обязательные правила (нарушать нельзя)

1. Телефон владельца (adb serial `2440cbe2`) — личный, на нём настоящая медиатека.
2. **Запрещено:** `adb uninstall`, `pm clear`, любые `connected*AndroidTest`, сброс данных приложения, ручная правка базы.
3. Перед любой установкой: `python scripts/lirix_phone_snapshot.py --out ~/lirix-backups/phone`. Убедиться, что в выводе `quick_check: ok`, и записать число строк по таблицам.
4. Установка только поверх: `adb install -r <apk>`.
   - На телефоне стоит отладочная сборка 1.5.2. Ставить нужно отладочную APK 1.5.3 из тега `v1.5.3`: `../lirix-v153-build/app/build/outputs/apk/private/debug/app-private-debug.apk`.
   - Релизная APK с GitHub поверх неё не встанет из-за другой подписи. Если установка выдаёт `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, остановиться и сообщить владельцу. Не удалять приложение.
5. Снимки экрана и выгрузки базы хранить только вне репозитория (`~/lirix-backups/…`). В отчёт не попадают названия треков, тексты песен, ключ Last.fm и прочие личные данные: писать «трек A», «трек B».
6. Ничего не коммитить и не пушить без прямого разрешения владельца.
7. Найденный дефект записать в отчёт с приоритетом P0–P3. Код не править: это задача приёмки.
