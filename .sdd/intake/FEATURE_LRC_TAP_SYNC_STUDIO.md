# FEATURE INTAKE: LRC Tap-to-Sync Studio (Интерактивная нарезка караоке)

## 1. Цель и контекст
Когда трек найден только со статичным текстом (`plainLyrics`) и в мировых базах караоке нет готовых таймкодов, пользователь должен иметь возможность прямо на смартфоне превратить обычный текст в синхронизированное караоке (`syncedLyricsLrc`).
Синхронизация происходит во время воспроизведения трека: пользователь слушает песню и тапает по кнопке/экрану в такт началу каждой строки вокала.

## 2. Границы (Scope)
- **Входит**:
  - Кнопка вызова `[ ⏱ Синхронизировать в караоке ]` на вкладке `Текст` экрана `NowPlayingScreen`.
  - Полноэкранный режим `LrcTapSyncDialog` / `LrcTapSyncStudio`.
  - Трекинг воспроизведения в реальном времени через `MediaSessionCollector.livePlaybackFlow` (Play/Pause, перемотка).
  - Фокус-телесуфлер: предыдущая строка, крупная текущая строка, следующая строка с прогресс-баром строк.
  - Огромная кнопка действия `[ ТАП (Следующая строка) ]` с хаптической отдачей.
  - Кнопка отката `[ ↺ Шаг назад ]` (отменяет последний таймкод и возвращает на предыдущую строку).
  - Формирование валидной LRC-строки стандарта `[mm:ss.xx] Текст`.
  - Сохранение в Room: Dual-write в `lyrics_cache` (`syncedLyricsLrc`) и `music_tracks`. Мгновенная активация в караоке-плеере и плавающем оверлее.
  - Опциональная отправка (Publish / Community Contribution) в публичный API `https://lrclib.net/api/publish` (при наличии сетевого подключения).
- **Не входит**:
  - Ручное перетаскивание спектрограммы аудио (не требуется на мобильном экране).

## 3. Критерии приёмки (DoD)
1. Если у трека есть статичный текст, кнопка «Синхронизировать в караоке» активна.
2. При нажатии открывается диалог студии с текущей позицией трека.
3. Каждое нажатие «ТАП» фиксирует текущее время трека `[mm:ss.xx]` к текущей строке и переходит к следующей.
4. По завершении всех строк отображается экран предпросмотра созданного караоке и кнопка «Сохранить».
5. После сохранения трек переключается на вкладку «Караоке», текст скроллится синхронно с музыкой, плавающий оверлей подхватывает новые таймкоды.
6. Наличие unit-тестов кодека и генератора LRC (`LrcSyncEngineTest.kt`).
