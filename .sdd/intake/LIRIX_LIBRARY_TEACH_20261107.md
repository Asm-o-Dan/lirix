## 1. Поиск внутри медиатеки
Одна строка запроса со встроенной кнопкой областей поиска. Выпадающий список с чекбоксами «Название / Исполнитель / Текст / Аккорды» заменяет постоянный ряд переключателей. Можно включить несколько полей, совпадение в любом выбранном поле подходит. Все поля выбраны по умолчанию; кнопка показывает «Всё», один выбранный тег или «Название +N». В списке поля оформлены компактными округлыми тегами при зоне нажатия строки не менее 48 dp. Последнее выбранное поле нельзя снять, пока не добавлено другое; доступно «Выбрать всё». Выбор применяется сразу, список закрывается по нажатию вне его или повторному нажатию кнопки. «Исполнитель» обозначает поле artist. Для поиска по композитору или автору слов понадобится отдельный источник авторства. Существующий поиск по альбому оставить в режиме «Всё». Ограничения избранного и скрытых песен действуют при каждом запросе.

Общий результат — один трек на trackKey с причиной совпадения. Сначала точное название, затем начало названия, исполнитель, альбом и фрагменты содержимого. Рядом со строкой текста показывать совпавшие слова; для аккордов — саму последовательность и переход на вкладку «Аккорды». Не менять текущую песню в стороннем плеере при просмотре найденного.

Начать с проекции Room для треков и их lyrics_cache. Нормализовать пробелы, регистр и ё/е, убрать метки времени LRC. Учитывать приоритет сохранённой ручной версии текста. Применить существующий разбор аккордов к строкам аккордов: сохранить тональность, суффикс и бас. В первой версии искать подряд идущие токены в исходной тональности. Запрос Am G находит Am G F C, пропускает Am7 G и слова с буквами Am. Поиск в другой тональности вынести в отдельную опцию позднее. Индекс FTS вводить только по результатам измерения задержки на большой тестовой библиотеке.

Приёмка: повторяющийся припев даёт один трек; поиск по фрагменту LRC работает без времени; обычный текст не проходит фильтр «Аккорды»; ручное редактирование сразу обновляет выдачу; все четыре поля работают офлайн.

## 2. Перевод в Teach Mode
Зафиксировать trackKey, название, исполнителя и целевой язык при открытии. Добавить «Перевод» к типам «Текст» и «Аккорды». Поиск заполняется названием, исполнителем и языком. Человек выбирает страницу и видит перевод, язык и источник до сохранения. Для двуязычной страницы отделять оригинал; при отсутствии достоверного построчного соответствия отображать перевод самостоятельным текстом. Сохранить атрибуцию и URL в song_translations. При смене песни или языка запоздавший результат остаётся привязан к исходной цели.

Кнопка «Сохранить для песни» завершает ручную привязку даже при неудаче обучения сайта. Следующий, необязательный шаг — «Искать на этом сайте в следующий раз». Lirix сам выводит шаблон из переходов и границы текста из выделения. Проверяет заново на выбранной и второй, отличной песне; сверяет название, исполнителя, тип содержимого и язык. Показывает предпросмотр. Уверенное правило можно включить одним нажатием. При неоднозначности попросить выбрать нужный результат, при нехватке второго примера — сохранить черновик. Технические параметры доступны через «Подробности». При отказе сайта сохранить статус ошибки и соблюдать существующие ограничения запросов.

Приёмка: русская песня → английский перевод; две песни с одинаковым названием; страница с одним заголовком; ошибка сети; правило не прошло проверку после успешного ручного сохранения. Старые правила текстов и аккордов продолжают работать.

## 3. Машинный перевод как запасной вариант
Порядок выдачи — явный выбор пользователя, готовый опубликованный перевод, машинный перевод. Кандидаты требуют выбора, а недоступный источник даёт «Повторить поиск». Только подтверждённое отсутствие готового перевода автоматически запускает машинный при включённой настройке и установленной модели. Первый запуск предлагает скачать нужный язык; если модели или исходного текста нет, экран объясняет следующий шаг.

Для Android проверить ML Kit на синтетических куплетах, включая RU→EN и EN→RU. Модели загружаются отдельно, после загрузки обработка идёт на устройстве. Маркировать происхождение, соблюдать условия атрибуции. Перевод стихов и идиом оценить вручную до выпуска. [Документация Google](https://developers.google.com/ml-kit/language/translation)

Хранить машинный результат отдельно от опубликованных версий. Ключ кеша учитывает trackKey, исходный и целевой языки, отпечаток оригинала и версию модели. При смене оригинала аннулировать устаревший вариант. Не подставлять фиктивный URL сайта. Действующий saveAutomaticIfEmpty проверяет любую запись для данного языка: машинный кеш не должен блокировать последующую загрузку человеческого перевода. Явно выбранный вариант сохраняет приоритет. Для общего формата данных предусмотреть чтение старых записей и проверку Android ↔ ПК, даже если первая модель работает только на Android.

Приёмка: найден готовый перевод — модель не вызывается; кандидаты и сетевой сбой различимы; при Missing и доступной модели появляется результат с пометкой; без модели в офлайне сохраняется оригинал; найденный позже авторский перевод доступен; исходный текст и пользовательские правки сохраняются.

## Уточнение страницы перевода
Предложение найти или создать перевод показывать автоматически один раз на trackKey при первом открытии текста этой песни, когда готовый перевод отсутствует. Считать показ состоявшимся после отображения панели. Сохранять признак локально между открытиями и перезапусками. Повторная смена языка, ошибка сети и возврат к песне не сбрасывают его. Другая песня получает собственный первый показ.

Панель компактная, с явной кнопкой закрытия. Закрытие сразу возвращает место тексту. В меню ⋮ постоянно доступен пункт «Перевод и язык», открывающий ту же панель по запросу. Выбор языка и режима отображения относится к этой панели, строка происхождения уже выбранного перевода остаётся рядом с содержимым. Скрытие панели не удаляет сохранённый перевод.

Приёмка макета: первый вход в A — панель есть; закрытие — текст открыт; возврат в A и перезагрузка — панель скрыта; вход в B — первый показ; меню ⋮ — повторное открытие. HTML использует localStorage только для демонстрационных идентификаторов песен. В продукте постоянное состояние связывать со стабильным trackKey.

Модульная сетка каркаса: 4 колонки, внешние поля по 16, межколонник 8 и вертикальные интервалы кратно 8. Полноширинное содержимое занимает 4 колонки, парные действия делят ширину по 2 колонки. Переключатели допускают собственное внутреннее деление внутри общего модуля. Наложение колонок в HTML можно скрыть.


## Дополнительные предложения по разгрузке интерфейса
Статус — варианты для обсуждения после просмотра макета. Основаны на текущих LibraryScreen, NowPlayingScreen, NowPlayingOverflowMenu и TeachModeScreen.

- Медиатека. Перенести «Скрытые треки» и «Чёрный список» из ряда поиска в меню экрана. Сейчас эти две кнопки занимают место рядом со строкой. В закрытом виде над списком оставить строку поиска и одну компактную строку «Треки ▾ · Все ▾ · Сортировка». «Треки / Исполнители» — способ представления, «Все / Избранное / Караоке / С аккордами» — состав списка, поля поиска — область совпадения. Эти три настройки сохраняют отдельные названия и значения.
- Результаты поиска. Фрагмент совпадения показывать только при непустом запросе. Обычная запись содержит название и исполнителя; дополнительные сведения открываются нажатием на запись или через ⋮. Счётчик результатов совмещать со строкой представления списка.
- Плеер. Регуляторы сдвига и размера текста открывать в компактной панели «Настроить текст». Если пользователь изменил сдвиг, сохранять доступный индикатор значения для быстрого возврата. Для аккордов в той же контекстной области показывать тональность и каподастр. Воспроизведение, прогресс и переключение содержимого остаются напрямую доступны.
- Обычный текст. Текущий FlowRow «Редактировать / Студия / Копировать» перенести в меню текста, сохранив одну заметную команду «Синхронизировать» для песни без таймингов. Выделение текста может открывать контекстное копирование; доступный пункт «Скопировать текст» остаётся в меню.
- Teach Mode. Показывать снизу по одной основной команде в зависимости от этапа: «Выберите фрагмент», «Сохранить для песни», после сохранения — предложение проверить сайт. «Сузить / Расширить / Убрать лишнее» раскрываются через «Изменить выделение». Адрес сайта отображается компактно, поле URL раскрывается нажатием. Предпросмотр открывается отдельно, чтобы не дублировать большой текст под страницей.
- Метаданные и статусы. В плеере одна компактная строка с исполнителем и альбомом, полные данные — в существующем окне сведений. Статус рядом с текстом отражает текущее состояние. Успех сохранения сообщается временно, а ошибка, влияющая на доступность содержимого, остаётся видимой с действием восстановления.

Первыми предлагаются сокращение шапки медиатеки и контекстная панель настройки текста. Малый визуальный размер тегов не уменьшает область нажатия до менее чем 48 dp. Редкие действия в ⋮ не дублируются другими постоянно видимыми кнопками.
