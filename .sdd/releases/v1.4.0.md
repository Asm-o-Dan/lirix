# Lirix v1.4.0 — Smart Chords Wrapping, Tap-to-Sync Studio & Dynamic Themes

Major Android release bringing syllable-accurate chord wrapping for live musicians, on-the-fly karaoke synchronization, and complete dynamic theming across the entire UI.

## What's New in v1.4.0

### 🎸 Smart Chords Wrapping
- **Syllable-Bound Text & Chord Wrapping**: Long lines now automatically wrap to fit any smartphone screen without breaking musical alignment. Chords stay anchored directly above their corresponding syllables.
- **One-Tap Wrap Toggle**: Easily switch between wrapped flow (`↩`) and horizontal scroll (`⇄`) right from the compact chord toolbar.
- **Hands-Free Auto-Scroll**: Tuned auto-scrolling with speed multipliers (0.5x – 2.0x) and pitch transposition (±12 semitones).

### ⚡ Tap-to-Sync Studio
- **On-the-Fly Karaoke Sync**: Create syllable-accurate `.lrc` timing by simply tapping to the rhythm while listening to any track.
- **Ergonomic Studio UI**: Clean layout designed with Literata and Golos Text typography, with gesture navigation inset protection.

### 🎨 Complete Dynamic Theming
- **Adaptive Library**: Search bar, chip filters, badge counters, and action sheets now fully adopt the active theme (Spotify Green, Yandex Yellow, Obsidian Dark, Pastel Violet).
- **Theme-Aware Posters & Wrapped**: Stats exports and track posters inherit active accent palettes.

### 🔍 Search Lifecycle & Stability
- **Real-Time Search Feedback**: Added clear visual progress feedback ("Searching lyrics...") and eliminated stale-cache flashes during track transitions.
- **Audio & Session Stability**: Protected against pause event duplication and play count inflation across background media sessions.

### 🔌 Connect & Desktop Roadmap Note
- **Release 2.0.0 Preview**: The Connect button in the top bar now features a dedicated roadmap status sheet. High-fidelity LAN PCM casting and Desktop Prompter are planned for Release 2.0.0.
