# Lirix v1.5.2 — машинный перевод, Teach Mode 2.0 и поиск по медиатеке

## Две сборки Android

Начиная с этой версии публикуются два APK с одной подписью и одним идентификатором приложения:

- `lirix-v1.5.2-private.apk` (рекомендуется) — машинный перевод OPUS-MT на устройстве, без SDK-телеметрии. Пока EN→RU и RU→EN; пакет около 234 МБ на направление, загрузка только по Wi-Fi.
- `lirix-v1.5.2-compact.apk` — перевод через Google ML Kit, модели около 30 МБ на язык. SDK может отправлять Google диагностику.

Машинный перевод выключен, пока вы его не включите, и используется только если готовый перевод не найден. Результат всегда помечен как машинный.

## Teach Mode 2.0

- Выделили текст и нажали «Сохранить для песни» — Lirix сам пробует запомнить сайт как постоянный источник. Правило включается только если автоматическая проверка получила тот же текст, что вы выделили.
- Поддержаны сайты, которые показывают текст скриптами. Такие страницы открываются скрыто, по одной, с ограничением частоты и не в режиме энергосбережения.
- Привязка текста к песне по-прежнему не зависит от того, удалось ли запомнить сайт.
- Импортированные наборы правил проверяются перед включением.

## Плеер

- «Не тот текст — искать дальше» и «Не те аккорды — искать дальше» в меню «⋮». Источник запоминается как неверный для этой песни, есть «Отменить». Ручной текст, правки и разметка студии не затрагиваются.
- Предзагрузка текста следующего трека, если плеер публикует очередь. Воспроизведением Lirix не управляет; без очереди всё работает как раньше.
- Панель «Настроить текст», более понятные состояния содержимого, исправления сдвига таймингов.

## Медиатека и избранное

- Поиск по названию, исполнителю, тексту и аккордам; работает без сети.
- Ручной выбор избранного сохраняется и не перезаписывается автоматикой.
- Готовые правила чёрного списка для мессенджеров; для треков без исполнителя автоматический поиск не запускается.

## Студия караоке

- Режимы «Быстро» и «Точно», крупные кнопки воспроизведения и перемотки на 5 секунд, отмена, пропуск строк с титрами.

## Обновление

- Проверка обновлений при запуске (раз в сутки; при сбое сети — повтор через час). Без нажатия ничего не скачивается.
- **С версии 1.5.1 автоматическое предложение обновиться не появится:** её встроенная проверка ожидает один APK в выпуске. Скачайте нужную сборку вручную и установите поверх — подпись та же, данные сохраняются.
- База данных обновляется с версии 14 до 15 автоматически.

Требуется Android 8.0 или новее (API 26). Целостность файлов — по `SHA256SUMS.txt`.

## Проверка и известные ограничения

- Автоматические тесты: Android (обе сборки), общий модуль и ПК — без ошибок на момент выпуска.
- **Не проверено на устройстве:** загрузка моделей и машинный перевод, скрытая отрисовка сайтов, чтение очереди реальных плееров, новые пункты меню, студия при увеличенном шрифте и с жестовой панелью, обновление базы на реальной библиотеке. Перед установкой сделайте резервную копию, если библиотека важна.
- Модели приватной сборки загружаются из стороннего репозитория Hugging Face и проверяются по SHA-256.
- ПК: правила для сайтов на скриптах не исполняются, предзагрузки и раздельного отклонения аккордов нет.
