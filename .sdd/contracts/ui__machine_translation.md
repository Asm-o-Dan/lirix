# UI ↔ on-device machine translation

Authority: ../specs/translations/machine_fallback_android_v1.md. Android provider optional; Desktop provider absent. Immutable request includes stable trackKey, exact original, metadata and target. Provider owns on-device language detection, model availability/download and independent cache. UI owns Missing-only/human-first policy and cancellation on original/track/target changes. Machine documents are display-only SongTranslation values with empty source URL; they never enter SongTranslationDao and cannot block or overwrite published/manual versions. No karaoke timestamps. SDK integration version is used for cache invalidation; not a promise of model revision. Preference defaults disabled; downloads only from explicit attributed action, over Wi-Fi.
