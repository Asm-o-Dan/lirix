# lyrics.ovh adapter + shared HTTP — 2026-10-21

Реализованы `shared/src/jvmShared/kotlin/com/lirix/app/feature/lyrics/{AdditionalLyricsResult,LyricsSourceHttp,LyricsOvhProvider}.kt`. DTO не пишет БД; adapter возвращает только plain, `builtin:lyrics-ovh`, sourceUrl API и null для LRC/chords/author. Отдельные offline synthetic tests: `desktop/src/test/kotlin/com/lirix/app/desktop/{LyricsOvhProviderTest,LyricsSourceHttpTest}.kt` (5+8 сценариев). Gradle выполняет root, здесь не запускался.

Документация https://github.com/NTag/lyrics.ovh проверена. API exact artist/title, JSON lyrics/404; текущий upstream сначала сам спрашивает LRCLIB. Plain fallback дополняет покрытие, но не является независимым LRC источником и не доказывает identity: API не возвращает artist/title для повторной проверки.

Нативный HTTP metadata-only smoke: Adele/Hello — 200,1854chars; Beatles/Yesterday — 200,711chars; случайный artist/title — 404,0chars. Root отдельно: Coldplay/Yellow — 200,1089chars. Не сохранялись полные тексты. Kotlin production transport этим smoke не проверен: его реальный запуск остается root live test.

HTTP: exact HTTPS allowlist на каждом redirect, максимум2, до2MiB actual bytes, connect4s/read6s/request deadline12s; OVH override256KiB/1.5s/2.5s/4s/0redirects. 403/429 включают host cooldown>=60s с Retry-After, без retries. Caller cancellation распространяется, own deadline становится null, активный connection закрывается. Reviewer energy_review проверил механику и не нашел конкретной регрессии. Указанное ограничение подтверждено: deadline отменяет/закрывает native request, однако системный DNS/native connect или blocking disconnect могут освобождаться позже срока. Structured IO worker не отделяется от родителя; fake-stream cancellation tests не доказывают универсальный wall-clock bound нативной сети.

Independent review integration plan: принят с final IDs `builtin:lyrics-ovh`, `builtin:akkords-pro`, `builtin:kugou`, redirects2 и согласованной Room14 attribution колонкой. Замечание передано исполнителям: multi-request find имеет общий15s budget; отдельные12s GET не заменяют этот бюджет. При chord enrichment основной lyrics provider нельзя менять на chord source: provenance хранится раздельно. Rejection gate до HTTP и atomic manual guard в persistence — обязательные интеграционные проверки, adapter их не имитирует. Встроенные source enable flags в текущем коде отсутствуют; disabled custom rules не должны трактоваться как другие hardcoded providers.
