## 3. Обнаруженные дефекты

### [DEFECT-153-01] [P0] Крах приложения при фоновом поиске метаданных трека на Android runtime (`PatternSyntaxException`)

- **Компонент:** `shared/src/commonMain/kotlin/com/lirix/app/metadata/TrackMatch.kt` (строки 24–28, 32)
- **Приоритет:** **P0** (Crash / Unhandled Exception в фоновом воркере)
- **Предусловие:** В настройках включена опция «Данные о треках» (`enabled = true`).
- **Шаги воспроизведения:**
  1. Открыть «Настройки → Данные о треках» и перевести переключатель в положение «Включено».
  2. Воспроизвести любой трек (например, англоязычный или русский) дольше 20 секунд.
  3. По истечении 20 секунд `TrackMetadataCoordinator` запускает корутину `lookup`, которая обращается к `TrackMetadataResolver.itunes`.
  4. Метод `itunes` обращается к `TrackMatch.sameTitle` / `TrackMatch.sameArtist`.
  5. Происходит инициализация объекта `TrackMatch` (`<clinit>`).
- **Фактический результат:**
  Процесс приложения немедленно завершается аварийно (`Process: com.lirix.app, PID: 31257 died`):
  ```text
  FATAL EXCEPTION: DefaultDispatcher-worker-6
  Process: com.lirix.app, PID: 31257
  java.lang.ExceptionInInitializerError
      at com.lirix.app.metadata.TrackMetadataResolver.itunes(TrackMetadataResolver.kt:118)
      at com.lirix.app.metadata.TrackMetadataResolver.access$itunes(TrackMetadataResolver.kt:56)
      at com.lirix.app.metadata.TrackMetadataResolver$itunes$1.invokeSuspend(TrackMetadataResolver.kt:15)
      ...
  Caused by: java.util.regex.PatternSyntaxException: Invalid value for match mode flags near index 4
  (?iU)\b(feat\.?|ft\.?|featuring|with|при уч\.?|при участии|remaster(ed)?|album version|single version|original( version| mix)?|explicit|clean|mono|stereo|bonus track|deluxe|из (к/ф|фильма|сериала|мультфильма)|from|ost|official( video| audio| music video)?|lyrics?( video)?|audio|video|hd|hq|\d{4})\b
      ^
  ```
- **Причина:**
  В регулярных выражениях `neutralNote` и `artistSplit` внутри `TrackMatch.kt` использован строковый флаг `(?iU)`. На стандартной JVM (Desktop Java SE) флаг `(?U)` (`UNICODE_CHARACTER_CLASS`) поддерживается с Java 7, поэтому JVM unit-тесты (`TrackMatchTest`) проходили успешно. Однако движок регулярных выражений Android (ART / ICU4C) не поддерживает синтаксис флага `(?U)` в строке регулярного выражения и выбрасывает `PatternSyntaxException`.
- **Влияние:**
  Любое фоновое распознавание метаданных на Android приводит к падению приложения. Блокирует пункты 3.3, 3.5, 3.6, 3.7, 3.11, 5.2, 5.3.
- **Статус:** Код в рамках приёмки не модифицировался (согласно п. 0.7 правил приёмки).
