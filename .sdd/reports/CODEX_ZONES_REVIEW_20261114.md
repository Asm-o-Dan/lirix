## Что сделано хорошо

- Модели приватной сборки: каталог с размером и SHA-256, загрузка только с huggingface.co по HTTPS, только по Wi-Fi, во временный файл с переименованием, повторная проверка хеша перед использованием.
- Движок: телеметрия выключена, ограничения на длину входа и число шагов декодирования; JNI ограничивает размеры и переводит исключения C++ в ошибки Java; исходники SentencePiece закреплены по хешу.
- Машинный перевод включается только пользователем; кеш в `cacheDir`, ключи — хеши, ограничение 128 файлов / 20 МБ; в базу переводов машинный результат не пишется.
- Обновления: имя файла строго `lirix-<тег>-<вариант>.apk`, сверка размера, SHA-256, подписи и варианта сборки; без нажатия ничего не скачивается.
- Lyrsense: сбой источника теперь отличается от «перевода нет» (AGENTS 5.2).

## Замечания без правок (на решение владельца и Codex)

| № | Замечание | Важность |
|---|---|---|
| 1 | Модели берутся из стороннего репозитория Hugging Face (`Zweiarm/opus-mt-onnx-int8`), закреплены по коммиту и хешу. Если автор удалит репозиторий, загрузка перестанет работать. Нужна своя копия (зеркало) до публичного выпуска. | средняя |
| 2 | Тексты `MachineTranslationEngineInfo` и ошибки Lyrsense заданы по-русски в общем коде; перевод идёт через `LirixStrings.message`. Для новых строк нужно проверить наличие английских вариантов. | низкая |
| 3 | Порог уверенности определения языка: 0,5 в компактной сборке и 0,90 в приватной. Поведение сборок на коротких текстах будет различаться. | низкая |
| 4 | `sentencepiece_jni.cpp` использует устаревший `std::wstring_convert` (работает, даёт предупреждение компилятора). | низкая |
| 5 | Студия: окно снова `decorFitsSystemWindows = true` с нижним отступом не меньше 56 dp. Коммит `0802e31` решал перекрытие кнопки «Применить» жестовой панелью иначе. Без устройства не проверить — обязательный пункт приёмки К4. | средняя, NOT RUN |
| 6 | Студия: «Пропустить титры» удаляет строки вида «муз.», «сл.», «music by», «lyrics by» после подтверждения, с отменой. Правило узкое, ложных срабатываний по коду не видно. | низкая |
| 7 | Поиск: фрагмент совпадения вырезается по позициям в приведённой к нижнему регистру строке; для редких символов, меняющих длину при смене регистра, фрагмент может сместиться на 1–2 знака. Падения нет. | низкая |
| 8 | CI ставит NDK и CMake через `sdkmanager` на каждый прогон; время сборки вырастет. На GitHub не запускалось. | низкая, NOT RUN |
