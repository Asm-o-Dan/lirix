# Данные о треках, аватар, новые «Итоги» и достижения — отчёт 2026-11-14

Спеки: `specs/media-core/track_metadata_and_avatar_v1.md` (уровень 2), `specs/wrapped-analytics/sound_summary_and_achievements_v1.md` (уровень 1).
Состояние: реализовано, не закоммичено, на телефон не установлено.

## Что сделано

- Загрузка данных о треке из открытых каталогов (iTunes, MusicBrainz, ReccoBeats, Deezer, Last.fm по ключу пользователя): жанр, год, длительность, темп, тональность, шкалы звучания, теги. Выключена по умолчанию. chosic.com не используется (защита Cloudflare).
- Room v16, таблица `track_metadata`; миграция 15→16 на Android и Desktop только создаёт таблицу.
- «О треке»: раздел с данными и источниками. Настройки: «Данные о треках».
- «Итоги»: профиль с аватаром (ручной выбор четырёх слоёв или вариант по статистике), блоки «Как это звучало», «Жанры», «Годы выпуска», «Рекорды периода» для выбранного периода.
- Достижения: 16 новых в разделе «Звучание», список разбит на разделы, английские названия и описания для всех 42.
- Очистка трека чёрным списком удаляет и его метаданные.

## Найдено и исправлено по ходу

- Настройки согласия создавались отдельным экземпляром на каждый вызов: переключатель в настройках не доходил до загрузчика до перезапуска приложения. Теперь один экземпляр на процесс; есть тест.
- Тесты политики резервного копирования потребовали явного решения по двум новым хранилищам: `lirix_profile` добавлен во все четыре списка (включая `xml-v28`), `lirix_track_metadata` объявлен «только это устройство» (согласие на сетевые запросы и ключ не должны восстанавливаться из копии).

## Ограничения и отложенное

- Идентификатор схемы v16 в `Schema14CompatibilityTest` взят из сгенерированного Room кода: независимого источника для новой версии нет.
- При равенстве голосов жанра между изданиями одной записи берётся жанр первого издания в ответе каталога.
- Покрытие русскоязычной музыки не измерено; ReccoBeats и Deezer знают не все записи, для них останутся только жанр и год.
- Desktop: загрузки, настроек, профиля и блоков звучания нет.
- Ручная правка жанра, перенос метаданных в архив библиотеки, постер с новыми данными — не сделаны.
- Дата получения достижений на Android по-прежнему не сохраняется.
