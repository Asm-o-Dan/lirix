# Данные о треках из каталогов и аватар профиля v1

Статус: IMPLEMENTED 2026-11-14, уровень 2. Независимое ревью не проводилось. Проверка на устройстве — NOT RUN.
Запрос владельца: «система аватара и парсинга доп. данных о песне», образец — страница анализа трека на chosic.com.
Решения владельца (2026-11-14): источники — все доступные; загрузка выключена, включает пользователь; аватар абстрактный с ручным выбором; настроение — теги Last.fm по собственному ключу пользователя.
Закрывает карточку `backlog/track-metadata-genre-mood.md` и первую часть C4 (`intake/ROADMAP_20261109.md`).

## Что получает пользователь

- В «О треке»: жанр, год выпуска, длительность, темп, тональность, теги слушателей и шкалы звучания (энергия, позитивность, танцевальность, акустичность, инструментальность, живое исполнение, речь) с указанием источников.
- В «Итогах»: блок «Профиль» с аватаром и тремя главными жанрами по времени прослушивания, с подписью «жанр известен для N из M треков».
- В настройках: «Данные о треках» — переключатель, объяснение, поле ключа Last.fm, очистка загруженного.

## Источники

chosic.com закрыт проверкой Cloudflare; защиту не обходим (AGENTS §9). Те же показатели отдают открытые API без ключа:

| Источник | Что берём | Как ищем |
|---|---|---|
| iTunes Search | жанр, год, длительность | исполнитель + название |
| MusicBrainz | ISRC записи | название + исполнитель, запись той же длительности |
| ReccoBeats | темп, тональность, лад, шкалы 0..1, громкость | по ISRC |
| Deezer | темп (если его нет выше), жанры альбома | по ISRC |
| Last.fm | теги слушателей (≥10 голосов, до 6) | только с ключом пользователя |

Разрешены только HTTPS-запросы к этим пяти хостам, ответ до 512 КБ, общий таймаут 10 с. Наружу уходят только название и исполнитель, сообщённые плеером. Ключ Last.fm принимается только в виде 32 шестнадцатеричных знаков и хранится в настройках, которые не входят в резервную копию.

## Сопоставление

Запись каталога принимается, только если совпали название, хотя бы один исполнитель и версия (live, remix, acoustic и т. п. — другая запись). Регистр, «ё/е», пометки вроде «Remastered 2011», «feat.», «из сериала» не различают записи. Кириллица и латинская транслитерация исполнителя считаются одним именем («Король и Шут» = «Korol I Shut»). Длительности совпадают при расхождении до 3 с.

- Плеер сообщил длительность — берутся записи этой длительности.
- Не сообщил, а записи каталога разной длительности — год и длительность не берутся; жанр берётся, только если все записи согласны. Иначе итог «неоднозначно», поля пустые (AGENTS 7.4).
- Ответ по ISRC принимается, только если в нём тот же ISRC, а для Deezer ещё те же название и длительность.
- Значения вне допустимых границ (шкалы 0..1, темп 30..300, тональность 0..11) отбрасываются.
- Первый каталог не ответил — итог «недоступно», ничего не сохраняется. Сбой любого следующего источника оставляет пустыми только его поля.

## Загрузка

- Выключена, пока пользователь не включит. Работает только для трека, который играет дольше 20 с; не чаще 30 запросов в час; медиатека целиком не выгружается.
- Не запрашиваются треки без названия или исполнителя и «Unknown Artist»; режим «только офлайн» и отсутствие сети запрещают запрос.
- Найденный ответ окончателен. «Не найдено» и «неоднозначно» повторяются не раньше чем через 7 дней. Сбой источника не стирает прежний ответ.
- Результат сохраняется под ключом того трека, для которого был сделан запрос (AGENTS 7.2). Если согласие отозвано, пока шёл запрос, ответ отбрасывается.

## Хранение

Room v16, таблица `track_metadata` (ключ — `trackKey`): статус FOUND / NOT_FOUND / AMBIGUOUS, жанры, год, длительность, ISRC, темп, тональность, лад, семь шкал, громкость, теги, источники по группам, время загрузки. Миграция 15→16 только создаёт таблицу; существующие строки не меняются (Android и Desktop).

Это восстанавливаемый кеш, а не пользовательское содержимое: в архив библиотеки и в резервную копию Android не входит, ручных правок не содержит, при очистке трека чёрным списком удаляется вместе с ним. Настройки `lirix_track_metadata` (согласие и ключ) в резервную копию не входят; `lirix_profile` (аватар) — входит.

## Аватар

Четыре независимых слоя: форма (5), узор (5), палитра (8), символ (4). Хранится строкой `форма-узор-палитра-символ`; повреждённое значение заменяется нейтральным. Аватар меняется только по действию пользователя: выбор слоёв вручную или кнопка «Собрать по моей статистике», которая подставляет вариант в черновик до подтверждения.

Правило автоматического варианта (одни и те же данные дают один и тот же аватар):

| Слой | Факт | Значения |
|---|---|---|
| Палитра | семейство главного жанра | рок/метал/альтернатива 0, хип-хоп/R&B 1, электроника 2, поп 3, джаз/блюз/соул 4, классика/саундтрек 5, фолк/кантри/авторская 6, прочее 7 |
| Узор | средняя энергия | ≥0,75 лучи; ≥0,55 эквалайзер; ≥0,35 волны; ниже — кольца |
| Символ | средняя позитивность | ≥0,6 солнце; ≤0,35 луна; между — нота; нет данных — без символа |
| Форма | число исполнителей | ≤10 круг; ≤40 скруглённый квадрат; ≤120 шестиугольник; ≤300 ромб; больше — восьмиугольник |

Средние взвешены по учтённому времени прослушивания. Если жанр известен меньше чем для 5 прослушанных треков, жанры и средние не выводятся; палитра и узор тогда зависят только от самого прослушиваемого исполнителя, символ не ставится. Пустая история — нейтральный аватар. Доли жанров считаются среди треков с известным жанром по первому жанру трека; при равенстве порядок по названию.

## Что не входит

- Desktop: таблица и миграция есть, загрузки, настроек и блока профиля нет.
- Ручная правка жанра пользователем; перенос метаданных в архив библиотеки.
- Настроение по тексту песни или по звуку на устройстве.
- Имя профиля, фото, обмен профилем.
