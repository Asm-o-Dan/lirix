# «Итоги»: звучание периода и достижения по данным о треках v1

Статус: IMPLEMENTED 2026-11-14, уровень 1 (схема не меняется). Проверка на устройстве — NOT RUN.
Запрос владельца: «переработать итоги и разнообразить достижения в связи с новой информацией».
Опирается на `specs/media-core/track_metadata_and_avatar_v1.md` (таблица `track_metadata`).

## Экран «Итоги» (Android)

Порядок блоков: период → время, главный исполнитель, топ треков → профиль с аватаром → **«Как это звучало»** → **«Жанры»** → **«Годы выпуска»** → **«Рекорды периода»** → факты → постер → достижения по разделам.

Новые блоки считаются для выбранного периода (сегодня, 7 дней, 30 дней, всё время) — того же окна, что и остальные итоги.

| Блок | Что показывает |
|---|---|
| Как это звучало | настроение периода; шкалы энергии, позитивности, танцевальности, акустичности; средний темп; доля времени в мажоре; подпись «данные известны для N из M треков» |
| Жанры | до 5 жанров с долями времени; подпись «жанр известен для N из M треков» |
| Годы выпуска | до 4 десятилетий с долями времени |
| Рекорды периода | самый быстрый, самый энергичный, самый спокойный, самый светлый трек |

Правила расчёта:

- Вес трека — учтённое время его прослушивания в периоде. Для «всего времени» в библиотеке без сессий берётся накопленное время трека.
- Учитываются только треки с известным исполнителем и подтверждённой строкой метаданных (FOUND).
- Каждая цифра показывается, только если соответствующий факт известен не меньше чем для 5 прослушанных треков периода. Иначе цифры нет (не ноль). Если нет ни одной цифры — один блок с объяснением: загрузка выключена; за период нет прослушиваний; данных мало (N из M, нужно 5).
- Жанр трека — первый жанр из каталога. Доли округляются до целых процентов; при равенстве порядок по названию (десятилетию).
- Настроение — четверть по средним энергии и позитивности, граница 0,5: «Бодро и светло», «Напористо и мрачно», «Спокойно и светло», «Тихо и задумчиво». Это автоматическая оценка, о чём сказано в подписи.
- Рекорд при равных значениях достаётся треку с меньшим ключом, чтобы результат не зависел от порядка строк.

## Достижения

Список разбит на разделы с заголовком «раздел · выполнено из всего»: Прослушивание, Открытия, Звучание, Тексты, Особые. Внутри раздела сначала выполненные, затем ближайшие к выполнению. Названия и описания проходят через общий каталог перевода (английские варианты добавлены для всех 42).

Новый раздел «Звучание» (16 достижений, только Android — на Desktop данных о треках нет). Считаются треки библиотеки с известным исполнителем и подтверждёнными данными:

| Id | Название | Условие |
|---|---|---|
| SOUND_CARD_INDEX | Картотека | данные найдены для 25 треков |
| SOUND_GENRES_3 / SOUND_GENRES_7 | Палитра / Всеядный | 3 / 7 разных жанров (без учёта регистра) |
| SOUND_GENRE_LOYAL | Верность жанру | 50 треков одного жанра |
| SOUND_NO_WORDS | Без слов | 5 треков с инструментальностью ≥ 0,7 |
| SOUND_SPRINTER / SOUND_SLOW_DANCE | Спринтер / Медленный танец | 10 треков быстрее 160 / медленнее 80 уд/мин |
| SOUND_CHARGE / SOUND_QUIET_HARBOR | Заряд / Тихая гавань | 25 треков с энергией ≥ 0,8 / 15 треков с энергией ≤ 0,35 |
| SOUND_SUNNY_SIDE / SOUND_BLUE_HOUR | Солнечная сторона / Синий час | 20 треков с позитивностью ≥ 0,7 / ≤ 0,3 |
| SOUND_DANCE_FLOOR | Танцпол | 20 треков с танцевальностью ≥ 0,7 |
| SOUND_UNPLUGGED | Без розетки | 10 треков с акустичностью ≥ 0,7 |
| SOUND_RETRO | Ретро | 10 треков, выпущенных до 1990 года |
| SOUND_TIME_TRAVELER | Путешественник во времени | треки из 5 разных десятилетий |
| SOUND_ALL_KEYS | Все двенадцать | треки во всех 12 тональностях |

- Строки добавляются в таблицу `achievements` при открытии «Итогов» вставкой без замены: существующие строки и их прогресс не меняются, схема прежняя.
- Без данных о треках прогресс этих достижений равен нулю; если загрузка выключена, над списком показана подсказка.
- Остальные достижения считаются как раньше. «Абсолютный слух» (20 любых) учитывает и новые.

## Что не входит

- Постер «Итогов» и анимированная сводка не меняются.
- Desktop: блоков звучания и раздела «Звучание» нет.
- Сохранение даты получения достижений на Android (как и раньше, считается при открытии экрана).

## Приёмка

| Критерий | Проверка |
|---|---|
| Доли, средние, настроение, десятилетия, рекорды для недели и месяца | `SoundSummaryTest` |
| Меньше 5 треков с фактом — цифры нет | `SoundSummaryTest` |
| Показатели достижений и границы порогов | `SoundSummaryTest` |
| Прежние достижения не меняются; полученное не отбирается | `SoundSummaryTest`, `GamificationEngineTest` |
| Английские варианты всех названий и описаний | `SoundSummaryTest`, `UiMessageCatalogTest` |
| Вид экрана, крупный шрифт, TalkBack, тёмная тема | NOT RUN |
