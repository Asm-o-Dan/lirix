# Спецификация SPEC-TEACH-05: Редизайн эргономики Teach Mode, стабилизация тач-инспектора и исключение потомков

## 1. Контекст и Цели
Реализовать эргономичный, устойчивый к ложным нажатиям режим обучения (`Teach Mode`) на основе UX-аудита (`.sdd/architecture_teach_inspector_ux.md`) и ADR-014.

---

## 2. Архитектурные Требования

### Зона 1: Сенсорный Инспектор (`app/src/main/assets/teach_inspector.js`)
1. **Жестовый арбитраж (Gesture Arbitration)**:
   - В `touchstart`: фиксировать `startX = touch.clientX`, `startY = touch.clientY`, `isScrolling = false`.
   - В `touchmove`: если `Math.hypot(touch.clientX - startX, touch.clientY - startY) > 8`, выставлять `isScrolling = true`.
   - В `touchend`: если `isScrolling === true`, немедленно прерывать выполнение.
2. **Устранение дребезга и дубликатов**:
   - Отслеживать `lastInspectTimestamp`. Игнорировать любые события, пришедшие в пределах 300мс после предыдущего.
   - Заблокировать синтетические `click` при включенном режиме инспектора.
3. **Двухслойная модель выделения (Include + Strip)**:
   - Хранить два массива: `window.__selectedParents = []` (включающие контейнеры) и `window.__strippedChildren = []` (вырезанные потомки).
   - Если пользователь кликает по элементу вне существующих родителей: элемент добавляется в `__selectedParents` с фиолетовой рамкой (`outline: 3px solid #B388FF`, `box-shadow: 0 0 16px rgba(179, 136, 255, 0.6)`).
   - Если пользователь кликает по элементу **внутри** уже выделенного родителя:
     - Если элемент уже в `__strippedChildren`: удаляется из исключений (toggle).
     - Иначе: добавляется в `__strippedChildren` с красной рамкой (`outline: 2px dashed #EF4444`, `opacity: 0.6`, `text-decoration: line-through`).
4. **Метод подъема к родителю**:
   - Экспортировать `window.expandTeachSelectionToParent()`: заменяет текущего родителя на `parent.parentElement`, пересчитывает стили и уведомляет `TeachBridge`.
5. **Мост JavaScript Interface (`TeachBridge`)**:
   - Передавать в Android:
     `onElementSelected(parentSelector, stripSelectorsJson, extractedText, linesCount, domain, parentsCount, strippedCount)`

### Зона 2: UI Редизайн (`app/src/main/java/com/lirix/app/ui/TeachModeScreen.kt`)
1. **Разгрузка шапки (Top Bar)**:
   - Слева: Кнопка «Назад» (если WebView может вернуться назад) + Крестик закрытия.
   - По центру: Название трека и текущий хост.
   - Справа:
     - Компактная двухпозиционная капсула: `[🌐 Сёрфинг] | [🎯 Инспектор]`.
     - Кнопка вызова меню **⋮ (Overflow Menu)**.
2. **Меню ⋮ (DropdownMenu)**:
   - 📥 Импорт правила из буфера обмена.
   - 📤 Экспорт/шеринг текущего правила.
   - 🔄 Сбросить все выделения (`window.clearTeachSelection()`).
   - 🌐 Открыть в системном браузере.
3. **Нижняя панель управления (Inspector Dock)**:
   - Строка 1:
     - Чип селектора: `[🟣 {selector}]`
     - Бейдж исключений (если есть): `[🔴 {N} вырезано]`
     - Кнопка `[▲ Родитель]` для расширения выделения.
     - Кнопка `[✕ Сброс]`.
   - Строка 2: Сегментированный переключатель целевого типа контента:
     - `[📝 Текст песни]` / `[🎸 Аккорды]`.
   - Строка 3: Компактный предпросмотр очищенного текста (3 строки).
   - Строка 4: **Единая кнопка действия**:
     - `«Сохранить правило и привязать»` (HyperViolet / Gradient).
     - При нажатии:
       1. Генерирует динамический `search.urlTemplate` на основе текущего хоста:
          `https://${domain}/search?q={query}` (или путь поиска, если он детектирован в URL).
       2. Сохраняет `CustomLyricsRuleEntity` с полями:
          - Если тип «Текст»: `"content.selector" = parentSelector`, `"content.stripSelectors" = stripSelectors`.
          - Если тип «Аккорды»: `"content.chordsSelector" = parentSelector`, `"content.stripSelectors" = stripSelectors`.
       3. Сохраняет очищенный текст/аккорды в `music_tracks` и `lyrics_cache` для текущего трека.
       4. Вызывает `onLyricsAttached` и закрывает экран `onClose()`.

## 3. Критерии приемки (DoD)
1. Скролл пальцем по странице в режиме инспектора **никогда** не приводит к случайному выбору элементов.
2. Одиночный тап четко выделяет элемент без перепрыгивания через SPAN.
3. Тап внутри фиолетового контейнера вырезает элемент красной рамкой, а его текст мгновенно исчезает из превью.
4. Кнопка `[▲ Родитель]` расширяет контейнер на уровень выше.
5. Шапка разгружена, вторичные кнопки аккуратно вынесены в меню ⋮.
6. Переключатель «Текст / Аккорды» сохраняет правило в соответствующий селектор и поле Room БД.
7. Все unit-тесты зеленые (`./gradlew testDebugUnitTest`).
8. Релизный APK собирается без ошибок (`./gradlew assembleRelease`).
