## Gate2 freeze: alpha and installed API

Normative clarification overriding ambiguous alpha wording above: `desktopReadableForeground` is exclusively an opaque-solid-text normalizer. Require nonempty backgrounds, each specified/opaque (`alpha==1f`), finite minimumContrast in1.0..21.0, and specified finite foreground. First take `solid = foreground.copy(alpha=1f)`. Contrast calculation and HSL search operate on solid; they never composite the incoming foregroundalpha. If solid passes, return solid. Return input bit-identically only when inputalpha was already1 and it passes. All successful results have alpha1, including transparent input.
