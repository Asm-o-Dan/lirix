# Модуль: AnalogTurntable   Зона: media-ui   Версия: v1   Статус: APPROVED

## 1. Назначение
Компонент Jetpack Compose для аналогового проигрывателя винила:
- Отрисовывает вращающийся виниловый диск с концентрическими канавками, шпинделем и обложкой альбома.
- Отрисовывает кинетический тонарм (звукосниматель) с шарнирным основанием, штангой, картриджем и световым индикатором иглы.
- Поддерживает сворачивание/раскрытие для экономии места на экране смартфона.

## 2. Публичный API

```kotlin
@Composable
fun AnalogTurntable(
    isPlaying: Boolean,
    albumArtBitmap: ImageBitmap?,
    isCollapsed: Boolean,
    onToggleCollapse: () -> Unit,
    onTogglePlayPause: () -> Unit,
    modifier: Modifier = Modifier
)
```

### Параметры:
- `isPlaying`: статус воспроизведения (управляет вращением и позицией тонарма).
- `albumArtBitmap`: обложка трека в центре пластинки (с фолбэком на стилизованный градиент с нотой).
- `isCollapsed`: свернут ли проигрыватель.
- `onToggleCollapse`: коллбэк переключения свёрнутости.
- `onTogglePlayPause`: коллбэк переключения Play/Pause при тапе по пластинке.

## 3. Кинематика и Анимации

### А. Вращение винила:
- При `isPlaying == true`: непрерывное вращение 360° со скоростью 16 сек/оборот (`LinearEasing`).
- При `isPlaying == false`: остановка на текущем угле или фиксация на 0°.

### Б. Тонарм (Звукосниматель):
- Угол поворота `tonearmAngle`:
  - Воспроизведение: `0f` (игла стоит на канавке винила).
  - Пауза: `-28f` (игла поднята и отведена на парковочную стойку).
  - Спецификация анимации: `spring(dampingRatio = 0.78f, stiffness = Spring.StiffnessLow)` — дает тактильный физический вес и легкое покачивание головки при опускании на пластинку.
- Точка вращения (pivot): верхний правый угол проигрывателя (`TransformOrigin(1f, 0f)` или точные координаты шарнира).

### В. Сворачивание:
- Анимация `AnimatedVisibility`:
  - `enter = expandVertically(animationSpec = tween(300)) + fadeIn()`
  - `exit = shrinkVertically(animationSpec = tween(300)) + fadeOut()`
- В свёрнутом состоянии: кнопка разворачивания или мини-пластинка 36dp рядом с треком.

## 4. Вне скоупа
- Физическая симуляция царапанья пластинки (scratching).
- Замедление скорости вращения pitch-fader.
