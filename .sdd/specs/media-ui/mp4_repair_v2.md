# MP4 repair v2 — APPROVED 2026-10-22

Scope: repair current silent offline H.264 exports; no audio, styles or release changes.

1. ByteBuffer frame submission retries after draining output until input is available; bounded by monotonic deadline (10 seconds), cancellation checked on every iteration. Frame index advances only after successful queue. Failed/short input buffer is an error, never a partial frame.
2. Codec adapter exposes input dequeue/write, output dequeue/read/release, format, EOS and release. Shared production pump is testable using a fake adapter, not a separate algorithm. Initialization checks supported formats: explicit semiplanar NV12 or planar I420; flexible uses getInputImage plane row/pixel strides and closes the image. Do not assume flexible means NV12. Unsupported codec fails explicitly.
3. finish queues EOS with same retry policy, drains until confirmed output EOS, checks queued/muxed frame count and nonempty output, then stops muxer successfully. Any error is propagated. close/abort releases all resources and removes incomplete output; never finalize partial video during exception cleanup. Constructor failure releases already-created resources.
4. Pipeline passes coroutine ensureActive callback into encoder; cancellation propagates. Render t=i/(N-1) (single frame t=1), timestamps remain i/fps. Progress completion reported only after successful finish. Lyric typewriter finishes at t=.85, holds final text through export end.
5. Typewriter uses Android ICU grapheme boundaries (minSdk >=24 must be verified); no split surrogate/combining/ZWJ sequences. Typography uses measured wrapping and fit within explicit title/artist/lyric rectangles; layout derived from full text for stable positions. No clipping or silent truncation of long metadata.
6. `CounterRollLabels(header, minutes, tracks, artists, topTracks, plays)` is immutable constructor data, populated by caller-localized resources; `ENGLISH` default retains constructor compatibility. MP4 repair owns CounterRollAnimator.kt; localization owns WrappedScreen.kt caller/resources.
7. Tests: production pump fake-backpressure, timeout, EOS timeout, muxer failure and cancellation/resource deletion; long final text and grapheme prefixes/layout bounds; device-only 1080x1920/24fps/96 frames test uses MediaExtractor and decode to verify frame timestamps/count/duration and color samples. Robolectric file existence is not codec validation. Device execution remains unverified until actually run.

Baseline: existing animation main/test directories copied verbatim to ignored build/repairs-baseline/mp4/{main,test}; original animation sources, shared AnimationSpec/PosterAnimator and animation tests were untracked Antigravity work at intake. Integration must include those prerequisite files, not only repair deltas.
