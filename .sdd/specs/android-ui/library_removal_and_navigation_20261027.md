# Медиатека: удаление и навигация

Два последовательных этапа. Разбор: `.sdd/reports/LIBRARY_MENU_NAVIGATION_AUDIT_20261027.md`. APK пока не создавать.

## 1. Меню и удаление из медиатеки

Убрать действия по горизонтальным свайпам строк. Рядом с каждым треком — доступная кнопка ⋮, меню «В избранное / Убрать из избранного» и «Удалить из медиатеки». Избранное переключается атомарно по текущему состоянию БД.

«Удалить из медиатеки» устойчиво исключает ключ трека из всех представлений медиатеки; аудиофайл, пользовательский текст, заметки, история и избранное сохраняются. Ключи хранятся в Android SharedPreferences `lirix_library_exclusions.xml`, `removed_track_keys_v1`; application singleton сериализует изменения с Mutex, копирует StringSet, проверяет `commit()` и публикует `StateFlow`. При ошибке записи показать сообщение и не утверждать успех. Все фильтры, поиск и исполнители получают общий реактивный список. Воспроизведение не возвращает удалённый трек автоматически. Snackbar объясняет сохранение аудио и предлагает Undo; после его исчезновения доступен список удалённых и восстановление в медиатеке, включая пустое состояние. Undo/восстановление удаляет конкретный ключ, не перезаписывая TrackEntity или параллельные изменения.

Новый prefs файл добавить в обе системные backup allowlist; схему Room не менять. Экспорт/слияние `LibraryArchive` prefs не переносит: не обещать перенос этой настройки. RU/EN и TalkBack обязательны. Проверки: реальный storage и повторное создание, многократное удаление/undo, ошибка записи, отсутствие потери истории/текста/файла, все фильтры, пустой список; визуальный и физический тест устройства отмечать отдельно.

## 2. Свайпы между экранами

После завершения меню: перемещаться между Плеер ↔ Медиатека ↔ Итоги после завершения свайпа, связав состояние с нижней навигацией и внешними переходами. Сохранить состояние экранов, reduced motion и доступность кнопок. Системный Back на краях, вертикальная прокрутка, дочерние горизонтальные фильтры, скрабберы и открытые модальные окна/клавиатура имеют приоритет. Тестировать направление, крайние страницы, конфликт жестов и возврат в обеих ориентациях.
