# 1. Восстановление поиска после появления интернета

Пользователь сообщил: если песня открыта без интернета, текст не находится, а после подключения поиск не возобновляется. Отложено до завершения текущего экрана общих настроек; затем первая задача очереди.

Предусмотреть повторный поиск при восстановлении сети и доступную кнопку «Попробовать ещё раз». Различать временную сетевую ошибку и подтверждённое отсутствие результата. Не перезаписывать сохранённый пользовательский текст, не допускать параллельных одинаковых запросов и применения результата к уже сменившемуся треку.

Приёмка: отсутствие сети → восстановление без смены песни; ручной повтор; смена трека во время запроса; повторные события сети; сохранённый текст остаётся целым. До реализации проверить фактическое поведение и согласовать сетевой контракт по .sdd/WORKFLOW.md.
