# Жанр, настроение и другие метаданные треков для «Итогов» и профиля

Запрос владельца от 2026-11-13 к пункту C4 (`intake/ROADMAP_20261109.md`): для расширенных «Итогов» нужно как-то определять жанр, настроение и, возможно, другие мета-метрики трека; допустимо получать их из интернета.

Сейчас жанр, настроение, длительность трека и событие намеренного пропуска в базе не хранятся (`reports/PROFILE_ANALYTICS_DIALECTIC_20261027.md`), поэтому «любимый жанр» и похожие показатели вывести не из чего. Эта карточка — предварительное условие второго этапа профиля.

Что нужно выяснить (сначала исследование, код после решения):
- Источники: открытые базы с API и понятными условиями (MusicBrainz, Last.fm, Discogs, ListenBrainz, Deezer и т. п.) против скрапинга страниц. Для каждого — что отдаёт (жанр, теги, настроение, темп, год, длительность), лимиты, условия использования, покрытие русскоязычной музыки.
- Сопоставление трека: метаданные из уведомлений плеера неточные; неуверенное совпадение не считать подтверждённым (AGENTS 7.4), несколько кандидатов — не выбирать молча.
- Настроение: готовые теги источника, признаки звука или оценка по тексту на устройстве; что из этого реально и честно подписывается.
- Хранение: отдельная таблица метаданных с источником, датой и уверенностью по каждому полю; ручная правка пользователя важнее автоматики (AGENTS 7.1); перенос в архив и на Desktop.
- Приватность и сеть: запросы раскрывают внешнему сервису, что слушает пользователь, — только с явного согласия, с лимитами и кешем; без фоновой массовой выгрузки всей медиатеки.

Уровень 2: новая схема, внешние источники, приватность. Нужны спека и ревью до реализации.

Приёмка исследования: таблица источников с рекомендацией; доля треков реальной медиатеки, для которых жанр найден уверенно (замер на синтетической или обезличенной выборке); предложенная схема хранения; список показателей «Итогов», которые после этого можно показывать, и тех, которые по-прежнему нельзя.
