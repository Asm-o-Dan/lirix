# Импорт набора правил создаёт активные правила без проверки

Найдено независимым ревью TeachMode 2.0 (`reports/TEACH_MODE_V2_STAGE4_20261101.md`). `ScraperRuleBundleCodec` (`app/src/main/java/com/lirix/app/feature/lyrics/`) при импорте сохраняет правила со статусом из файла. Правило, созданное в TeachMode, включается только после успешной проверки (SPEC-TEACH-06 R9/R10); импортированное этот шаг обходит. Desktop при выполнении правил не смотрит на `status`.

Уровень 2 (безопасность, внешние данные). Запланировано как A5 в `intake/ROADMAP_20261109.md`.

Что сделать: импортированные правила получают статус DRAFT независимо от содержимого файла; включение — через ту же проверку, что в диалоге правила; Desktop пропускает DRAFT. Проверить политику URL (`RuleUrlPolicy`) для шаблонов из файла.

Приёмка: импорт набора с правилом на чужой или локальный адрес не приводит ни к одному сетевому запросу без действия пользователя; ранее сохранённые собственные правила не меняют статус; экспорт и повторный импорт своего набора не теряет правила.
