# 4. Убрать «Повторить анимацию» из итогов

Прямой запрос пользователя по скриншоту 3964.jpg: кнопка повтора анимации больше не нужна. Отложено после исправления жестов медиатеки.

Убрать действие из экрана итогов и закрыть освободившийся отступ. Сохранить показ статистики, выбор периода, первоначальную анимацию и возможность поделиться карточкой. Не удалять общий анимационный движок, используемый другими экранами или экспортом.

Приёмка: кнопки нет в RU/EN, нет пустого блока на её месте; фильтр периода, итоговые значения и экспорт работают. Локальная обратимая правка с проверкой diff и отображения, по уровню 0 .sdd/WORKFLOW.md.
