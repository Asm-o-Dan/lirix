# Как я написал оффлайн-хаб для караоке и аккордов на Jetpack Compose с 120 FPS винилом и реверс-инжинирингом MediaSession

> Дисклеймер: Все описанное ниже — полностью открытый Open Source проект (MIT) без рекламы, платных подписок и сбора персональных данных.

Современные музыкальные сервисы всё сильнее закручивают гайки. Spotify прячет синхронизированные тексты песен за премиум-подпиской, Яндекс Музыка далеко не для каждого трека имеет караоке-тайминги, а в Telegram или VK тексты песен вообще живут своей жизнью.

Если вы играете на гитаре или любите подпевать любимым исполнителям, вы наверняка сталкивались с классическим «адом вкладок»:
1. В одном приложении играет музыка.
2. В браузере открыт AmDm или Ultimate Guitar с аккордами.
3. В третьем месте ищется текст, который приходится скроллить пальцем каждые 15 секунд.

Я решил закрыть эту боль раз и навсегда и написал **Lirix** — музыкальный Companion & Analytics Hub для Android на чистом Jetpack Compose. В этой статье расскажу об инженерных вызовах: как выжать стабильные 120 FPS из векторного винила, как подружить MediaSession с капризными контроллерами Telegram, и как сделать синхронизацию караоке в 3 тапа.

## Архитектура: как Lirix узнает, что у вас играет?

Большинство подобных утилит требуют ручного поиска трека. В Lirix задача стояла жестче: **нулевое трение**. Вы запускаете трек где угодно (Spotify, Яндекс Музыка, VK Музыка, Telegram, YouTube Music) — Lirix мгновенно подхватывает трек, обложку, позицию воспроизведения и статус плеера.

### Подводный камень: Dual-Controller Ingress в Telegram

В Android взаимодействие с плеерами идет через `MediaSessionManager.addOnActiveSessionsChangedListener`. Мы получаем список `MediaController`.

Казалось бы, бери активный контроллер и читай `metadata` и `playbackState`. Но в продакшене нас ждал сюрприз от Telegram:
- Telegram регистрирует сразу два контроллера: один от внутреннего аудио-движка (`telegramAudioPlayer`), второй — сервисный `MediaSessionHelper`.
- У одного контроллера есть метаданные, но `playbackState.actions` не содержит флага `ACTION_SEEK_TO`. У второго есть перемотка, но он часто рапортует `STATE_NONE`.

Мы решили это через скоринговый арбитраж контроллеров:
```kotlin
fun resolveTargetController(controllers: List<MediaController>): MediaController? {
    return controllers
        .filter { it.playbackState != null && it.metadata != null }
        .maxByOrNull { controller ->
            var score = 0
            val state = controller.playbackState?.state ?: PlaybackState.STATE_NONE
            if (state == PlaybackState.STATE_PLAYING) score += 100
            if (state == PlaybackState.STATE_PAUSED) score += 50
            val actions = controller.playbackState?.actions ?: 0L
            if ((actions and PlaybackState.ACTION_SEEK_TO) != 0L) score += 20
            score
        }
}
```

Благодаря этому перемотка и статус воспроизведения работают бесшовно даже в нестандартных плеерах.

## 120 FPS аналоговый винил на Jetpack Compose

Главный экран плеера вдохновлен аналоговыми проигрывателями: вращающийся виниловый диск с текстурой канавок, стилизованный тонарм (звукосниматель) с иглой, и динамическая палитра, извлекаемая из обложки альбома.

### Почему наивная реализация убивала плавность?

В первой версии угол вращения и позиция тонарма вычислялись в `State<Long>`, обновляемом таймером каждую секунду. Результат — микрофризы и рывки при перерисовке.

Для достижения кинематографичной плавности на экранах 90/120 Гц мы применили три оптимизации:

1. **Интерполяция тиков через `withFrameMillis`:**
   Вместо таймеров мы привязались к кадровой развертке дисплея:
   ```kotlin
   LaunchedEffect(isPlaying) {
       if (!isPlaying) return@LaunchedEffect
       var lastFrame = withFrameMillis { it }
       while (isActive) {
           val currentFrame = withFrameMillis { it }
           val delta = currentFrame - lastFrame
           lastFrame = currentFrame
           // Плавная интерполяция угла вращения пластинки
           vinylAngle = (vinylAngle + delta * ROTATION_SPEED) % 360f
       }
   }
   ```

2. **Кеширование градиентов:**
   Пересоздание `Brush.sweepGradient` и `Brush.radialGradient` в теле `@Composable` вызывало постоянные аллокации в куче. Обернув кисти в `remember(themeTokens)`, мы снизили нагрузку на Garbage Collector до нуля.

3. **Физический тонарм на Canvas:**
   Угол наклона звукоснимателя рассчитывается относительно прогресса трека `currentPosition / duration`. Игла плавно опускается на край диска при старте и скользит к центру композиции.

## LrcTapSync Studio: Караоке в 3 тапа прямо на смартфоне

Что делать, если для редкого инди-трека нет синхронизированного караоке (`.lrc`), а есть только текст в заметках?

Раньше приходилось открывать десктопные редакторы, вручную вбивать таймкоды `[02:14.30]` и кропотливо сводить дорожки.

В Lirix мы встроили **LrcTapSync Studio**:
1. Вставляете текст из буфера обмена.
2. Включаете песню.
3. Тапаете по строке в момент, когда вокалист начинает петь.

Алгоритм студии автоматически:
- Валидирует строгую монотонность (таймкод каждой следующей строки обязан быть строго больше предыдущей).
- Рассчитывает среднюю скорость слогов (WPM) и подсвечивает подозрительно короткие интервалы.
- Экспортирует чистый стандартный `.lrc` файл и сохраняет его в локальную базу SQLite Room.

## Аккорды AmDm с транспонированием и умным автоскроллом

Для музыкантов встроен парсер и визуализатор аккордов:
- Автоматический поиск по базе AmDm.
- **Транспонирование в 1 клик:** если тональность песни неудобна для вокала, кнопки `+1` / `-1` мгновенно пересчитывают все аккорды (Am -> Bbm -> Bm).
- **Интерактивные аппликатуры:** тап по любому аккорду открывает мини-гриф с постановкой пальцев.
- **Умный автоскролл:** скорость скролла автоматически адаптируется под длительность песни, освобождая руки для гитары.

## Личный Wrapped 24/7: Полная приватность без «облаков»

Все любят годовые итоги Spotify Wrapped или Яндекс Музыки. Но почему их нужно ждать целый год?

В Lirix встроен локальный движок персональной аналитики:
- **Индекс одержимости:** вычисляет треки с аномальной частотой реплеев за последние 7, 30 дней или все время.
- **Суточный компас активности:** строит диаграмму распределения прослушиваний (утро, день, вечер, ночь).
- **26 игровых ачивок:** от «Ночного меланхолика» (прослушивание грустных треков в 3 часа ночи) до «Аудио-марафонца».
- **Генератор шеринга:** формирует эстетичные карточки для Stories (9:16) и квадратные посты (1:1).

**Ключевое отличие:** Ни один байт данных не покидает ваше устройство. Вся аналитика считается на лету через агрегационные SQL-запросы в Room Database.

## 4 темы оформления

Интерфейс поддерживает 4 продуманных визуальных стиля с адаптацией под системный AMOLED Black:
- **Spotify Style:** глубокий зеленый акцент и фирменная плотность верстки.
- **Яндекс Музыка:** теплый янтарно-желтый драйв.
- **Obsidian:** минималистичный монохром для ценителей строгой эстетики.
- **Pastel / Paper:** мягкие кремово-кофейные оттенки с акварельным выделением строк.
